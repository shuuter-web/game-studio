# 🌱 PLAYSEED: カブ盛りバブル（仮）

> ユーザー持ち込みのお題「どうぶつの森っぽいIP × カブ × すごろく。突然変異カブの大発生、空前のカブ取引ブーム。
> カブを頭に積んで移動。爆発カブの押し付け合い、有望カブの取り合い。すごろくはシンプルに、相場読みは数字最小で」を展開した。
> 「どうぶつの森っぽい」は**雰囲気（動物の住人・のんびりした島・季節）を借りるだけのオリジナルIP**とする。
> 実在作品の固有名詞（通貨名・カブ売りのキャラ・「カブ価」等の用語）は使わない。

## 1. ログライン（What）
流れ星の夜を境に、島のカブが次々と突然変異した。光るカブ、歌うカブ、膨らみ続けるカブ。
住人たちは「カブを頭に盛って歩く」のが大流行中で、**頭上のカブタワーがそのまま自分の持ち株**。
サイコロで島を回り、市場で売り買いし、すれ違った相手にヤバいカブを押し付け、有望なカブをひったくる。
シーズン終わりにいちばん稼いだ住人が勝ち。

## 2. コアファンタジー（Why it feels good）
のんびりした島で、**バブルに踊る投機家**になる。可愛い見た目のまま欲と駆け引きをむき出しにできるギャップと、
「みんなが売り抜けた後に爆上がりした」「押し付けた爆弾カブが相手の頭で破裂した」という他人を出し抜く快感。

## 3. コアループ（30秒で何を繰り返す？）
サイコロを振る → 移動中に**すれ違った相手の頭へ自分のてっぺんのカブを押し付けるか、相手のてっぺんを奪うか**を選ぶ →
止まったマスで「市場で売る／畑で抜く（買う）／イベント」 → 全員の頭を見て、次にどの種類が上がるか読む。

成立の核は4つのルールだけ：
1. **カブは上からしか出し入れできない**（頭の上は積み木。売るのも渡すのも、いちばん上から順番）。
   爆弾カブが途中に埋まると、その下のカブは売れない＝**積む順番が戦略になる**。
2. **値段は数字でなく、市場の看板の顔5段階**（😱→😐→🙂→😄→🤩）。
3. **相場は需給で動く：全員の頭に乗っている数が多い種類ほど下がる**。
   頭上は公開情報なので、**みんなの頭を見れば相場が読める**（数字を見る代わりに、人を見る）。
4. **背が高いほどぐらつく**。風マス・段差マスで高すぎるタワーは上半分が崩れてマスに散らばり、誰でも拾える。

## 4. フック / 新規性（Novelty）
- いちばんのひねり：**ポートフォリオが頭の上に積まれて全員に見えている**。持ち株・需給・順番・リスクが1本のタワーに全部出る
- 既存ゲームの「あれ」を「これ」に置き換えた：株ボードゲームの「株券と価格表」→「頭のカブタワーと看板の顔」
- 30秒トレーラーで“絵”になる瞬間：天まで届きそうなカブタワーで橋を渡る住人／風マスで崩れて広場にカブの雨／
  押し付けた爆弾カブが相手の頭で「ポンッ」とはじけてタワーが四方に飛ぶ

## 5. 市場性（Market）
- ターゲット：家族・友人と遊ぶパーティゲーム層、配信者（崩落と爆発が配信映え）、まったり系IPのファン
- 参照タイトル：すごろくパーティ系、株・相場系ボードゲーム（差別化の一点：**数字の表を読まずに、人の頭を見て相場を読む**）
- 収益モデル：買い切り＋季節パック（新しい突然変異カブ・島）
- 配信先：Switch系コンソール / Steam / モバイル（オンライン対戦）
- 追い風/逆風：まったり動物IP需要は根強い。逆風は「どうぶつの森っぽさ」が強すぎると模倣に見える点
  → 動物以外のフック（カブタワー）を前面に出す

## 6. 面白さの核（Fun）
- ジューシーポイント：満面の🤩看板の前で、高く積んだ同種カブを上から一気に売り抜ける瞬間／爆弾の押し付け成功
- 上達/深まりの方向：積む順番の管理、他人の頭から需給を読む、「みんなが持ってる＝下がる」の逆張り、うわさの真偽判定
- 中毒のフック：毎回カブの種類と順番がバラけて展開が違う。負けても「あの時売っていれば」が明確

## 7. 拡張性 / 伸びしろ（Stretch）
- 縦に深まるか：突然変異カブ図鑑のコンプリート、住人ごとの小さな能力差、ランク戦
- 横に広がるか：**突然変異カブの種類＝コンテンツ**。季節ごとに新種（夏：花火カブ、冬：雪だるまカブ）を足せる。島の形・市場の店主も差し替え可能
- 継続サイクル：季節イベント（週替わりの「流行カブ」）、図鑑、オンラインの短いシーズン
- アピールの面：タワー・爆発・崩落・図鑑・季節衣装と複数の絵が切れる
- 天井とリスク：カブの種類を増やしすぎると「覚えること」が増え、数字最小の良さが死ぬ。1試合に出る種類は4〜6に絞る

## 8. 検証すべき最大の賭け（Riskiest Assumption）
「**頭を見て相場を読む**」が本当に駆け引きになるか。需給で値が動くだけだと全員が同じ判断をして平坦になる恐れがある。
→ 最小プロト：カブ4種・看板5段・需給ルール・うわさカード（自分だけ見える「◯◯カブが来週上がるらしい」）だけの
4人ホットシート版で、「売り時がプレイヤーごとに割れるか」を見る。押し付け・崩落はその後。

## 9. スコープ感
- 最小プレイアブルに必要な要素（3つまで）：①上からしか触れないカブタワー ②需給で動く顔5段の相場 ③すれ違いの押し付け/ひったくり
- 技術リスク / 未知数：技術は軽い。リスクはバランス（需給の感度、爆弾の頻度）とオンラインの手番テンポ
- 規模感：ルール検証は1日試作（単一HTML）、本制作はパーティゲーム級

## 11. ひとことメモ / 着想元
ユーザー持ち込み。最大の賭けの検証プロト：`prototypes/kabu-mori/`（v0.7.0、3D・CPU/ホットシート対応）。
v0.2.0 で相場の表示をUI（顔5段の看板）から**カブの大きさ**に置き換えた（ユーザー案）。値が上がると島じゅうの同じ種類のカブが一斉に膨らむ。
副次効果：高いカブほど大きく、タワーが高く揺れやすくなる＝「高値の資産ほど抱えるのが怖い」が見た目と一致する。
v0.3.0 で「カブを得る機会が少ない」（ユーザー判定）に対応し、うわさマス・道を**カブマス**（6/16マス）に変更。止まると置いてあるカブをタダで拾え、そのカブのうわさも聞こえる（うわさはマスの追加効果になった）。
CPU40試合で、1試合の拾得 約22個・売却 16.6→36.5個、判断が割れた日 2.5→5.7（売った日の約27%）。
突然変異カブ図鑑の初版案と盤面案は `_raw-seeds-log.md` の同日エントリにある。
v0.4.0（ユーザー判定「拾える数の運勝負になっている」「頭に積むインセンティブがない」を受けて）：
- **食べる**：番の最初に頭のカブを1個（どの段でも）食べられる。突然変異で効果が違う
  （🎈ふくらみ＝その色を値上げ／🥀しおれ＝好きな色を値下げ／👟はしり＝サイコロ2回／🧲じしゃく＝好きな相手から1個引き寄せ／✨きらきら＝次のうわさ的中）。
- **頭の上の反応**（自分の番の終わり）：同じ色の隣接で🌱増殖、同色3連で👑大カブに合体（1段高く売れる）、
  違う色の隣接で🧬突然変異（色の組み合わせで種類が決まる。べに×ほし は💣）。積むほど当たりが出る。
- **💣ばくだん**：食べられず売れない。持ち主の番の終わり3回で破裂し両隣ごと吹き飛ぶ。押し付けはどの段でも選べる。
- 売る・食べるは**どの段でも**選べる（真ん中を抜くと上が落ちて新しい隣接ができる）。
- 不採用：サイコロ2個から目を選ぶ／拾うか選ぶ（ユーザー判定でNG）、毎朝の朝市ドラフト（手番外のターンが煩雑。たまのイベントならアリ）。
- CPU40試合：1試合あたり 食べる4・増殖7.7・合体6.5・突然変異6.1・破裂2.1。CPUは売りが早く最大の高さ5.5段なので、積む価値はまだ人の手で要確認。
v0.4.1（ユーザー判定「爆弾が出過ぎ」「大カブは3倍以上の値段か？」）：
- 大カブは「1段上の値段」だったため合体が損になっていた（例：🙂3🪙×3個=9 → 合体後5🪙）。**同じ色1個の4倍**に修正。
- 💣：カブマスには出さない／べに×ほしの突然変異でも35%しか💣にならない／導火線3→5日／**市場でタダで引き取ってもらえる**（平和な処分）。
  CPU40試合で破裂 2.1→0回、引き取り 0.6回/試合。
v0.4.2：💣の市場引き取りは「簡単すぎて脅威が消える」（ユーザー判定）ため撤回。手放す手段は押し付けのみ。
出現を減らす変更（カブマスに出さない・べに×ほしの35%・導火線5日）は維持。CPU40試合で破裂0.48回・押し付け0.48回/試合。
v0.5.0：**カブの値段に上限なし**（ユーザー指示）。🤩の先も1段ごとに値段1.6倍（8→13→20→33→52…）、大きさ1.18倍で膨らみ続ける。
CPU40試合で最高到達 段10（133🪙）、🤩超えの日が1試合あたり延べ8.4日。バブルの見た目（島じゅうのカブが巨大化）がそのまま出る。
v0.6.0（ユーザー指示）：
- 相場を真ん中へ戻す力を撤廃（流行・需給・ゆらぎ・食べる・ラジオだけで動く）。CPU40試合で、底値の日 延べ15日・🤩超え 延べ13日/試合、最高 段12。
- マスを16→20に増やし、🔀ならべかえ（隣り合う2つを入れ替え）／🧪けんきゅうじょ（好きなカブを突然変異。15%で💣）／🌧ひりょう（その番は同色の隣接が必ず増える）を追加。
- 🪽はね（突然変異）：食べるとサイコロを振らず好きなマスへ飛べる。カブマスとけんきゅうじょで手に入る。CPUで1試合1.8回使用。
v0.7.0：盤をモノポリー型の正方形（1辺6マス・四隅が畑）に変更し、カメラは回転をやめて手番の人を追って平行移動する。
円形＋周回カメラだと同じ絵が続き、どこに何のマスがあるかの手がかりがなかった（ユーザー判定）。
