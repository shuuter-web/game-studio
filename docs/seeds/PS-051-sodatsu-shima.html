そだつ島

島のほうが育つ。プレイヤーはほぼ一定のまま、収穫が大きくなる

保留 収穫放置成長Web/モバイルタップ手描きボクセル 2026-09-06 producer (方向は greenlight-judge の指摘から)

1. ログライン（What）

手描きの浮島は、放っておくと勝手に層を重ねて育つ。深い層ほど硬く、価値が高い。プレイヤーの力はほとんど変わらない——育つのは島のほうで、プレイヤーはそれを収穫する。留守にした時間だけ島が厚くなっていて、次に開いたときの一掴みが大きくなる。

2. コアファンタジー（Why it feels good）

自分が強くなるのではなく、世界の側が自分を待っていてくれる。畑や貯金に近い、育ったものを刈り取る満足。放っておいた時間が無駄にならないという安心。

3. コアループ（30秒で何を繰り返す？）

育った層を見て、どこから食うか決める（入力）→ タップで削り、層ごとに違う手応えで剥がれる（変化）→ 深い層ほど大きく加点し、島が薄くなる（報酬）→ どこまで刈るか、どこを残して育てるか（意思決定）。 残す判断があることがこの案の核。刈り尽くすと次の成長が遅くなる。

4. フック / 新規性（Novelty）

  • いちばんのひねり：エスカレーションの担い手がプレイヤーではなく世界。強化ツリーを1本も作らずに、破壊の単位が育っていく。
  • 置き換え：放置ゲームの「数字が増えている」を、画面の中で目に見えて厚くなる島に置き換えた。
  • 30秒トレーラーで絵になる瞬間：時間送りで、島が層を重ねて盛り上がっていく早回し。

5. 市場性（Market）

  • ターゲット：短時間×高頻度で開くモバイル層。放置・収穫系に反応する層。
  • 参照タイトル：放置系インクリメンタル全般／Vampire Survivors 的なラン型ではない（差別化の一点：成長がHUDの数字ではなく画面の形として見える）
  • 収益モデル：F2P（時短・拡張）or 買い切り
  • 配信先：Web / Mobile
  • 追い風：「留守の間に育っていた」はモバイル最強クラスの復帰動機。逆風：放置系は数が多く、作業感に転びやすい。

6. 面白さの核（Fun）

  • ジューシーポイント：厚く育った層に初めて手を入れ、一掴みでごっそり剥がれる瞬間。
  • 上達の方向：刈り方。全部刈ると成長が鈍るので、どこを残すかの配分が上手くなる。
  • 中毒のフック：次に開いたときの厚み。開くまで分からない。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦：層の種類、島の最大厚、収穫の記録。強化ツリーが無くても成長が成立するのが構造上の強み。
  • 横：島テーマと層の組み合わせ。既存の generateIsland() を段階的に走らせるだけで増える。
  • 継続サイクル：復帰動機が設計の中心にある（他案は後付けで足す必要がある）。
  • アピールの面：育つ絵と刈る絵の対比。早回しが強い。
  • 天井とリスク：放置系の宿命として作業感に転ぶ。刈るのが待ち時間の消化になったら死ぬ。

8. 検証すべき最大の賭け（Riskiest Assumption）

「残す判断」が本当に効くか。 これが無いと、ただの待ち時間つきタップ収穫になる。刈りすぎたら成長が鈍る／残したら加速する、という関係をプレイヤーが自分で発見して調整し始めるか。 → 層3種＋成長速度が残量に依存するだけの最小プロトで、2〜3回の収穫を通して刈り方が変わるかを見る。変わらなければ、この案は放置系の平均に落ちる。

9. スコープ感

  • 最小プレイアブル：①層を積む成長 ②層ごとの硬さと得点 ③残量に依存する成長速度
  • 技術リスク：最も低い。支えも落下も敵も物理も要らず、generateIsland() を段階的に走らせるだけ。今回の実測（世界が毎フレーム変わっても15³で2.20ms）がそのまま素直に効くのはこの方向。
  • 規模感：1週間

11. ひとことメモ / 着想元
