羅生門（Rashomon）

飢饉に沈む荒廃平安京の下層で、堕ちた検非違使が悪鬼と人の業を斬る

保留 京都フルプライス据置ソウルライク平安末 2026-06-26 idea-scout
※ 京都・フルプライス据置スプリントの対抗。死にゲー需要×文学的フック。

1. ログライン（What）

飢饉と疫病で都が腐った平安末期。舞台は朽ちた羅生門、死体の積まれた河原、廃れた寺院。職を失い人を斬って生きる元・検非違使となり、重い間合いの太刀と組み技で人と鬼を斬るソウルライク。斬った相手の「真実」が三者三様に語られ、選んだ解釈で世界が分岐する。

2. コアファンタジー（Why it feels good）

雅な京都の真逆——腐った都で、業を背負いながら生き延びる暗さと強さ。芥川・黒澤の「羅生門＝真実は人の数だけある」という文学的テーマを、死にゲーの緊張感の中で体感する。

3. コアループ（何を繰り返すか）

重い間合いの太刀・組み技で人と鬼を斬る（戦闘）→ 死＝積んだ「業」を落とす（リスク）→ 篝火＝地蔵で休む・回収に戻る（リソース管理）→ 斬った相手の真実が語られ選んだ解釈で世界が分岐（物語進行）→ 武具と業を糧に深部（餓鬼道と化した都）へ（進行）。

4. フック / 新規性（Novelty）

  • いちばんのひねり：ソウルライクという実証済みジャンルに「芥川/黒澤の羅生門」という強い文学的フックを接続。
  • 一目で伝わる引き：死にゲー需要は固く、和風ソウルライクはSekiro系の隣接で市場が温まっている。

5. 市場性（Market）

  • ターゲット：ソウルライク/死にゲーファン、和風高難度アクション層。
  • 参照タイトル：Sekiro系の和風ソウルライク。差別化はテーマ（腐った都・業）と分岐する真実の構造。
  • 収益モデル：フルプライス買い切り。
  • 配信先：PS5/Xbox/PC。
  • 追い風/逆風：追い風＝死にゲー需要は固く市場が温まっている。逆風＝ソウルライクは競合が非常に多く、完成度勝負になりやすい（焼き直し寄り）。

6. 面白さの核（Fun）

  • ジューシーポイント：高難度の間合い読みを制して強敵を倒す達成感。
  • 上達の方向：重い間合いと組み技の熟練、死を重ねての学習曲線。
  • 中毒のフック：斬った相手ごとの三者三様の真実を追い、物語の全体像を掴む欲求。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦に深まるか：武具・業の育成ツリー、周回での真実の見え方の変化。
  • 横に広がるか：都の各層（河原・寺院・宮中崩壊エリア）への拡張。
  • 継続サイクル：真実の分岐を全て見るための周回プレイ。
  • アピールの面：巨大怨霊「餓鬼仏」等のボス絵が強い訴求力を持つ。
  • 天井とリスク：高難度ゆえのプレイヤー離脱リスク。難易度アクセシビリティの設計が必要。

8. 検証すべき最大の賭け（Riskiest Assumption）

ソウルライクとして高難度の緊張感を保ちながら、「真実は人の数だけある」という分岐構造がプレイヤーに伝わるか。最小プロトで1体の敵とその真実の分岐だけを作り検証する。

9. スコープ感

  • 最小プレイアブルに必要な要素（3つ）：①重量級の剣戟戦闘、②死亡時の業ロスト＋篝火システム、 ③真実分岐の物語システム。
  • 技術リスク／未知数：高難度戦闘のバランス調整、分岐物語の実装負荷。
  • 規模感：AAA/AAスコープ。フル開発は複数年級。
