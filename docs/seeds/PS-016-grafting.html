接ぎ木（Grafting）

1本の樹を皆で育て、自分の実だけ太らせる

保留 デジタルボードゲームタイル配置経路フロー対戦 2026-06-26 idea-scout
※ デジタルのボードゲーム的ゲーム。コアループは「1手番で繰り返す意思決定」、面白さは「悩ましさ・読み合い」で読む。

1. ログライン（What）

共有の一本の樹に、プレイヤーが順番に枝タイルを接いでいく。接いだ向きで養分の流れる経路が変わり、養分が通れば自分の果実が成長し、他人の枝に堰き止められれば枯れる。自分の利益のための一手が必ず他人の経路を変える、純度の高い空間の奪い合い（タイル配置×経路フロー）。

2. コアファンタジー（Why it feels good）

皆で一本の樹を育てているのに、本心は自分の実だけを太らせたい。協調を装った利己の駆け引きと、盤面が毎回まったく違う木に育っていく発見の楽しさ。

3. コアループ（自分の手番で繰り返す意思決定）

樹の養分経路を読む（入力）→ 枝タイルを1枚接ぐ（変化）→ 流路が変わり自分/他人の果実の成長が増減する（報酬）→ 次にどこを接げば自分に水が来るか空間を読む（次の意思決定）。この1手番の「経路をめぐる利己と妨害の択」が、得点を外しても面白いか（The Toy Lens）が核。

4. フック / 新規性（Novelty）

  • いちばんのひねり：タイル配置に「共有の単一構造物を全員で奪い合う」相互作用を付与した。
  • 置き換え：各自が自分の盤を作るタイル配置を、一本の樹を奪い合う形に反転した。
  • 盛り上がる瞬間：相手の果実に届く寸前の水を、自分の枝一本で横取りした瞬間。

5. 市場性（Market）

  • ターゲット：相互作用の濃い中量級アブストラクトを好むゲーマー。
  • 参照タイトル：タイル配置×フロー系。差別化は「共有の一本を奪い合う」相互作用の純度。
  • 収益モデル：買い切り（PC/Switch/モバイル）。オンライン対戦も視野。
  • 配信先：Steam／Switch／モバイル。
  • 追い風/逆風：追い風＝相互作用の濃さはゲーマーに刺さる。逆風＝フロー系は既視感（パイプ/水路系）があり、新鮮さは題材側に寄りがち。

6. 面白さの核（Fun = 悩ましさ・相互作用・盛り上がり）

  • 悩ましい瞬間：利己の一手が必ず誰かの水を堰き止める、利己と妨害が常に同義になる択。
  • 上達の方向：数手先の養分の流れを読み、自分に水を引きつつ他人を枯らす経路設計。
  • 盛り上がりのフック：毎回違う木に育つ盤面と、土壇場の横取り。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦に深まるか：枝タイルの種類（分岐・逆流・貯水）を増やせば経路読みが深まる。
  • 横に広がるか：樹の初期形・季節（養分量の変動）・果実の種類で変化を足せる。
  • 継続サイクル：毎回異なる樹に育つリプレイ性が継続を担保。
  • アピールの面：「一本の樹を奪い合う」「毎回違う木」が体験として伝わる。
  • 天井とリスク：終盤に経路が硬直し打てる手が減ると、読み切られて作業化する恐れ。

8. 検証すべき最大の賭け（Riskiest Assumption ／ アナログ固有リスク含む）

終盤、樹が育って経路が固まった後も逆転の余地が残るか。硬直すると読み切られて作業化し、Fun が失われる。最小プロト（デジタル）で1ゲーム通し、終盤の手の選択肢数と逆転発生率を実測する。硬直するなら、逆流・貯水など「固まった流路を覆す枝タイル」を入れて打開できるかを検証する。デジタルなら養分の流れをアニメーションで一目化でき、経路の読みやすさはアナログより有利。（judge 差し戻し論点：経路硬直後の逆転機構の有無）

9. スコープ感

  • 最小プレイアブルに必要な要素（3つ）：①枝タイルと養分経路の判定、②果実の成長/枯死、 ③手番順と勝利条件（CPU相手1体でよい）。
  • 技術リスク／未知数：経路フローを一目で読める養分アニメ表現。終盤硬直のバランス。対戦AIの強さ。
  • 規模感：デジタルプロトは1〜2週間。製品化は中規模。
