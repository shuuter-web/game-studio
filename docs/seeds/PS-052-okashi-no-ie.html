おかしの家

魔女が帰る前に、お菓子の家をタップだけで食べ尽くす

採用 パズルWebタップのみターン制手描き 2026-09-16 claude (Sprint 19 / ユーザー選定)
Sprint 19「売れそう・作りたくなる設定」15案からユーザーが選んだ案。土台は SKETCH VOXEL PUZZLE（prototypes/voxel-puzzle/ v0.1.0）で、v0.2.0 で設定を載せて30ステージにした。

1. ログライン（What）

森の奥の、クッキーの壁とキャンディの窓の家。魔女が帰ってくる前に、タップだけで全部食べ尽くす。 1タップ＝ひとくち＝1ターン。生クリームは毎ターン溢れ、シュークリームは3ターンで破裂し、パチパチキャンディは口の中で弾けて周りごと食べる。口数の上限内に家を消せばクリア。

2. コアファンタジー（Why it feels good）

「食べていい」という背徳と、家一軒を一人で平らげる全能感。手描きの線が沸いているので、お菓子が「描かれた直後」のように瑞々しく見え、かじった破片が床で跳ねる。

3. コアループ（30秒で何を繰り返す？）

盤面を回して見る → どれをかじるか決める → タップ → 連鎖が波ごとに走る（弾ける・崩れる・同じ味が消える）→ クリームが増える／シューが刻みを減らす → 残りと口数を見て次を決める。演出を剥がしても「どこから食べれば少ない口数で全部消えるか」は成立する（solve.mjs で最短口数が出る）。

4. フック / 新規性（Novelty）

  • いちばんのひねり：増えるお菓子（しぼり袋・とけたチョコ）を止める順番が手数を決める。全部壊すゲームに「時間」が入る
  • 既存ゲームの「あれ」を「これ」に：ブロック崩し／マッチ系の「消す」を、3Dボクセルの「かじる」に。裏からはかじれない
  • 30秒トレーラーで絵になる瞬間：パチパチ8個が一周連鎖して家が一気に消える（L30）／とうがらしを先に食べてクリームに埋もれる失敗

5. 市場性（Market）

  • ターゲット：ワンタップ・数分で1ステージのカジュアル層。お菓子の絵で年齢を選ばない
  • 参照タイトル：Pokémon Café Mix／Sweet Escapes 系の「お菓子×パズル」（差別化の一点：3Dボクセルを回して食べる・手描きの沸き）
  • 収益モデル：F2P＋広告（ステージ制）／買い切りも可
  • 配信先：Web（現状）→ Mobile
  • 追い風：お菓子題材は定番で説明不要。逆風：3Dの回転操作はカジュアル層に一段ハードルがある（要検証）

6. 面白さの核（Fun）

  • ジューシーポイント：大口アメを2つ同時になめて5×5×5で家の半分を一口にする瞬間
  • 上達の方向：連鎖の届く範囲を数える／増えるものを先に止める判断／「辛いのは後で」の順序
  • 中毒のフック：お手本口数（par）との差。1口縮める再挑戦

7. 拡張性 / 伸びしろ（Stretch）

  • 縦：口数の星評価、お手本口数の達成率、魔女の帰宅までの「日数」メタ
  • 横：新しいお菓子＝新ギミック。Sprint 18 で整理した8型（壊してはいけない／動く／層／順序／増殖の型／止める／隠す／鏡）がお菓子で全部言い換えられる（割れ物の皿＝壊してはいけない、転がるドロップ＝動く、ケーキの層＝層…）。「1ステージ1新登場、主役ステージ2つ」の並べ方が決まっているので、追加は機械的に進む
  • 継続サイクル：季節の家（クリスマスの氷の家、ハロウィンのかぼちゃの家）
  • アピールの面：家の外観（クッキーの城、チョコの塔、和菓子の茶室）でストア画像が変わる
  • 天井とリスク：手数パズルなので「解が一つで覚えゲー」になりやすい。乱数（クリームの出る場所）で毎回少し違う

8. 検証すべき最大の賭け（Riskiest Assumption）

「3Dを回して裏側を見る」操作が、カジュアル層に成立するか。回さずに解けるステージだけで続くなら3Dの意味が薄い。 → 実機で、回転しないと見えない面にキーのお菓子を置いたステージ（L15 の塔など）の離脱率を見る。

9. スコープ感

  • 最小プレイアブルに必要な要素：ルール（core）／30ステージ（solver で検証済み）／お菓子の記号と説明パネル …… v0.2.0 で揃っている
  • 技術リスク：なし（Canvas 2D、画像アセットなし）。増えるお菓子のステージ設計に「下からかじれない」ルールが要った
  • 規模感：1週間（ここまで1日）。新お菓子1種＋主役ステージ2つで半日
