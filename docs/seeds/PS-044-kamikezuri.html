カミケズリ

紙の塊を削ってお題の形を彫り出す、戻せない一発勝負

却下 彫刻Web/モバイルタップ手描きボクセル創作共有 2026-09-06 producer

1. ログライン（What）

ノートの上に立ち上がった紙のブロック塊から、お題の形——うさぎ、急須、「祭」の一字——を削り出す。削った紙は戻らない。足すのではなく引くことでしか作れない、一発勝負の彫刻ゲーム。

2. コアファンタジー（Why it feels good）

プレイヤーは彫り手。頭の中の形を、取り返しのつかない手つきで世界に固定する。「自分が作った」という満足は他の報酬で代替できず、作品が棚に増えるほど戻ってくる理由になる。

3. コアループ（30秒で何を繰り返す？）

残す形を思い描いて削る面を選ぶ（入力）→ 塊が落ち、紙の白い断面が現れる（変化）→ シルエット一致率が上がる／下がる（報酬）→ 残り手数でどこを落とすか（意思決定）。演出を剥がしても「どこを落とすか」の一手一手に緊張があるかが核。

4. フック / 新規性（Novelty）

  • いちばんのひねり：引き算しかない。Undoなし（1作品につき一度だけ「継ぎ」で戻せる救済のみ）。
  • 置き換え：積むクラフトの創作欲を、削る一方向の不可逆性に置き換えた。慎重さが作品の質になる。
  • 30秒トレーラーで絵になる瞬間：完成した彫刻を回すと、正面・側面・上面の3方向のシルエットが全部お題に合う。

5. 市場性（Market）

  • ターゲット：作って見せたい層。クラフト系を遊ぶが、建てるのは面倒だと感じている人。
  • 参照タイトル：箱庭クラフト全般／彫刻系トイアプリ（差別化の一点：足さずに削る、しかも戻せない）
  • 収益モデル：買い切り＋作品共有。お題パックの追加販売。
  • 配信先：Web / Mobile
  • 追い風：短時間で「作品」が残る体験はSNSと相性が良い。逆風：創作系は上手い人の作品が目立ち、初心者が離脱しやすい。

6. 面白さの核（Fun）

  • ジューシーポイント：大きな塊がごそっと落ちて、形が一気に見えてくる瞬間。
  • 上達の方向：3面図の読み。「この方向から見て要らない」を三次元で同時に判断できるようになる。
  • 中毒のフック：自分の作品棚と、同じお題を他人がどう彫ったかの比較。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦：難しいお題、道具の解放、作品棚、称号。上手い人ほど少ない手数で高い一致率を出せる。
  • 横：お題のテーマ替え（動物／道具／文字／建築）が正解ボクセルデータだけで足せる。制作コストが極小。
  • 継続サイクル：日替わりお題＋他人の作品を見る導線。作品が残るのでプロフィールが育つ。
  • アピールの面：削る過程、3面シルエットが揃う瞬間、作品棚——3枚の絵で語れる。
  • 天井とリスク：採点の納得感がすべて。理不尽な減点が一度でもあると創作意欲が折れる。

8. 検証すべき最大の賭け（Riskiest Assumption）

一致率の採点が納得できるか。機械的な体積一致だと「惜しい」が伝わらず理不尽に感じる。 → お題1つ＋一致率表示だけのプロトを5人に触ってもらい、点数と自分の手応えがずれないかを見る。

9. スコープ感

  • 最小プレイアブル：①正解ボクセルとの一致率採点 ②手数制限 ③作品の保存と閲覧
  • 技術リスク：中。採点設計（体積一致か、3面シルエット一致か、両者の重みづけか）が未知数。
  • 規模感：1週間

11. ひとことメモ / 着想元

手描きの沸き線が「まだ確定していない線」に見えるので、削って形を確定させるという主題と噛み合う。紙という素材設定も style から素直に出てくる。

producer の受け止め: 市場性の指摘（採点する時点で創作ではない）は構造の問題で、調整では消えない。却下に同意する。一方 judge が挙げたもう一つの根拠「15³では うさぎ・急須・『祭』が判別可能にならない」は、 実測で覆る（33³で6.8ms/枚・52fps）。つまりこの種を殺したのは解像度ではなく、 創作を名乗りながら答え合わせをしているという一点。

救済経路（別種として記録）: judge の指摘どおり、この種の中で本物なのは「正面・側面・上面の3方向のシルエットが全部お題に合う」。これは実在する良質なパズル形式で、 答えがあることが正当化される。創作を名乗るのをやめて3面シルエットパズルに振り切れば別種として立つ。 → _raw-seeds-log.md Sprint 12 の追補に記録。
