かたまりノート

紙くずの塊になって島を削り、削るほど自分が大きくなる

採用 アクション成長Web/モバイルタップ手描きボクセル 2026-09-06 producer

1. ログライン（What）

ノートの隅から生まれた紙くずの塊になる。島をタップで削ると、削れた紙片が自分に貼り付いて少しずつ大きくなる。大きくなるほど一度に巻き込める量が増え、さっきまで歯が立たなかった岩盤も、最後には島ごと丸ごと巻き取れるようになる。

2. コアファンタジー（Why it feels good）

小さいものが大きくなり、世界の側が縮んでいく。さっきまで自分を阻んでいたものが、今は単なる材料になる——成長の実感としてもっとも原始的で、もっとも強い形。

3. コアループ（30秒で何を繰り返す？）

削れる場所をタップ（入力）→ 紙片が自分に貼り付き、体が一回り育つ（変化）→ 一度に削れる範囲が広がり、硬い層に手が届く（報酬）→ 次はどの層を食いに行くか（意思決定）。演出を剥がしても「削る→大きくなる→もっと削れる」の三拍子だけで手が動くかが核。

4. フック / 新規性（Novelty）

  • いちばんのひねり：成長と爽快感が同じ量である。自分のサイズが強さで、強さがそのまま一撃の規模。別々に設計する必要がない。
  • 置き換え：転がして集める塊魂の原理を、転がすのではなく削って取り込む操作に置き換えた。
  • 30秒トレーラーで絵になる瞬間：終盤、一撃で島の1/4がまとめて自分に吸い込まれる。

5. 市場性（Market）

  • ターゲット：説明不要の「大きくなる」快感を求める層。年齢を問わない。
  • 参照タイトル：塊魂／Agar.io系（差別化の一点：削って取り込む＋紙という素材）
  • 収益モデル：F2P広告 or 買い切り
  • 配信先：Web / Mobile
  • 追い風：「大きくなる」系は短尺動画との相性が極めて良い。逆風：巨大化ゲームはWebで量産され、飽和気味。

6. 面白さの核（Fun）

  • ジューシーポイント：ワンサイズ上がった直後、さっき削れなかった層がまとめて剥がれる瞬間。
  • 上達の方向：どの順で食えば早く大きくなるか（柔らかい層から効率よく回る経路取り）。
  • 中毒のフック：1ランの到達サイズ。あと一回り、が常に見えている。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦：到達サイズの記録、ラン間の初期サイズ・食べる速度の恒久強化。
  • 横：島テーマを足すだけ（雪・溶岩・都市）。硬さの配置を変えるだけで難易度が作れる。
  • 継続サイクル：1ラン3〜5分＋日替わりの島。到達サイズのランキング。
  • アピールの面：小さい絵と大きい絵の対比だけでトレーラーが成立する。
  • 天井とリスク：サイズが上がりきると単調になる。終盤に「削る対象がなくなる」問題への設計が要る。

8. 検証すべき最大の賭け（Riskiest Assumption）

タップで「巻き込んで大きくなった」実感が出るか。 塊魂は転がす操作だから体が育つのが分かる。タップは離れた場所への指示なので、自分が育った感じにならない危険がある。 → サイズ3段階だけの最小プロトで、段階が上がった瞬間に手応えが変わったと分かるかを見る。分からなければ、操作を「なぞって食う」に変える分岐を先に検討する。

9. スコープ感

  • 最小プレイアブル：①サイズ段階と削れる範囲の連動 ②硬さによる進入制限 ③取り込みの演出
  • 技術リスク：低。範囲破壊は既にあり、サイズで半径を変えるだけ。崩落も敵も不要。
  • 規模感：1週間
