花街立志伝 ―舞を極める妓―

芸を磨き贔屓を集め、名妓へと登り詰める花街の育成RPG

保留 京都Cozy RPG花街育成 2026-07-02 idea-scout
※ 京都×Cozy×RPGスプリント（題材重複OK版）のヒキ強案。Sprint8「置屋の女将」（経営視点）を当人視点の育成RPGに転換した版。文化への敬意（芸＝評価軸）を継承。

1. ログライン（What）

芸事（舞・唄・三味・所作）の熟練を個別に育成し、座敷で気に入られた客を贔屓（後援者）として集める。贔屓の格と芸の熟練で「妓の位（半玉→芸妓→名妓）」が上がっていく、一人称の花街立身RPG。置屋→お茶屋→南座の大舞台・宮中の御前へと道が開く。

2. コアファンタジー（Why it feels good）

「芸を磨き、登り詰めたい」という進行欲と、④名妓への憧れという世界観アスピレーション。稽古で失敗するとぷくっと膨れ、成功で自信ありげに衿を直す。贔屓が増えると簪や衣裳が華やぎ、見た目の成長が可視化される。

3. コアループ（何を集め、何が育つか＝RPGの進行構造）

稽古で芸事（舞・唄・三味・所作）を個別に育成する（練習）→ 座敷に上げて客の趣味・機嫌を読み、手持ちの芸札を正しく選んで座敷を沸かせる（対決代替：座敷のもてなし成否）→ 気に入られた客が贔屓（後援者）として付く（収集）→ 贔屓の格と芸の熟練で妓の位が上がる（進行）→ 位が上がると出られる座敷・習える秘伝の芸が開放される（ゲート解放）→ 季の大舞台では舞のリズム成否で評価が決まる（大目標）。

4. フック / 新規性（Novelty）

  • いちばんのひねり：Sprint8「置屋の女将」の経営視点を、主人公自身の芸熟練ともてなし対決を核にした一人称の立身RPGに転換。花街を「探索」して贔屓と秘伝を集める構造。
  • 一目で伝わる引き：①登り詰める進行欲＋④名妓への憧れという強い世界観訴求。

5. 市場性（Market）

  • ターゲット：育成×立身RPG層、和風世界観・花街モチーフ好き層。
  • 参照タイトル：育成経営シムの一人称版。差別化は「主人公自身が芸を極める」視点の転換。
  • 収益モデル：買い切り。
  • 配信先：Switch/PS/PC。
  • 追い風/逆風：追い風＝育成＋憧れの世界観は商業的に強い。逆風＝舞妓・花街の題材は全世界向けに文化的配慮が特に必要（戯画化・不正確な扱いを避ける設計が必須）。

6. 面白さの核（Fun）

  • ジューシーポイント：座敷でもてなしが的中し、客が沸いて贔屓が付く瞬間。
  • 上達の方向：客の趣味・機嫌を読み、芸札を正しい順で選ぶ座敷の読み合い。
  • 中毒のフック：妓の位が上がるたび解放される新しい座敷・秘伝の芸。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦に深まるか：芸事ごとの熟練ツリー、秘伝の芸の収集。
  • 横に広がるか：置屋→お茶屋→南座→宮中と、格上の舞台への段階的拡張。
  • 継続サイクル：贔屓との関係進行、季ごとの特別公演イベント。
  • アピールの面：簪や衣裳が華やぐ成長の可視化、南座の大舞台の一枚絵。
  • 天井とリスク：文化的配慮を欠くと国内外で強い反発を招くリスクが最も高い題材。芸＝評価軸を一貫させ、容姿でなく技芸の上達を評価の中心に据える設計が不可欠。

8. 検証すべき最大の賭け（Riskiest Assumption）

「座敷のもてなし成否」が、客の趣味・機嫌を読む戦略性を持ちながら、文化的に敬意ある表現として成立するか。最小プロトで客1パターン・芸札3種を作り、対決の手応えと表現の適切さを検証する。文化アドバイザーの監修も要検討。

9. スコープ感

  • 最小プレイアブルに必要な要素（3つ）：①芸事の個別熟練育成、②座敷のもてなし成否システム、 ③贔屓収集と妓の位進行。
  • 技術リスク／未知数：文化的表現の適切さの担保（監修体制含む）。
  • 規模感：コアプロトは数週間。フル開発は中規模。文化考証コストを見込む必要。
