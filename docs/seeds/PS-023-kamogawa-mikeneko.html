鴨川デルタの三毛猫便り

京都の路地に暮らす猫になり、人の落とし物を届けて縁を結ぶ

保留 京都Cozy据置猫探索 2026-06-26 idea-scout
※ 京都×Cozyスプリントの本命。生活シム（単発お使い）として設計。RPG進行版は PS-025「猫の縁結び」参照。

1. ログライン（What）

主人公は鴨川界隈に暮らす一匹の三毛猫。住人が落とした手紙・お守り・忘れ物を見つけ、手がかりから持ち主を推理して届ける。届けるたびに路地の人々と縁が深まり、四季と時間で街の表情と届け物が移ろっていく、猫目線で京都の暮らしを歩くCozyゲーム。

2. コアファンタジー（Why it feels good）

「京都の猫になって路地を歩きたい」という没入と憧れ。塀の上、縁の下、川辺——人には入れない京都の隙間を、気ままに、しかし人の役に立ちながら歩く。届けると人が「あらまあ」と笑う、小さな善行の連鎖が積み重なる充足。

3. コアループ（何を繰り返すか）

路地・川辺・縁側を歩いて落とし物や困りごとを見つける（探索）→ 誰のものか手がかりから推理する（判断）→ 届ける（実行）→ 住人がお礼にごはん・昼寝場所・新しい路地を開いてくれる（報酬）→ 四季と時間で街の表情と届け物が変わる（反復の変化）。

4. フック / 新規性（Novelty）

  • いちばんのひねり：経営でも内装でもない、唯一「暮らす側」に振ったCozy。プレイヤーは人間でなく猫。
  • 置き換え：Strayの「猫として街を歩く」没入と、京都の路地・縁側という舞台を接続した。
  • 一目で伝わる引き：縁側で丸くなる猫、塀の上を歩く猫——「これになりたい/撮りたい」と一目で動く。

5. 市場性（Market）

  • ターゲット：Cozy/スローライフ層＋猫ゲー人気層（Stray購買層の隣接）。全年齢・全世界。
  • 参照タイトル：Stray（猫の没入）× 京都の暮らし。差別化は「猫視点で人の縁を結ぶ」お使い構造。
  • 収益モデル：買い切り（プレミアムインディー〜フルプライス級）。
  • 配信先：Switch/PS/Xbox/PC。
  • 追い風/逆風：追い風＝猫ゲー・Cozy・和風はいずれも強い個別市場で掛け算が効く。逆風＝お使い構造だけだと単調化しやすく、進行の起伏が要る。

6. 面白さの核（Fun）

  • ジューシーポイント：塀の上・縁の下から見る京都の景色と、猫の歩き・伸び・毛づくろいの可愛い挙動。
  • 上達の方向：手がかりから持ち主を推理する観察眼、路地の地理を覚えて効率よく届ける動線読み。
  • 中毒のフック：新しい路地が開くたびに広がる街と、住人との縁が深まっていく小さな物語。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦に深まるか：住人ごとの長期エピソード（季節をまたぐ縁）、猫自身の縄張り・仲間猫との関係。
  • 横に広がるか：祇園・嵐山・伏見など京都の別エリアへ拡張。四季・年中行事イベント。
  • 継続サイクル：季節ごとに変わる届け物と街の景色。実績としての「縁の図鑑」。
  • アピールの面：縁側の猫、屋根を歩く猫のスクリーンショットがそのままSNS映え・拡散素材になる。
  • 天井とリスク：お使いのバリエーションが尽きると作業感が出る。縁の深まりや小さな謎解き性で単調化を防ぐ設計が要る。

8. 検証すべき最大の賭け（Riskiest Assumption）

「猫としての移動・観察」そのものが、届け物の報酬なしでも触って楽しいか（The Toy Lens）。最小プロトで猫の移動アクション（歩く・伸びる・跳ぶ・毛づくろい）だけを作り、目的なしで 5分歩き回りたくなるかを検証する。ここが弱いとお使いの繰り返しだけの単調なゲームになる。

9. スコープ感

  • 最小プレイアブルに必要な要素（3つ）：①猫の移動アクション、②落とし物発見と推理UI、 ③届けた際の住人リアクションと縁の進行。
  • 技術リスク／未知数：猫視点での立体的な街歩き（塀・屋根の縦移動）の操作性。
  • 規模感：コア移動プロトは数週間。フル開発は中〜大規模（オープンな街の作り込み量に依存）。
