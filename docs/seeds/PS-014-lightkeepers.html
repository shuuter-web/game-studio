灯台守の夜（Lightkeepers）

霧の夜、見えない船を「光の角度」で奪い合う

保留 デジタルボードゲームエリアマジョリティ対戦PC/Switch/モバイル 2026-06-26 idea-scout
※ デジタルのボードゲーム的ゲーム。コアループは「1手番で繰り返す意思決定」、面白さは「悩ましさ・読み合い・盛り上がり」で読む。

1. ログライン（What）

霧の立ちこめる夜の海で、プレイヤーは各自の灯台を回し、扇形に海面を照らす。照らしたマスにいる船トークンが自分の得点に傾くが、領域は固定マスでなく毎手番ぐにゃりと動く。隣の灯台と光が重なれば船は分配され、空白を独占すれば総取り。盤面の支配が常に流動する、光の角度の奪い合い（エリアマジョリティ）。2〜4人・30〜60分。

2. コアファンタジー（Why it feels good）

霧の海を統べる灯台守として、見えない航路を一筋の光で照らし出し、相手の隙を突いて船団をかすめ取る読みの快感。自分の一回しで海の支配図がぐにゃりと変わる手応え。

3. コアループ（自分の手番で繰り返す意思決定）

盤の船配置と各灯台の向きを読む（入力）→ 自分の灯台を1方向へ回す（変化）→ 照らした扇内の船が得点に傾く（重なれば分配）（報酬）→ 次手番、どの方角に賭けて回すか布石を読む（次の意思決定）。この1手番の「角度の読み合い」自体が、得点ルールを外しても面白いか（The Toy Lens）が核。

4. フック / 新規性（Novelty）

  • いちばんのひねり：エリアマジョリティの支配領域を「回転する扇」にして、盤面の支配が常時流動する。
  • 置き換え：固定エリアの陣取りを、毎手番形が変わる動的な光の領域に変えた。
  • 盛り上がる瞬間：終盤、密集した大船団を1手の回転で丸ごと奪う逆転。

5. 市場性（Market）

  • ターゲット：中量級の陣取り・アブストラクト寄りを好むボードゲーマー。
  • 参照タイトル：エリアマジョリティ系。差別化は「支配領域が回転で常時動く」一点。
  • 収益モデル：買い切り（PC/Switch/モバイル）。オンライン対戦・非同期対戦も視野。
  • 配信先：Steam／Switch／モバイル。
  • 追い風/逆風：追い風＝動的マジョリティは稀で新規性が立つ。デジタルなら扇の重なりを画面が自動可視化でき、アナログ最大の難点（計算待ち）が消える。逆風＝自動計算で悩ましさまで消えると作業化する。

6. 面白さの核（Fun = 悩ましさ・相互作用・盛り上がり）

  • 悩ましい瞬間：隣の灯台と「重ねて潰すか／空白を独占するか」の択が毎手番突きつけられる。
  • 上達の方向：数手先の各灯台の向きを予測し、最も船が傾く角度を読む先読み力。
  • 盛り上がりのフック：終盤の大逆転と、狙った独占がハマったときの快。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦に深まるか：灯台ごとの非対称能力（扇が広い/狭い、二方向照射）で読みの深度が増す。
  • 横に広がるか：海図（船配置パターン）・潮流による船移動・霧で見えない隠匿マスの追加。
  • 継続サイクル：ボードゲームなのでリプレイ性＝海図のバリエーションと対戦相手で担保。
  • アピールの面：「回る光」「動く陣地」「終盤の総取り逆転」が体験として一言で伝わる。
  • 天井とリスク：能力やギミックを盛るほど幾何認知が重くなる。拡張しても「扇は一目で読める」を守る。

8. 検証すべき最大の賭け（Riskiest Assumption）

デジタルなら扇の重なり・分配は画面が自動で可視化・計算できるので、アナログ最大の難点（計算待ち）は消える。代わりの賭けは「自動計算しても悩ましさが残るか」＝最適手が一目で見えてしまい作業化しないか、そしてCPU／オンライン相手との読み合い（次にどの方角へ回すかの駆け引き）が成立するか。最小プロト（デジタル）で、重なりをリアルタイム表示した状態でも「重ねて潰すか／独占するか」の択が悩ましいまま残るかを実測し、自明化するなら情報を一部隠す（相手の次手を読ませる）等で緊張を保てるか比較する。

9. スコープ感

  • 最小プレイアブルに必要な要素（3つ）：①回転する灯台と扇の照射範囲、②船配置と得点の傾き/分配のリアルタイム可視化、③手番順と勝利条件（CPU相手1体でよい）。
  • 技術リスク／未知数：扇の重なり判定と得点プレビューのUI設計。読み合いが成立する対戦AIの強さ。
  • 規模感：デジタルプロトは1〜2週間。製品化は中規模。
