おおぐらい

島の獣になり、食べるほど壊し方の種類が増える

却下 アクションローグライトWeb/モバイルタップ手描きボクセル 2026-09-06 producer

1. ログライン（What）

島に棲む腹ぺこの獣になる。街を壊して食べると技を覚える——噛みつき（1点）、尻尾払い（横一列）、ブレス（貫通）、踏み潰し（真下の柱ごと）。技が増えるほど、壊れ方の形そのものが変わる。

2. コアファンタジー（Why it feels good）

怪獣になって街を壊す。しかもただ暴れるのではなく、手数が増えていくことで暴れ方が豊かになる。できることが増える喜びと、壊す痛快さが同じ方向を向いている。

3. コアループ（30秒で何を繰り返す？）

今ある技のどれで、どこを壊すかを選ぶ（入力）→ 技ごとに違う形でブロックが吹き飛ぶ（変化）→ 食べた量で次の技が近づく（報酬）→ 新しい技をどこで試すか（意思決定）。

4. フック / 新規性（Novelty）

  • いちばんのひねり：成長が量ではなく種類。強くなるのではなく、壊し方の語彙が増える。
  • 置き換え：怪獣ものの破壊を、技ごとにボクセルの削れる形が違うという一点に集約した。
  • 30秒トレーラーで絵になる瞬間：4つの技で街が4通りの形に崩れるカット割り。

5. 市場性（Market）

  • ターゲット：怪獣・破壊もの。説明が一切要らない題材。
  • 参照タイトル：Rampage系／怪獣ゲーム全般（差別化の一点：技＝削れる形。見た目でなく挙動で技を分ける）
  • 収益モデル：F2P広告 or 買い切り
  • 配信先：Web / Mobile
  • 追い風：怪獣題材は普遍。逆風：Rampage的な既視感が強く、新規性で語りにくい。

6. 面白さの核（Fun）

  • ジューシーポイント：新技の初撃。今までと違う形で街が崩れる。
  • 上達の方向：技の使い分け。柱にはブレス、屋根には尻尾、という読み。
  • 中毒のフック：技のアンロック。次に何が来るかが見えている。

7. 拡張性 / 伸びしろ（Stretch）

  • 縦：技ツリー、獣の種類（技セットが違う）、階層。
  • 横：街の構造を足すだけ。技と構造の掛け算でコンテンツが増える。
  • 継続サイクル：ランごとに引ける技が変わるローグライト＋日替わり。
  • アピールの面：技ごとに絵が違うので、素材の枚数が自然に増える。
  • 天井とリスク：技が増えても壊れる絵が同じなら成長は感じられない。技ごとの削り形の差が命綱。

8. 検証すべき最大の賭け（Riskiest Assumption）

技が増えることが、本当に爽快感の増加になるか。 削れる形が違うだけで、壊した量も感触も同じなら、技は名前が違うだけのボタンになる。 → 技3種（点・線・貫通）だけの最小プロトで、壊れ方の違いが操作の楽しさの違いになっているかを見る。

9. スコープ感

  • 最小プレイアブル：①技ごとの削り形 ②食べた量による解放 ③技の切り替えUI
  • 技術リスク：低。範囲破壊の形を変えるだけで、崩落も敵も不要。
  • 規模感：1週間

11. ひとことメモ / 着想元

3条件のうち「成長」を種類の増加で解いた案。量（PS-049）・数字（PS-048）と対になる第三の軸として発散したが、新規性で明確に落ちる。技＝削り形という発想だけは他案に移植できる。

judge が「保留ですらなく却下」とした理由は構造的:

種類は、エスカレーションではない。 今回のお題は自ら「爽快は減衰するので破壊の単位が育つ必要がある」と定義した。4番目の技は1番目より強くない、違うだけ。つまりこの案は、実装が完璧に成功して技ごとの削り形が理想的に違っても、このスプリントの前提条件を満たせない。プロトを作って確かめるまでもなく答えが出ているので、保留ではなく却下。
