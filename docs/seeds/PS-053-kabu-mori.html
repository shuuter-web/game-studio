カブ盛りバブル（仮）

頭のカブタワーで相場を張る、押し付け合いすごろく

保留 パーティすごろく2-4人相場オンライン/ローカル 2026-10-15 claude (ユーザー持ち込みお題の展開 / 2026-10-15)
ユーザー持ち込みのお題「どうぶつの森っぽいIP × カブ × すごろく。突然変異カブの大発生、空前のカブ取引ブーム。カブを頭に積んで移動。爆発カブの押し付け合い、有望カブの取り合い。すごろくはシンプルに、相場読みは数字最小で」を展開した。「どうぶつの森っぽい」は雰囲気（動物の住人・のんびりした島・季節）を借りるだけのオリジナルIPとする。実在作品の固有名詞（通貨名・カブ売りのキャラ・「カブ価」等の用語）は使わない。

1. ログライン（What）

流れ星の夜を境に、島のカブが次々と突然変異した。光るカブ、歌うカブ、膨らみ続けるカブ。住人たちは「カブを頭に盛って歩く」のが大流行中で、頭上のカブタワーがそのまま自分の持ち株。サイコロで島を回り、市場で売り買いし、すれ違った相手にヤバいカブを押し付け、有望なカブをひったくる。シーズン終わりにいちばん稼いだ住人が勝ち。

2. コアファンタジー（Why it feels good）

のんびりした島で、バブルに踊る投機家になる。可愛い見た目のまま欲と駆け引きをむき出しにできるギャップと、「みんなが売り抜けた後に爆上がりした」「押し付けた爆弾カブが相手の頭で破裂した」という他人を出し抜く快感。

3. コアループ（30秒で何を繰り返す？）

サイコロを振る → 移動中にすれ違った相手の頭へ自分のてっぺんのカブを押し付けるか、相手のてっぺんを奪うかを選ぶ → 止まったマスで「市場で売る／畑で抜く（買う）／イベント」 → 全員の頭を見て、次にどの種類が上がるか読む。

成立の核は4つのルールだけ：

  1. カブは上からしか出し入れできない（頭の上は積み木。売るのも渡すのも、いちばん上から順番）。爆弾カブが途中に埋まると、その下のカブは売れない＝積む順番が戦略になる。
  2. 値段は数字でなく、市場の看板の顔5段階（😱→😐→🙂→😄→🤩）。
  3. 相場は需給で動く：全員の頭に乗っている数が多い種類ほど下がる。頭上は公開情報なので、みんなの頭を見れば相場が読める（数字を見る代わりに、人を見る）。
  4. 背が高いほどぐらつく。風マス・段差マスで高すぎるタワーは上半分が崩れてマスに散らばり、誰でも拾える。

4. フック / 新規性（Novelty）

  • いちばんのひねり：ポートフォリオが頭の上に積まれて全員に見えている。持ち株・需給・順番・リスクが1本のタワーに全部出る
  • 既存ゲームの「あれ」を「これ」に置き換えた：株ボードゲームの「株券と価格表」→「頭のカブタワーと看板の顔」
  • 30秒トレーラーで“絵”になる瞬間：天まで届きそうなカブタワーで橋を渡る住人／風マスで崩れて広場にカブの雨／押し付けた爆弾カブが相手の頭で「ポンッ」とはじけてタワーが四方に飛ぶ

5. 市場性（Market）

  • ターゲット：家族・友人と遊ぶパーティゲーム層、配信者（崩落と爆発が配信映え）、まったり系IPのファン
  • 参照タイトル：すごろくパーティ系、株・相場系ボードゲーム（差別化の一点：数字の表を読まずに、人の頭を見て相場を読む）
  • 収益モデル：買い切り＋季節パック（新しい突然変異カブ・島）
  • 配信先：Switch系コンソール / Steam / モバイル（オンライン対戦）
  • 追い風/逆風：まったり動物IP需要は根強い。逆風は「どうぶつの森っぽさ」が強すぎると模倣に見える点 → 動物以外のフック（カブタワー）を前面に出す

6. 面白さの核（Fun）

  • ジューシーポイント：満面の🤩看板の前で、高く積んだ同種カブを上から一気に売り抜ける瞬間／爆弾の押し付け成功
  • 上達/深まりの方向：積む順番の管理、他人の頭から需給を読む、「みんなが持ってる＝下がる」の逆張り、うわさの真偽判定
  • 中毒のフック：毎回カブの種類と順番がバラけて展開が違う。負けても「あの時売っていれば」が明確

7. 拡張性 / 伸びしろ（Stretch）

  • 縦に深まるか：突然変異カブ図鑑のコンプリート、住人ごとの小さな能力差、ランク戦
  • 横に広がるか：突然変異カブの種類＝コンテンツ。季節ごとに新種（夏：花火カブ、冬：雪だるまカブ）を足せる。島の形・市場の店主も差し替え可能
  • 継続サイクル：季節イベント（週替わりの「流行カブ」）、図鑑、オンラインの短いシーズン
  • アピールの面：タワー・爆発・崩落・図鑑・季節衣装と複数の絵が切れる
  • 天井とリスク：カブの種類を増やしすぎると「覚えること」が増え、数字最小の良さが死ぬ。1試合に出る種類は4〜6に絞る

8. 検証すべき最大の賭け（Riskiest Assumption）

「頭を見て相場を読む」が本当に駆け引きになるか。需給で値が動くだけだと全員が同じ判断をして平坦になる恐れがある。 → 最小プロト：カブ4種・看板5段・需給ルール・うわさカード（自分だけ見える「◯◯カブが来週上がるらしい」）だけの 4人ホットシート版で、「売り時がプレイヤーごとに割れるか」を見る。押し付け・崩落はその後。

9. スコープ感

  • 最小プレイアブルに必要な要素（3つまで）：①上からしか触れないカブタワー ②需給で動く顔5段の相場 ③すれ違いの押し付け/ひったくり
  • 技術リスク / 未知数：技術は軽い。リスクはバランス（需給の感度、爆弾の頻度）とオンラインの手番テンポ
  • 規模感：ルール検証は1日試作（単一HTML）、本制作はパーティゲーム級
