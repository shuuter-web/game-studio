# Voxel Mine v0.5.0 大木とデバッグメニュー

## 木の種類

樹木は地形セルとは別の個体とし、`kind` で `sapling`（若木）と `large`（大木）を区別する。若木は従来の形と伐採時の木材2個を維持する。大木は1セル幅の木ブロックを3段、葉ブロック14個を組み合わせた樹冠で描く。各ブロックに固定IDを割り当て、タップした1ブロックだけを燃料1で除く。幹ブロックは木材2個、葉ブロックは報酬なし。全17ブロックを除いた時だけ大木1本の伐採完了として記録する。範囲強化は大木に適用しない。

出航時に若木6本と大木2本を決定的に配置する。生き物や他の木と足場セルを共有せず、木が足場ごと壊れた場合は倒れた扱いにする。描画は既存のワールド座標投影、面の奥行き順、手描き輪郭を共用し、地形の素材や発見物抽選には触れない。

## 保存と移行

保存形式v6では木の種類・位置・伐採済み・倒木状態に加え、大木で除去済みのブロックIDを保持する。v5の未伐採大木は全ブロックあり、伐採済み大木は全ブロック除去済みとして移す。v4の木はすべて若木として読み、探索中なら大木を決定的に補う。再読込で削ったブロックや木材が復活・重複しない。v1〜v3の移行、旧v4の木が空だった遠征の補充も維持する。

## デバッグメニュー

港・探索中・リザルトから共通のメニューを開く。対象となる現在の世界の種と通常/独立テストのセーブ枠を表示し、「セーブデータを初期化」を確認した場合に限り `resetGame()` を実行する。初期化対象は `saveKey()` の枠だけとし、ほかの世界や通常/独立テストの枠は保持する。再読込しても初期状態を維持する。

## 生き物の輪郭

立体パーツごとに、カメラから見た投影外周だけを太い揺れる線で描く。隣り合う面が共有する内側の線は細く抑える。太い線幅は地形ブロックと共通の計算を使う。視点回転による外周の変化は描画だけに限定し、捕獲位置・燃料・乱数列・保存状態を変えない。
