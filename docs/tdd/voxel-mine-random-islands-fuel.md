# Voxel Mine ランダム島・燃料表示 TDD

## 目的

出航のたびに未知の島へ向かう感覚を作り、採掘可能回数を表す燃料を常に判断しやすくする。燃料切れは即座に画面を切り替えず、帰還する理由をプレイヤーへ伝えてから遠征結果へ進める。

## 地形生成

- 島の生成種は世界種・行き先・遠征通番から作る。
- 新しい出航では遠征通番を進め、同じ行き先でも地形、木、生き物の配置を変える。
- 探索中のセーブには生成済みセルを保存し、再読込では同じ島と採掘状態を復元する。
- `?seed=` は一連の出航を再現できるよう、決定的な乱数生成を維持する。

## 燃料表示と帰還

- 探索中は画面上部中央に残量数値と横長ゲージを表示する。
- 残量が少ないと警告色、0では空状態の色へ切り替える。
- 最後の燃料を消費した処理と連鎖報酬を完了してから、操作を遮る帰還メッセージを表示する。
- メッセージは「燃料がなくなった。帰還しよう。」とし、確認操作の後にリザルトへ移行する。
- 帰還メッセージ表示中の状態を保存し、再読込後も同じ段階から再開する。

## セーブ互換

セーブ形式を v7 とし、帰還メッセージの確認状態を追加する。v1〜v6は未確認として補完し、既存の所持品、強化、島の途中状態を維持する。
