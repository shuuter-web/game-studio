# Voxel Mine v0.3.0 技術設計

## レビューと境界

2026-09-22、producerとtech-leadのレビューを経て単一HTMLの既存描画を維持する。ゲーム実装はindex.html、検証はverify.mjs、設計は本書とGDDに分離して担当する。

地形定義 `MATERIALS` とアイテム定義 `ITEMS` を分ける。地形の土・石を在庫に入れず、工作用の新素材・既存鉱石・換金品を所持品カタログで扱う。通貨は所持品とは別の `player.coins` とし、コスト計算では共通のhave/spendを通す。

## 採掘と抽選

破壊ごとの抽選は、世界seed・行き先・遠征通番・セルIDに対する決定的なhashで行う。抽選表はデータ化し、無発見も含める。発見物にはコンボ倍率を掛けないため、処理順序・範囲・連鎖のフレーム刻みで結果が変わらない。鉱石の報酬倍率は維持する。

遠征通番は成功した出航のみで増加する。再読込・リザルト表示・売却では増やさない。

## 生き物

出航時にセル表面へ決定的に配置する。論理状態は個体ID、種類、足場セル、捕獲済み状態を持つ。描画アニメーションは見た目だけで、論理位置や報酬の乱数列を変えない。

採掘と捕獲で行動開始ガードを共有し、探索中・燃料あり・保留連鎖なし・帰還中でないことを検査する。個体の存在と画面上の可視性を確認してから燃料1とターン1を消費する。捕獲済みの個体は二重取得できない。

足場破壊後は残存する足場へ決定的に移し、足場が完全になければ逃走扱いとする。投影位置と地形の深度を用い、島の裏に隠れた個体を描画・捕獲できないようにする。

## リザルトと換金

状態遷移は `base → exploring → result → base`。任意帰還・燃料0・島を掘り尽くした場合、最後の連鎖処理を待ってresultへ移行する。リザルトは遠征中に確定した獲得物・捕獲数・採掘数・燃料使用量・終了理由を表示するだけ。確認ボタンは港への遷移のみで報酬を付与しない。

換金は港の明示的な売却操作で行う。今回の仕様ではリザルトで自動換金しない。換金品だけを減算しコインを加算して即保存する。素材は売らない。リザルトには「売却見込額」と表記し、所持コインと区別する。

## セーブv3と移行

v3は通貨、遠征通番、個体状態、リザルト状態と集計を保存する。保留連鎖と相対時刻の既存保存も維持する。

v1/v2を旧IDで検証してから土+石を1個につき新素材1個へ換算する。在庫と遠征haulをそれぞれ変換し、haulを在庫へ二重加算しない。装備・航路・容量を保持する。v2遠征中は燃料・地形・損傷・保留連鎖を復元する。移行中の遠征には生き物を追加せず、次の出航から配置する。

v3検証ではphase別のpending整合、非負整数の通貨/通番/集計、個体ID重複・足場範囲・種類・状態を検査し、検証成功後だけ実状態へ適用する。

## 進行保証と検証

初回つるはし・タンク・航路をコインで強化可能にし、保証配置の生き物から得た換金品を売れば最初の強化へ到達できるようにする。無料出航・補給を維持する。その他の旧土・石コストは新素材へ差し替える。

QAは旧回帰を更新し、確率ドロップ/無発見、抽選再現、個体の事前配置と再読込、二重捕獲、港限定換金、最終燃料の捕獲、連鎖帰還、result保存・再表示、旧土石変換、スマホ表示を検証する。
