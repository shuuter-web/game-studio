Seed Sprint 12 / Pitch

けずるゲームの企画
— SKETCH VOXEL から何を作るか

手描きの線が沸き続ける3Dボクセルを、タップで壊す試作 SKETCH VOXEL ができた。 削って断面が覗く瞬間はすでに気持ちいい。足りないのは、その快感の行き先だけだ。

この文書は「これを土台に長く遊べるゲームを作るなら何か」を12案発散し、 中立の判定を通したうえで、残った3案とその賭けをまとめたもの。

2026-09-06 producer / greenlight-judge 種：PS-043〜047 の全文

01土台にあるもの、無いもの

企画の実現コストは、この一覧との距離でほぼ決まる。試作が持っているのは、 ボクセルグリッド／露出面の算出／画家アルゴリズム／沸く手描き線／破片物理／面のタップ判定／範囲破壊／シード生成。 持っていないのは、設置・支えと落下・材質の硬さ・敵・時間圧。

重要なのは、この試作が「世界は静止していて、タップの瞬間だけ変化する」前提で最適化されていること。 線の沸きは1秒に10回、島の全面を引き直すことで成立していて、キャッシュで誤魔化せない。 つまり動き続けるもの・崩れ続けるものは、この設計の真正面の敵になる。 以下の3案の順位は、ほぼこの一点で決まっている。

2026-09-06 追記・この段落は訂正されている 上の「崩れ続けるものは真正面の敵」は、その後の実測で言い過ぎだと分かった。 世界が毎フレーム変わっても 15³で2.20ms／33³で7.37ms（60fps予算16.6msに対し13%／44%）で、 大量破壊も連続崩落も性能面では成立圏内。解像度がそのまま予算になる。 この訂正で、下の3案の順位づけの根拠の一部は無効になっている。 内訳と留保は 次の企画（Sprint 13） にある。

02「長く遊べる」の作業定義

そのまま発散すると案がぼやけるので、先に分解した。リテンションには型が5つあり、 どの型で引っ張るかを各案が宣言する（型ゼロは失格）。

型引っぱり方この土台との相性
① 毎回違う生成・ローグライトシード生成が既にある
② 積み上がるコレクション・メタ進行破片が既に素材を運んでいる
③ 上手くなるスキルの天井・記録更新指標の設計しだい
④ 見せ合える共有・非同期対戦・ランキング基盤が要る＝スコープ外になりやすい
⑤ 終わらない仕事箱庭・世界が育つ静止した世界と相性が最良

03残った3案

本命

けずり町

PS-047 全文 → 型 ⑤ 箱庭 ＋ ② 積み上がる

島をタップで削ると、草・土・石・結晶が破片になって手元に入る。その素材だけで島の上に町を建てる。 素材はどこからも湧かない——置いた1ブロックは、必ずどこかに開けた穴の対価。 町が育つほど、足元の島が痩せていく。

入力どこを削るか選んでタップ
変化破片が飛び、島に穴が空く
報酬素材が増え、置ける物が解放される
意思決定何を建てるか／そのためにどこを削るか

削るだけで楽しいことは試作で確認済み。この案はその出力に行き先を付けるだけ。

ひねり
素材が湧かない閉じた系。クラフト系は普通どこかで無限に湧くが、この島は有限。集める作業を、実証済みの「削る快感」そのものに置き換えている。
絵になる
町が完成した島を回すと、裏側が穴だらけになっている。
差別化
参照は Minecraft／Townscaper。差の一点は「建設が土地の消費と直結している」こと。クラフト系が持っていない緊張で、しかも一目で伝わる。
スコープ
技術リスク低・1週間。支え・重力・敵・時間圧のいずれも不要で、土台の描画前提を壊さない唯一の伸ばし方。破片は既に素材の種別を運んでいるので、在庫化はその延長で足りる。
採点
自己 Fun 3 / Market 4 / Novelty 4 = 11（中立判定は未実施。この案は判定の講評から生まれた）
検証すべき最大の賭け 削る快感と置く満足が、本当に1本のループで繋がるか。 素材の受け皿を付けただけで、削る側が「作業」に格下げされる危険がある（今は目的がないからこそ自由で気持ちいい）。 素材3種＋置ける物3種だけの最小プロトで、削るのをやめて置きたくなる／置くために削りたくなる 往復が自然に起きるかを見る。起きなければこの案は全部崩れる。 第二の賭けは「島が痩せること」が罰ではなく緊張として機能するか。
対抗

ホリホリ発掘帖

PS-043 全文 → 型 ② コレクション

岩塊をタップで削ると、断面に色の違うボクセルが覗く。埋まっているのは骨か、土器か、鉱石か。 標本そのものを叩けば罅が入って価値が落ちる——「壊す」と「壊さない」を同じタップに載せた発掘ゲーム。

入力削る位置を決めてタップ
変化断面に標本の端が覗く
報酬/罰露出で加点、当てると罅
意思決定次にどこを削るか／道具を替えるか

構造としてはマインスイーパ型（露出して情報を得る／当ててはいけないものがある）。強い血統。

ひねり
破壊ゲームなのに壊してはいけないものが中にある。同じタップが得点にも失点にもなる。
絵になる
最後の一片が落ちて、埋まっていた全身が手描きの線ごと現れる。
強み
4案中これだけが実証済みの快感の上に建っている。試作で一番良かった「削ると結晶の脈が覗く」瞬間を主役に据え、覗くことに理由（標本）と、覗きすぎることに罰（罅）を与えて、快感を意思決定に変換している。
弱点
差別化点である「無傷率」がストアの1枚目で見えない。低品質な発掘アプリが量産され、識別性が生死を決めるカテゴリで、識別されない差別化は市場性に計上できない（判定の指摘）。
スコープ
技術リスク低・1週間。崩落物理を必要としない。床が最も高い＝1週間で本当に存在する状態になる唯一の案。
採点
判定 Fun 4 / Market 3 / Novelty 3 = 10（自己採点 11、市場性 −1）
検証すべき最大の賭け（差し戻し済み） 起案時は「慎重に削るのが退屈にならないか」としていたが、判定でこれは下流と指摘された。 先に死ぬのは断面から埋蔵物を推理できるか（情報の可読性）で、読めなければ推理は当て推量に退化し、 退屈は自動的に確定する。固定標本を1体埋めて断面を見るだけの1時間の確認で潰せる。
次点

けしけし団

PS-045 全文 → 型 ① ローグライト ＋ ③ 上手くなる

授業中のノートから落書き妖怪が立体で膨れ上がり、机を侵食してくる。武器は消しゴムひとつ。 タップで妖怪の体を削り取って消す——敵にHPバーはなく、体力＝体積。

入力支えになっているブロックを狙ってタップ
変化上半身ごと崩れる
報酬撃破点
意思決定どこを抜けば一番大きく崩れるか
ひねり
HP＝体積。どこをどう削ったかがそのまま強さになる。物量アクションの殲滅感を、数値ではなく体を物理的に削る操作に置き換えた。
強み
識別性が3案中最大。ノートの落書きという設定が、手描きスタイルを飾りではなく必然に変えている唯一の案。10秒の動画で一目で伝わる。
スコープ
技術リスク高。起案時は「中・1週間」としていたが、これは誤り。この案は次項の解体パズルの崩落システムを丸ごと含んだうえに、敵の湧き・移動・接近を足したもので、厳密により重い。さらに動く敵は島のキャッシュを毎フレーム壊し、全グリッド走査を誘発する。3案中もっとも重い。
採点
判定 Fun 3 / Market 4 / Novelty 3 = 10（自己採点 12、面白さ −1・新規性 −1）
検証すべき最大の賭け 問い自体は正しい（体積を削る戦闘が、ただの連打を超えるか）が、順番が違う。 先に崩落と移動する敵が、この描画設計で必要な速度で動くかを通さないと、戦闘が存在せず問いに到達しない。

もうひとつ、起案時にあった第二軸「削るほど消しカスが積もり、カスが次の敵を育てる」は、 売り文句の爽快感と正面から利害対立する。軽ければ飾りとして死に、重ければ 「殲滅が気持ちいい」と売ったゲームが殲滅を罰することになる。カスを捨てて体積HP一本に絞るのが妥当。

04解像度の値段（実測）

判定では「グリッドが15³では標本も彫刻も判別可能な形にならない」が複数案の減点根拠になった。 これは試作の定数の話なので、議論せず測った。試作を33³に振って計測した結果がこれ。

グリッドブロック露出セル描いた面島1枚の描画FPS
15³（現行）6723403221.5 ms60
33³4,5771,6241,4746.8 ms52
測って分かったこと 沸き10Hzの予算は1秒あたり100ms。33³でも 6.8ms × 10回 = 68ms/秒 で収まる。 つまり解像度は壁ではなく、値段のわかるダイヤルだった（モバイルの余裕は未確認）。 この結果、却下した案を殺したのは解像度ではなく、後述する構造の問題のほうだと確定した。

05判定の全体像

12案を発散し、4案をフル記入して中立の判定にかけた。 採用ライン（合計11以上、または1軸が5）に到達した種はゼロ。 数合わせではなく構造的な理由がある——4案中3案が、 土台の描画設計が構造的に苦手とするもの（支え・落下・動くもの）に賭けていた。

種面白さ市場性新規性合計自己判定
PS-043 ホリホリ発掘帖4331011保留・床が最も高い
PS-045 けしけし団3431012保留・識別性は最大
PS-046 こわし屋ワンタップ332810保留・賭けの立て方だけは唯一正しい

却下した案と、その理由（PS-044 カミケズリ）

「紙の塊からお題の形を削り出す。戻せない一発勝負」。自己採点との差が最大（−4）だった。 死因は解像度ではなく、創作と答え合わせの矛盾にある。 正解ボクセルに対して採点する時点で、それは「自分の作品」ではなく「他人の答えへの近似」であり、 全員が同じ答えに収束するギャラリーは見て面白くない。市場性の柱にしていた共有動機が丸ごと消える。 調整では消えない構造の問題なので、却下に同意した。

ただしこの案の中に本物がひとつある——正面・側面・上面の3方向のシルエットが全部お題に合う。 これは実在する良質なパズル形式で、答えがあることが正当化される。 創作を名乗るのをやめて3面シルエットパズルに振り切れば別種として立つので、発散ログに記録した。

こわし屋ワンタップ（PS-046）の位置づけ

「一点を抜いて塔を思った向きに倒す解体パズル」。単体の点は最下位だが、 けしけし団の前提システムそのものなので、検証対象としての価値は合計点より高い。 ここが通るか否かで、けしけし団の生死が同時に決まる。

06次の一手

本当の分岐は種の優劣ではなく、「支え・落下システムに投資するか否か」。 ここが決まれば3案の順位は自動的に決まる。

  1. けずり町の往復確認（推奨・最初にやる）— 素材3種＋置ける物3種だけの最小プロト。 賭けが安く、外れても失うものが少なく、当たれば発掘帖の弱点（天井が低い・識別性がない）もそのまま埋まる。
  2. 崩落スパイク — 塔1本で、決定性・読みやすさ・崩落中のfpsを同時に見る。 通れば けしけし団 が本命に復帰、通らなければ けしけし団 と こわし屋 が同時に落ちる。
  3. 発掘帖の可読性チェック（1時間）— 固定標本を1体埋めて、断面が読めるか。 崩落スパイクの待ち時間に潰せる。

なお けずり町 と ホリホリ発掘帖 は排他ではない。 発掘帖の出口を図鑑ではなく建設にすれば、そのまま合流する。
