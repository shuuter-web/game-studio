# Voxel Mine 航海図鑑 受け入れ基準

- 港にだけ図鑑入口があり、遠征中とリザルト中は開けない。
- ブロック、生き物、敵、ギア、特性、素材の6カテゴリを切り替えられる。
- 未入手を含む全項目の名称、説明、性能、用途、入手先が最初から表示される。「？？？」や情報マスクを使わない。
- 登録総数とカテゴリ別件数が実データ定義と一致する。
- 一覧から詳細、詳細から一覧、一覧から港へ一操作ずつで戻れる。
- Escapeが詳細→一覧→港の順に動き、閉じると港の入口へフォーカスが戻る。
- 375×667で2列一覧が横にはみ出さず、閉じるボタンと6タブが44×44px以上になる。
- 図鑑閲覧でコイン、所持品、装備、遠征、乱数列が変化しない。
- 地形破壊、大木の幹・葉の伐採、生き物捕獲、敵の初可視、ギア入手、特性入手、素材入手が内部確認履歴へ記録される。
- 自律削岩杭による初破壊もブロック確認として記録される。
- 確認履歴、既読、初回場所がschema 10で保存・復元され、デバッグ初期化で消える。
- ギア個体差は図鑑項目を増やさず、フレーム4種と特性定義を別カテゴリで管理する。

自動検査は `verify-codex.mjs` と既存の `verify-v08.mjs`、`verify-v07.mjs`、`verify.mjs` を実行する。
