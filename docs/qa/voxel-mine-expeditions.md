# Voxel Mine v0.2.0 検証記録

実施日: 2026-09-20。対象: `prototypes/voxel-mine/index.html`。

## 結果

- `node tools/check.mjs prototypes/voxel-mine/index.html`: 通過（構文、乱数、参照アセット、バージョン）。
- `node prototypes/voxel-mine/verify.mjs`: 全項目通過。Playwright + Windows上のEdgeで実行。
- `git diff --check`: 通過。
- 390×844の拠点・採掘画面、1280×900の採掘画面で横方向のはみ出し・操作部の欠けなし。スクリーンショットを目視確認。

## 検証対象

初期航路と出航ボタン、Canvasの実クリック採掘、燃料とターン、部分打撃、硬さ不足と空振り、視点操作、拠点限定クラフト、航路ロック、タンク増強、無料補給、同一seed再訪、範囲採掘・連鎖の消費、最後の燃料と任意帰還時の連鎖報酬、連鎖途中の再読込、報酬重複防止、旧v1セーブ移行、不正セーブ、通常セーブとfreshスロットの分離。

seed 0 / 1 / 777 / 12345で各6島の固有素材が生成されることを検証した。

## 修正した問題

複数素材の鉱脈連鎖は、フレームごとの処理量によってコンボ倍率の適用先が変わっていた。異種4予約の再現ケースで、修正前は銅2・結晶4と銅3・結晶3に分岐。予約時刻順（同時刻は予約順）に処理するよう修正し、両方が銅3・結晶3になる回帰テストを追加、通過を確認した。

既存の再帰的な連鎖拡張も停止し、予約済み報酬をセーブに含めることで、帰還・再読込で最後の連鎖を失わないようにした。

## 実行環境

通常はPlaywrightが解決可能で、対応Chromiumをインストール済みの環境で実行する。
別の環境では `PLAYWRIGHT_MODULE_PATH` にPlaywrightモジュール、`PLAYWRIGHT_EXECUTABLE_PATH` に対応ブラウザの絶対パスを指定する。
画像は `artifacts/voxel-mine/` に出力しGit管理から除外する。

## 残る確認

燃料60から始める初期バランス、強化までの遠征回数、実機での採掘の触り心地はプレイ評価が必要。今回の検証は長時間の経済バランスや実機FPSを保証しない。
換金品・特性素材・モンスター・遺跡は後続段階であり、今回の検証対象外。
