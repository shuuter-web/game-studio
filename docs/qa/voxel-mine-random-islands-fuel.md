# Voxel Mine ランダム島・燃料表示 QA

## 自動受入項目

- 同じ行き先への連続出航で島の占有セルが変化する。
- 探索中の再読込では生成済みセルと採掘状態が一致する。
- 探索中のみ燃料ゲージが表示され、数値・最大値・幅が残量に同期する。
- 最後の燃料で得た通常報酬、伐採報酬、連鎖報酬を確定してから帰還メッセージを表示する。
- 帰還メッセージ中は採掘操作を受け付けず、再読込後もメッセージを復元する。
- 確認操作後に燃料切れ理由のリザルトを表示する。
- 旧セーブを読み込み、追加項目を安全な初期値で補完する。

## 目視項目

- 390×844相当で燃料ゲージがタイトルや操作UIと重ならない。
- 通常・残量少・空の各状態が背景から判別できる。
- 帰還メッセージの本文とボタンが小画面でも欠けず、次の操作が明確である。
