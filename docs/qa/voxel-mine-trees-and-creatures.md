# Voxel Mine v0.4.0 樹木と立体生物の検証

## v0.4.1 追補

既存のv3遠征、およびv4へ移行して木が空のまま保存された遠征を再読込し、現在の島へ木が現れることを確認した。補充後の再読込でも木の位置と所持品を維持する。4種の世界seedで全6行き先に複数の木が配置された。生き物の立体メッシュは2つの異なる姿勢を持ち、その切り替えで燃料・所持品・個体状態を変えないことを検査した。従来の採掘・伐採・捕獲・売却・旧セーブの全回帰も通過。

実施日: 2026-09-22。Windows上のPlaywrightとEdgeで実行。

- `node tools/check.mjs prototypes/voxel-mine/index.html`: 通過。
- `node prototypes/voxel-mine/verify.mjs`: 全項目通過、実行時例外なし。
- 390×844の島の画像で、樹木の幹と葉、生き物の立体形状、地形との前後関係を確認。

検証内容: 初回出航時の樹木配置、実際のCanvas操作での伐採、燃料1の消費、木材2個の獲得、伐採済み状態の保存と重複取得防止、港での正確な換金、最終燃料のリザルト反映、同じ世界の種での配置再現。v3進行中遠征の通貨と状態を移行し、次の出航から樹木が現れることも確認した。既存の採掘・捕獲・連鎖・旧v1/v2セーブの回帰検査も通過。
