# Voxel Mine v0.7 受入検証

- schema 8の初期値とデバッグ初期化
- 旧schemaを読み込んだ場合の新規開始
- 個体換金品の名前・説明・価格の決定性、多様性、再読み込み
- ギアの重量6、最大3個、港限定編成、装備中だけの効果
- 4種の地形傾向と遠征ごとの変化
- 埋没宝箱の露出、燃料消費、二重取得防止、島2の設計図保証
- 古代哨戒機の4手周期、攻撃予告、連鎖採掘の1手判定
- 全地形で哨戒機が固体ブロック上面へ接地し、ほかの配置物と重ならないこと
- 哨戒機が通常生物とは異なる形・色・大きさを持ち、文字なしの4分割耐久ゲージと攻撃カウント数字がカメラへ追従すること
- 耐久減少がゲージへ反映され、攻撃直前は数字アイコンの輪郭と脈動でも警告されること
- 敵が一部でも見える時だけ通常表示が現れ、地形・木による完全遮蔽、画面外、撃破、撤退時には表示と押下判定が消えること
- 通常探索では敵情報と攻撃ボタンが常設されず、本体タップで攻撃、耐久ゲージまたは数字アイコンのタップで任意の詳細表示が開くこと
- 詳細表示は背景を暗転させない幅196px以下の情報札として敵へ追従し、行動・特性・報酬を切り替えられること
- 情報札の開閉とページ切替で燃料・敵手番・攻撃予告が変化せず、表示中もカメラ操作できること。札の外側をタップした最初の一回は閉じるだけで採掘・攻撃へ貫通しないこと
- 撃破・撤退後に哨戒機モデルと頭上表示が残らないこと
- 敵の足場破壊後に安全な地表へ移動し、候補がなければ攻撃を停止すること
- カメラ操作で敵手番が進まないこと
- 敵撃破時のギア取得と船体0の緊急帰還
- 燃料切れ通知を挟んだリザルト遷移
- ユーザー向け表記が船外削岩機・削岩出力に統一されていること
- 葉ブロック1個につき葉由来の個体換金品1個を得て、再読込で重複しないこと
- 既存の採掘、木、生き物、帰還、売却、強化、保存の回帰
- 実行時エラーと参照アセットエラーが0件

`verify.mjs` で既存機能の回帰、`verify-v07.mjs` で新しい垂直スライスを検証する。
