# Voxel Mine v0.8 受け入れ基準

- 3種の条件ギアが宝箱、敵、工房の決定的なランダム抽選へ含まれ、港で重量6・最大3枠の制約を受ける。
- 自律削岩杭は最初の成功した手動地形採掘位置へ配置され、配置手番には作動せず、次の有効行動から距離2以内を毎手番1個だけ固定出力1で掘る。
- 自動掘削の対象順は距離、セル番号で固定され、追加の燃料・手番・敵カウント・連鎖・ギア再発動を発生させない。
- 複数の自律削岩杭は装備個体ごとに1基ずつ作動し、3Dモデルと配置状態が保存・復元される。
- 三拍増幅器は3の倍数手番の手動地形採掘と大木伐採だけを+1し、別行動に使った手番の効果を持ち越さない。
- 樹冠共振器は葉ブロックを中心にした大木伐採だけを+1する。幹と地形では発動しない。
- 同名複数と異なる条件は加算され、追加範囲は+2を超えない。範囲伐採した各パーツの報酬は重複しない。
- 鉱脈連鎖、無料自動掘削、敵行動、燃料切れ帰還が定義順に一度ずつ解決され、再読込後も結果が一致する。
- schema 9の不正な状態を拒否し、旧schemaは新規ゲームとして初期化する。
- v0.7までの採掘、木、葉報酬、生き物、宝箱、敵、燃料通知、リザルトが回帰しない。

自動検査は `verify-v08.mjs`、`verify-v07.mjs`、`verify.mjs` と `node tools/check.mjs prototypes/voxel-mine/index.html` を実行する。
