# Voxel Mine v0.6.1 燃料ゲージの位置と注視点の追従

実施日: 2026-09-23。

Shooter 指示（実機スクリーンショット付き）:

> UIが邪魔で画面が見辛くなっているので残り燃料のゲージは下がいいと思います。
> あと、木が乗ったことで島の中心がズレているので、残っているブロックに応じて注視点が動くようにして欲しいです。

**この作業は Dragon Tide のスレッドから依頼された**（Shooter の取り違え）。
voxel-mine 側の経緯がそちらに埋もれないよう、ここに残す。

## ① 残り燃料のゲージを下段へ

`#fuel-status` を `top:10px` から `bottom:92px` へ。
下端は 道具列(12px) → ヒント(66px) → 燃料(92px) の順に積む。

燃料が画面上部から退いたので、狭い画面（max-width:900px）で
`#hud` と `#inv` を `top:76px` まで下げていた回避も外して上端へ戻した。

## ② 注視点が残っているブロックに追従する

木が上に生えたことと、片側を掘り進めたときに残りが画面端へ寄ることは、
どちらも「注視点が島の原点に固定されている」という同じ原因だった。

### 基準ごと重心に置き換えるのは駄目だった

最初、注視点をそのまま残りブロックの重心にした。
ところが**島の質量は下の岩盤に偏っている**ので、初期の画角が 1.7 マス下へずれた
（旧来の手詰め値 `camTargetY = -1.6 - (islandRadius - baseRadius) * 0.35` に対し、
重心は y = +0.1 だった）。

目的は「掘った分だけ視点が付いてくる」ことなので、**差分だけ**を足す形にした。

```
注視点 = 島に降りた時の基準（従来の式そのまま）
       + （今の重心 − 島に降りた時の重心）
```

降りた直後の見え方は従来と完全に同じで、掘るほど視点がずれていく。

### 外接箱ではなく重心

外接箱の中心だと、細い木が数本生えただけで視点が大きく振られる。
木はブロック数が少ないので、重心ならほとんど動かない。

### 追従の仕方

- ブロックが壊れたら `focusDirty` を立てるだけ。重心の計算は
  フレームあたり最大1回（1回の採掘で複数壊れるため）
- 時間ベースの指数平滑で寄せる（約1秒で9割）。採掘のたびに飛ぶと酔う
- 動いていないフレームでは `cameraDirty` を立てない＝余計な再ソートが起きない

### セーブ

`camera.targetX/Y/Z` を保存する。読み込み時は、保存された注視点が今の重心に
対応するよう基準の重心を逆算して結び直す（掘った分のずれを引き継ぐ）。
`targetY` しか無い旧セーブは、その島の重心から作り直す。

## 検証

- `node tools/check.mjs prototypes/voxel-mine/index.html`: 通過
- `node prototypes/voxel-mine/verify.mjs`: **実行できず**。
  この環境に Playwright が入っていないため（`Install playwright or set PLAYWRIGHT_MODULE_PATH.`）。
  代わりに Claude Code のブラウザペイン（375×812 のモバイル表示）で実機確認した。
- 島に降りた直後の注視点が `(0, -1.6, 0)` ＝従来値と一致することを確認
- 島の左側 45%（226ブロック）を削ると、注視点が x 方向へ 1.76 マス追従し、
  残りが画面中央に収まることを確認
- 燃料ゲージが下段に出て、画面上半分が空くことを画面で確認

## 積み残し

**島の左端が画面外にはみ出ることがある。** 今回の変更の前からある。
`fitCameraToIsland` は `islandRadius` から引きの距離を決めているが、
木がシルエットを横へ広げるぶんが計算に入っていない。
