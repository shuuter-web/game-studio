# Voxel Mine — 開発コンセプト

## 掘るほど、船が自分らしくなる。

漂流する浮島を限られた燃料で掘り、奇妙な特性を持つ素材やギアを持ち帰る。飛空艇の積載量の中で特性を組み合わせ、掘り方が変わる自分だけの掘削船を育てる探索ハクスラ。

浮島には、古代文明のお宝や遺跡の断片も眠っている。予想外の発見が次の探索目的を生み、船を強化して遠い空域へ進むうちに、巨大浮島と失われた世界の秘密へ少しずつ近づいていく。

## 進め方

- 全体の詳細なGDDは作らず、このコンセプトを判断の軸にする。既存の設計資料は参考資料として扱う。
- 一度に試す中心的な変更は一つ。遊べる形にして公開し、ユーザーの評価を次の変更へ反映する。
- 各ステップの説明は「何を変えたか」「どこを遊んで評価するか」を短く伝える。
- 最初はギアを手に入れる機会を確かめ、次に組み合わせによる掘り方の変化を磨く。世界の秘密は、探索中の発見から次の目的へつながる小さな要素として育てる。
- 帰還リザルトは結果を明快に示す。探索中の文章は、意外な発見や新しい展開につながることを重視する。

## 次に試す一歩

ギアごとに機能を表す呼び名と専用の機械イラストを用意し、何を拾ったか、何を搭載するかを見分けやすくする。

評価する点：ギアの名前と機械の姿を見て、種類の違いが分かるか。以前より覚えやすく、搭載したいギアを探しやすいか。
