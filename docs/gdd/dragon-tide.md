# 竜潮 / Dragon Tide

> **Game Design Document v0.3**
> 2026-06-21 / game-designer: Claude
> 参考フレームワーク: Jesse Schell『The Art of Game Design』(Elemental Tetrad / MDA / Interest Curve / Flow / The Toy)
>
> **v0.3 大方針転換（Shooter 指示）**:
> 「脅威に対処する戦術ゲーム」を**やめ**、**塊魂(Katamari)型の「規模のエスカレーション」**へ転換。
> プレイヤーが脅威にさらされることは基本なく、**「ちょっと気持ちいいこと」と「すごく気持ちいいこと」**の連続で面白さを作る。
> これに伴い **隊形システムは完全カット**、**属性×隊形の三すくみは廃止**。群れの形は**線の引き方**でのみ表現する。
>
> **v0.2 → v0.3 の主な変更**
> - 隊形（密集/散開/円環）を**全面削除**。攻撃倍率の差だけで意味が薄く、静的拠点相手では切り替える動機がなかった
> - 脅威ベースの設計（弾幕を読んで凌ぐ）を**降格**。投射物は「雰囲気」＋穏やかなダメージに
> - **雪だるま成長**を中核に：卵を回収すると**その場で竜+1**、群れが増えるほど**カメラが引いて世界がジオラマ化**
> - **ダウン/復帰モデル**：被弾でHP0でも消滅せず、フェードアウト離脱→数秒後フェードイン全回復。**恒久喪失なし**
> - 属性（火/氷/影）は**未実装の将来構想**として保留（スプライトのパレットだけ準備済み）

## 0. ピッチ

> **指でラインを描く。竜の群れがそれをなぞって、地上の街並みを薙ぎ払っていく。**
> **壊すほど群れが増え、増えるほど大きく薙げる——気づけば世界を覆う竜の嵐になっている、塊魂型の蹂躙フローアクション。**

- **ジャンル**: 群体操作 × ライン・ドロー × 規模エスカレーション（塊魂型）
- **プラットフォーム**: HTML5 Canvas / スマホブラウザ縦持ち片手
- **セッション長**: 1ラン（複数の文明ステージ）数分〜
- **同時表示**: 自軍最大 100体（開始10体から雪だるま式に増加）
- **オフライン完結**: 単一HTMLファイル / セーブは将来IndexedDB
- **テキスト最小**: UIはアイコン中心、ナラティブは建築のシルエットのみ

> **設計の背骨（v0.3）**: 脅威でなく**規模の拡大が快感**。
> 「ちょっと気持ちいい（小建物がポップに弾ける常時のスイープ）」と
> 「すごく気持ちいい（群れが増えて一気に大きく薙げる瞬間）」のリズムで面白さを積む。

## 1. Essential Experience（核心体験）

> **「指の腹から、生き物の群れの重みが流れ出していく」流体所有感は維持する。**
> **その群れが街並みの上を流れると建物が次々に砕け、砕くほど群れが膨らみ、やがて世界そのものを覆う巨大な嵐になる。**
> **プレイヤーが感じるべきは『自分がどんどん大きく・強くなっていく雪だるま的高揚』。脅威に怯えるのではなく、規模が跳ね上がる快感を浴びる。**

設計上の絶対条件:
1. **「操作している」と「眺めている」の境界が曖昧であること**（v0.1から継承）
2. **成長が目に見えること**（v0.3の核）。群れの数・薙ぎの幅・カメラの引きで「自分がデカくなっている」が常に体感できる
3. **跡が残ること**（v0.2から継承）。砕いた街は崩れ、群れが通った後の世界は目に見えて変わっている

## 2. Elemental Tetrad 分析

### 2.1 Mechanics（実装済み＝★、構想＝☆）
- ★ **ライン・ドロー**: 指でなぞった軌跡（ワールド座標）が群れの誘導パス
- ★ **Boids**: 分離 / 整列 / 結束 + パスへの引力。**群れの密度は線の引き方で自然に変わる**（隊形ボタンは廃止）
- ★ **雪だるま成長**: 卵を回収すると**その場で竜+1**。開始10体 → 最大100体
- ★ **カメラズーム**: 有効個体数が増えるほどカメラが引き、世界がジオラマ化（塊魂のスケール演出）
- ★ **静的な建物（街区）**: マップに街区状にびっしり配置。ブレス＋体当たりで破壊。破壊で群れは（直接は）増えない
- ★ **卵持ち建物**: 全建物の約18%だけが目印（金色オーブ、明滅）付きで、陥落時に卵を1個落とす
- ★ **ブレス攻撃**: 射程内の建物へレーザー状に持続照射
- ★ **体当たり＋ヒットストップ**: 建物に接触で単発ダメージ＋一瞬停止
- ★ **投射物（雰囲気）**: 一部の建物がたまに弾を撃つ。穏やかなダメージ＋軽ノックバック
- ★ **ダウン/復帰**: 被弾でHP0→フェードアウト離脱→約5秒後フェードイン全回復。消滅なし
- ★ **ステージ制（4文明）**: 石器→古代→中世→近世要塞。全建物破壊で次ステージ、群れは持ち越し
- ☆ **属性（火/氷/影）**: 未実装。スプライトのパレットのみ準備
- ☆ **スクロールマップのルート選択 / 時代の主城（ボス）**: 構想（現状は1ステージ＝1文明の連鎖）

### 2.2 Story（物語 / 出来事の順序）
- **最小限の世界観**: 竜は時を超える「潮」。人間の文明は興っては滅び、群れは時代から時代へ渡って地上を呑む
- **明示的セリフ無し**。ステージ（時代）が進むと建築様式・地上の色・空の色だけが変わる
- **加害の暗喩**: 時代が進むほど建物が撃ち返してくる（雰囲気）ことで、人類の抵抗の進化が静かに示唆される

### 2.3 Aesthetics（感覚 / 何が届くか）
- ★ **視覚**: 半透明シルエットの竜（角張った膜翼＋頭＋しなる尻尾、ドラゴンスピリット風トップビュー）。地上は街区状のミニチュア建築。群れが増えるとカメラが引いて落差が際立つ
- ★ **触覚**: スマホ振動。ライン描画中の微弱な持続振動、体当たり時のパルス
- ★ **聴覚**（方針）: アンビエント基調。群密度で低音が増す（構想）
- ★ **時間感覚**: タイマー非表示。「次の街区だけ」「卵持ちだけ」が積み重なる

### 2.4 Technology（媒体・素材）
- ★ HTML5 Canvas 2D（単一HTMLファイル、外部ライブラリなし）
- ★ Boids＋空間ハッシュ近傍探索。建物はオフスクリーンcanvasにプリレンダ→drawImageで合成
- ★ 竜スプライトは羽ばたき16フレームをプリレンダ、尻尾のみ動的（緩和チェーン）
- ★ `setInterval(16ms)` ループ（`document.hidden` でも止まらない）。canvasは `{ alpha:false }`（`desynchronized` は点滅の原因のため不使用）
- ★ カメラ：群れ重心追従＋ズーム。`worldToScreen`/`screenToWorld` で座標往復整合
- ★ 振動: `navigator.vibrate` ベストエフォート

> **Tetrad 整合チェック（v0.3）**: 4要素が**「規模のエスカレーション」**で結ばれる。
> 卵を呑む(M)と群れが増え、薙ぎ幅とカメラの引き(M)が拡大し、世界がジオラマ化(A)して「デカくなった」が届く。
> 被弾しても離脱→復帰(M)で群れは基本減らず、嵐が一瞬陰って盛り返す(A)。脅威でなく規模が主役。

## 3. コアファンタジー / The Toy（玩具レンズ）

### コアファンタジー
> **「群れになる」、そして「どんどん大きくなって世界を覆っていく」。**
> プレイヤーは群れそのものの意志であり、成長していく災害。

### The Toy: 勝敗条件を全部外しても面白いか？
**Yes**（v0.1検証で合格）：
1. ★ **線を描くだけで竜が追従する**——眺めるだけで気持ちいい原始的快楽
2. ★ **何もない空に円を描くと群れが渦を作る**——ASMR的な無目的快楽
3. ★ **群れを街区に重ねるだけで建物が砕ける**——スケールの落差そのものが快楽
4. ★ **卵を拾うほど群れが膨らみカメラが引く**——成長を眺める快楽（v0.3で追加・検証済み）

## 4. コアループ（塊魂型・規模エスカレーション）

### 4.1 ベースライン（常時＝「ちょっと気持ちいい」）
```
線を引く → 群れが街区を薙ぐ → 小建物が次々ポップに砕ける →
（金色の卵持ちを見つけて狙う）→ 卵を拾う → その場で竜+1 →
薙ぎ幅が少し広がる
```
密集した小建物を群れでザーッと薙ぐ**スイープそのもの**が常時の快感。

### 4.2 スパイク（時々＝「すごく気持ちいい」）※一部は今後実装
```
卵を拾い続けて群れが育つ → カメラが引いて世界がジオラマ化 →
☆ 大きな建物（城・神殿）がサイズ的に呑み込めるようになる「閾値超え」 →
☆ ランクアップ演出（嵐の規模が一段上がる）
```
「育つ→大きいものを食える→もっと育つ」の跳ね上がりが快感のピーク。
**閾値ゲート・ランクアップ演出・ご褒美建物は次フェーズの実装対象**（§13）。

### 4.3 ラン（マクロ: 文明縦断）
```
石器 → 古代 → 中世 → 近世要塞 と4文明を制覇 →
各ステージで群れは持ち越し、ランを通して雪だるま式に巨大化 →
最後の文明では世界を覆う嵐になっている
```
ラン中は一貫して強くなる（雪だるま）。終了動機をプレイヤーに渡さない（スタミナ等の区切り装置なし）。

## 5. 敵（文明）の設計 ※脅威でなく「呑み込む手応え」

> **v0.3の転換**: 敵は脅威ではない。**呑み込む対象の手応えと、成長の関門**として設計する。
> v0.2の「隊形 × 弾幕の三すくみ」は**廃止**。

### 5.1 実装済み
- **街区状の高密度建物**: ステージごとに150〜230棟。小（即砕け）/中/大（堅め）の混在
- **卵持ち建物（約18%）**: 金色の明滅オーブで明示。陥落時に卵1個＝竜+1の源。**成長を緩やかにし、狙いどころを可視化**
- **投射物（雰囲気）**: 一部建物がたまに弾を撃つ。穏やかなダメージ（HPの約1/7）＋軽ノックバック。脅威ではなく時代の空気づくり

### 5.2 構想（次フェーズ）= 「呑み込む手応え」のバリエーション
- **建物の階層とサイズ関門**: 大建築は一定の群れサイズで一気に溶ける（閾値未満は穏やかに抵抗＝塊魂の「まだ持ち上げられない」）。「すごく気持ちいい」閾値超えの本体
- **ご褒美建物**: 食うと群れが+10体一気に増える穀倉、誘爆して周囲を巻き込む火薬庫——スパイクを意図的に配置
- **時代のワンダー**: 巨大になって初めて食える目玉。ステージのクライマックス
- ※**動く敵（迎撃竜等）は原則入れない**。入れるなら「建物から発進し帰る」場所紐付きにして、追いかけっこ・空中戦にしない

## 6. 文明（ステージ）の設計

「時代を越える」＝**新しい視覚体験**を供給する装置。脅威の高度化ではなく、景色とスケールの更新が主目的。

### 6.1 実装済みステージ（4文明）

| # | 文明 | 建築シルエット | 背景色 | 投射（雰囲気） |
|---|---|---|---|---|
| 1 | 石器時代 | 不規則な円・多角形（洞窟/焚き火/土塁） | 暗い緑の荒野 | 遅い弓矢 |
| 2 | 古代文明 | 四角・三角（神殿/ピラミッド） | 砂漠の黄土 | 投石（範囲） |
| 3 | 中世 | 城壁・塔付き四角 | 霧の灰緑 | 矢の雨（扇状） |
| 4 | 近世要塞 | 星形・稜堡 | 戦場の黒紫 | 大砲・銃撃（多方向） |

全建物破壊でクリア → フラッシュ →「STAGE N」→ 次マップ生成。群れの数・HPは持ち越し。

### 6.2 構想（拡張）
産業時代・蒸気幻想などの追加、各時代の「らしさ」3点セット（外観・呑み心地・落ちる卵の種類）、時代のワンダー。

## 7. MDA マッピング（ルール→動的振る舞い→感情）

| Mechanics（書ける） | Dynamics（生まれる） | Aesthetics（届く） |
|---|---|---|
| 指の軌跡が群れの引力場になる | S字に引くと群れが蛇行しうねる | **流体所有感** |
| 卵回収＝その場で竜+1 | 金色の卵持ちを探して狙う動線 | **成長の手応え・収集の満足** |
| 有効個体数でカメラが引く | 育つほど世界が小さく見える | **雪だるま的高揚・支配感** |
| 群れを街区に重ねると建物が砕ける | 密集街区を広く薙ぐルート取り | **スイープの快感（ちょっと気持ちいい）** |
| 被弾→ダウン→数秒で復帰 | 撃たれて嵐が一瞬陰り、盛り返す | **脆さと回復のリズム（脅威でなく余韻）** |
| 建物の破壊跡が残る | 通過跡を振り返る | **加害的高揚・支配の実感** |
| ステージ（時代）で景色が一変 | 「次の時代が見たい」連鎖 | **発見と更新の期待** |

> **逆算原則**: 右列の感情から左列を設計。v0.3の目的地は**「規模が跳ね上がる快感」**。

## 8. Interest Curve（興味曲線）

### 8.1 1ステージ（数分）
```mermaid
xychart-beta
    title "Single Stage Interest Curve"
    x-axis "Progress (%)" [0, 20, 40, 60, 80, 100]
    y-axis "Interest" 0 --> 10
    line [5, 6, 7, 8, 9, 7]
```
- 序盤：小さい群れで街区を薙ぐ導入（5〜6）
- 中盤：卵持ちを拾って群れが育ち、薙ぎ幅とカメラ引きが拡大（上昇）
- 終盤：群れが巨大化し街区を一掃する全能感（ピーク9）→ クリアの余韻

### 8.2 1ラン（4文明縦断）
```mermaid
xychart-beta
    title "Full Run Interest Curve (4 civilizations)"
    x-axis "Stage" [1, 2, 3, 4]
    y-axis "Interest" 0 --> 10
    line [6, 7, 8, 10]
```
- ステージが進むほど群れが大きく、景色も一変 → 興味は基本右肩上がり（雪だるま）
- 谷を作らず、最後の文明を最大規模のクライマックスにする

### 8.3 「飽き」予測と先手
| 飽きるタイミング | 兆候 | 先手の打ち手（多くは次フェーズ） |
|---|---|---|
| ベースラインの単調 | 薙ぐだけになる | **閾値ゲート＋ご褒美建物**で「すごく気持ちいい」スパイクを挿す |
| 成長の頭打ち感 | 増えても変化が乏しい | **ランクアップ演出**で規模の段階を可視化 |
| 景色の慣れ | 同じ文明が続く | **ステージ遷移**で視覚をリセット（実装済み） |

## 9. Flow / 失敗の扱い

### 9.1 フロー維持の3技法
| 技法 | 実装 |
|---|---|
| フィードバックの即時性 | 線描画に群れが即反応。破壊はパーティクル＋振動＋音 |
| 目標の明確さ | 卵持ちが金色で目立つ。HUD最小（生存数/最大、卵数、ステージ、ミニマップ） |
| 雑音の排除 | テキスト・通知・タイマー表示なし |

### 9.2 失敗とリスク（v0.3で大幅緩和）
- **恒久喪失なし**：被弾でHP0でも消滅せず、フェードアウト離脱→約5秒後フェードイン全回復で復帰
- ダウン中は群れの有効個体数から除外＝嵐が一瞬陰る（ペナルティでなく余韻のフィードバック）
- **全員ダウンでもゲームオーバーにしない**（順次復帰、ソフトロックなし）
- 投射ダメージは穏やか。脅威でなく雰囲気
- → 塊魂同様「欠けてもすぐ戻る」軽さ。プレイヤーは成長に集中できる

> **設計哲学**: 失敗は罰でなく一瞬の陰り。プレイの主役はあくまで成長。

## 10. 進行・メタ

### 10.1 実装済み
- 卵回収＝その場で竜+1（ラン中の雪だるま成長）
- ステージ（文明）クリアで群れを持ち越し

### 10.2 構想（次フェーズ）
- **恒久メタ**：竜の種類アンロック・新文明（生の強さより**種類・コレクション**中心にして毎ランの成長曲線を平らにしない）
- **卵＝コレクション**：蹂躙した相手から対応する属性の卵（例：火の神殿→火竜）。世界踏破とコレクションを相互補強
- ランクアップ称号（FLIGHT→STORM→TEMPEST→CALAMITY 等）の演出

---

## 11. 属性システム（火 / 氷 / 影）※未実装・将来構想

- 現状**未実装**。竜スプライトのパレット（火/氷/影）だけ用意済みで、稼働は火のみ。
- 将来、**敵側に属性相性を要求する建物が入って初めて**編成（卵の種類）が意味を持つ。
- **設計順序の原則**: 敵のバリエーションが先、属性・編成は後。刺さる相手が居ない段階で属性を作り込まない。

## 12. 操作・UI（縦持ち片手）

### 12.1 実装済み
- **画面全体が線描画エリア**（隊形/属性ボタンは廃止したため下部UI予約なし）
- **群れを線で引っ張る＝マップ移動**（専用移動操作なし）
- カメラは群れ重心を緩やかに追従＋ズーム
- HUD：生存数/最大・卵数・ステージ・ミニマップ（最小限）
- 敗北/リトライは別オーバーレイ（恒久喪失モデルにより出番は限定的）

### 12.2 アイコン設計（i18n対応）
- 文字は使わない方針を維持。金色オーブ＝卵持ち、など視覚記号で示す

## 13. 次フェーズの開発方針（合意済みの方向）

塊魂型「規模のエスカレーション」を深める。**脅威は足さない**。

1. **閾値超えの快感（最優先候補）**: 建物の階層＋サイズ関門。大建築は群れが一定サイズで一気に溶ける。「すごく気持ちいい」の本体
2. **ランクアップ演出**: 群れの規模が段階を超えると称号＋フラッシュ＋カメラパンチ
3. **ご褒美建物**: 穀倉（+10体）、火薬庫（誘爆で周囲一掃）
4. **時代のワンダー**: ステージの目玉となる巨大建築
5. （以降）属性＝コレクション、恒久メタ（種類アンロック）

## 14. 参考タイトルと差別化

### 14.1 参考タイトル
| 作品 | 学ぶ要素 |
|---|---|
| **Katamari Damacy** | **規模が拡大し世界を呑む快感**、対象が世界そのもの、脅威でなく成長が主役 |
| **flOw / Flower** | 無目的快楽、テキストレス、群れの物理的気持ちよさ |
| **Vampire Survivors** | 「もう一周」、最小UI、到達度＝スコア |
| **Pikmin** | 群れへの愛着 |
| **Civilization 系** | 時代を越える視覚的変遷 |

### 14.2 差別化
1. **指で群れを"なぞる"**連続パス描画
2. **塊魂型の非対称**：脅威に対処するのでなく、成長して世界を覆っていく
3. **静的文明を呑み込む構図**：攻める側が圧倒的に大きい
4. **時代縦断の視覚更新**：1ランで文明史を駆け抜ける
5. **テキストゼロのナラティブ**：建築様式の変遷だけで歴史を語る
6. **跡が残る蹂躙**：破壊跡がマップに刻まれる

### 14.3 持ち込まないもの
- ❌ クラフト / 素材集め
- ❌ 長文ナラティブ / カットシーン
- ❌ ガチャ課金導線（卵は完全ゲーム内報酬）
- ❌ PvP（初版）
- ❌ スタミナ・日次クエスト等の区切り装置
- ❌ **脅威ベースの設計**（弾幕を読んで凌ぐ緊張）——v0.3で明確に方向外に
