# 掘り島 v0.3.0 — 発見物・生き物・遠征リザルト

2026-09-22の追加要望を反映する。土や石を集める経済から、採掘で発見した素材と換金品を持ち帰る経済へ移行する。

## 今回の仕様

- 草・土・石は地形であり、所持素材としては取得しない。破壊時に無発見／工作部品などの強化素材／換金品を抽選する。
- 銅以降の鉱石は従来どおり強化素材として採れる。土・石を要求する全クラフト費用は新素材へ差し替える。
- 島の表面に生き物を最初から配置する。今回の生き物は捕獲対象であり、攻撃してくるモンスターとは別の第一段階。
- 生き物をタップすると燃料1・1ターンで捕獲し、対応する換金品を取得する。同一個体は一度だけ取得可能。存在と捕獲状態を保存する。
- 採掘で足場を失っても生き物が宙に残ったり見えない場所から捕獲できたりしないようにする。捕獲可能な範囲を視点と一致させる。
- 出航ごとに抽選の内容が変わる一方、同じ遠征を読み直しても抽選結果は変わらない。描画回数、連鎖処理のフレーム刻み、観察時間は結果に影響しない。
- 換金品は素材と区別して保管し、港で売却してコインを得る。売却は港だけで可能。同じ品を二重売却できない。
- 任意帰還・燃料切れ・島の採掘完了は、最後の報酬処理後に独立リザルトへ遷移する。獲得素材、換金品と売却見込額、捕獲数、使用燃料を表示する。
- 「港へ戻る」でリザルトを閉じる。リザルト表示・再読込では獲得物を再加算せず、状態をそのまま再開する。

## 進行と互換性

初期島で初回の道具・飛空艇強化の費用をすべて得られること。初期島に生き物を保証し、完全な無収穫のリスクを抑える。無料出航・補給は維持する。

旧セーブの在庫、装備、航路、燃料容量は保持する。土・石は換算を明示して新素材に移行し、再読込で繰り返し換算しない。遠征中だったセーブも、損傷・燃料・未処理連鎖を失わないようにする。

数値・生き物の種類・抽選テーブルはコード冒頭の設定へ集約する。素材厳選、敵の攻撃、遺跡は今回の変更に含めない。

## 受入条件

土石の直接取得なし、無発見と発見の両方がある、同一遠征の抽選再現性、生き物の事前配置と二重捕獲防止、最後の燃料での捕獲・連鎖結果、リザルトの増分集計と保存再開、素材を売らない換金、旧セーブ移行、スマートフォンでの操作を機械検証する。
