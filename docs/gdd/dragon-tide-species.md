# Dragon Tide — 竜種15種の案（命名・動き・攻撃）

- 作成: 2026-08-08 ／ 対象コード: `prototypes/dragon-tide/index.html`（**v0.33.1** 時点）
- **これは案。未実装。** 動きパラメータの仕様は [docs/ui/dragon-tide-controls.md](../ui/dragon-tide-controls.md) §12、
  攻撃の図形の元ネタは [dragon-tide-next-steps.md](dragon-tide-next-steps.md) §3-4／§3-5。
- 本書は next-steps §3-5「アンロック竜種8案」を**差し替える**（あちらは攻撃の図形から名前を付けていたため、
  操作感の違いが名前から読めなかった）。

## 1. 課題と、この案の骨

**課題（ユーザー指摘・2026-08-08）**：現在の名前は 火竜／氷竜／影竜／緋竜 という**属性の名前**なので、
「なぜ氷竜のほうが小回りが利くのか」が名前から読めない。属性は色と攻撃の説明にしかなっておらず、
**操作感の違いに納得感がない**。

**骨**：**名前を「体躯・飛び方」で付ける**。竜の姿から動きが推測できれば、操作感の違いがそのまま納得になる。

```
名前（体躯・飛び方）  →  動きのプロファイル  →  攻撃の図形
   隼＝細身・鋭い翼       小回り・速い・脆い      直進貫通弾
   鯨＝巨体・丸呑み       鈍重・大回り            吸引→爆縮
   蜻蛉＝停空・直角に飛ぶ  即時方向転換・停止可    回転掃射
```

命名規則：**一字（生き物の姿）＋「竜」**。属性（色・エフェクト）は名前から切り離し、見た目の担当に落とす。

### 1-1. 前提となる構造変更（これが無いと15種にできない）

**現状は「竜種 = 攻撃タイプ」の1対1**。`flockWeapon` が `beam`/`bullet`/`missile`/`melee` の4値しかなく、
動きプロファイルも `SPECIES_MOVEMENT[flockWeapon]` で引いている。つまり**竜種を増やすには攻撃を増やすしかない**。

→ **`SPECIES_DEFS` を新設して、竜種を「攻撃 × 動き × 見た目」の組にする。**

```js
const SPECIES_DEFS = {
  falcon: { name:"隼竜", attack:"bullet",  move:{…}, palette:"ice",   unlock:{…} },
  eagle:  { name:"鷲竜", attack:"beam",    move:{…}, palette:"fire",  unlock:null },
  …
};
```

- `flockWeapon` は「攻撃タイプ」だけを指す内部値に戻し、竜種IDは別に持つ（`flockSpecies`）。
- こうすると**攻撃6〜7種で15竜種**が作れる（同じ攻撃でも動きが違えば別の竜として成立する）。
- 影響範囲：`SPECIES_CHOICES` / `WEAPON_HUD` / `WEAPON_ELEMENT` / `mv()` / `CARD_DEFS` の `weapon:` フィルタ /
  ランセーブ（`flockWeapon` を保存している）。

## 3. 既存4種の改名

| 現 | 新 | 理由 |
|---|---|---|
| 🔥 火竜（beam） | **鷲竜** | 王道・基準機であることを姿で示す。数値は現行 default のまま |
| ❄️ 氷竜（bullet） | **隼竜** | 「小回りが利いて速い」が名前から読める |
| 🌑 影竜（missile） | **鴉竜** | 群れて追う＝誘導弾。影の色味は見た目として残す |
| 🐾 緋竜（melee） | **甲竜** | 「装甲で体当たり・重い」が名前から読める |

- **属性（色・エフェクト）は捨てない**。`DRAGON_ELEMENT_COLORS` の fire/ice/shadow/crimson はそのまま
  見た目の担当として使い、名前とは切り離す（鷲竜=炎色、隼竜=氷色 など）。
- セーブ互換：`flockWeapon` の値（beam等）は据え置きなので、**既存のランセーブは壊れない**。
  表示名だけ差し替わる。

## 4. 攻撃の実装コスト（3段階）

| 段 | 攻撃 | 使う既存部品 |
|---|---|---|
| **既存流用**（4） | 持続ブレス／直進貫通弾／誘導弾／体当たり | そのまま |
| **軽い**（5） | 前方扇／長射程直線／連鎖グラフ／同心円パルス／設置領域 | `spawnDragonProjectile`（角度を複数）／貫通弾の射程・威力振り／近傍建物を順に線で結ぶ＝`motherBreathFx` の線描画流用／`emitShockwave`（敵側に実装済み）／地面レイヤーに帯を焼く |
| **重い**（6） | 回転掃射／衛星竜／跳弾折れ線／吸引→爆縮／焔の軌跡／突貫 | 新規。角度を回す常時ビーム、周回する子オブジェクト、反射計算、引力＋爆発、地面に残る帯の寿命管理、群れ全体の一斉移動 |

**進め方の推奨**：まず**Ⅰ〜Ⅲの9種**（既存流用4＋軽い5）で「動きが違うと別のゲームに感じる」かを実機で確認する。
それが通ってからⅣ〜Ⅵ（重い6）へ。

## 5. アセット

現状の竜の絵は **ラスター3枚**（`dragon_fire_body/wing` `dragon_ice` `dragon_shadow`）＋
`DRAGON_ELEMENT_COLORS` のティントで4種を賄っている（緋竜は fire を赤ティント）。

15種を **5シルエット × 配色** で組む案：

| シルエット | 対象 | 備考 |
|---|---|---|
| 小型・細身 | 隼竜／燕竜／蜂竜 | 既存 ice を流用できる可能性あり |
| 標準 | 鷲竜／鴉竜／雷竜 | 既存 fire / shadow |
| 大型・重厚 | 鶴竜／鮫竜／甲竜 | **新規1枚** |
| 巨体 | 鯨竜／亀竜 | **新規1枚** |
| 長胴 | 蛇竜 | **新規1枚**（胴を複数節で描くなら実装も要る） |
| 特殊 | 蜻蛉竜／蝶竜／鏡竜 | 薄い翼＝**新規1枚** |

→ **新規は4枚程度**。トップビューの竜シルエットは AI 生成で賄える範囲
（`/gen-game-asset`／`C:\forge\ClaudeCodeForge`）。**人間製の素材が大量に要る案ではない。**

※**トップビュー厳守**。立面・ドームで描かないこと（過去に差し戻し実績あり）。

## 6. UI とアンロックへの波及

- **4択メニューは15種に耐えない**（`showSpeciesSelect` はカードを縦に並べるだけ）。
  グリッド＋スクロール、または**アンロック済みのみ表示**が必要。
- 解放は既存の `CHALLENGE_DEFS`／`evaluateChallenges` に接続する（next-steps §3-7 の
  「チャレンジ＝腕前で解く特別枠」と噛み合う）。初期解放は **鷲竜のみ**が自然。
- **専用カード**：1竜種あたり3〜4枚だと 15種で45〜60枚。`CARD_DEFS` の `weapon:` フィルタを
  `species:` に拡張して段階投入する。**Ⅰ〜Ⅲの9種ぶんだけ先に作る**のが現実的。

## 7. 未決の論点

1. **名前の路線**：本書は「生き物の姿」で統一した。別路線として
   **A) 漢語2字の機構名**（貫竜・掃竜・環竜…＝攻撃が読める／動きは読めない）、
   **B) 生き物＋属性の二重名**（氷の隼竜…＝情報量は最大だが冗長）がある。
2. **旋回半径の上限**：Ⅳ群（鯨竜157／亀竜127）は目安180pxの散らばりを超える見込み。
   `leaderPull` で締める前提だが、**実機で群れが画面から溢れないかは要検証**。
3. **止まれる竜（`minSpeed 0`）の重なり**：v0.33.1 で押し分けを入れたが、
   蜻蛉竜・蝶竜は混み合うと小刻みに震える（実測 約12回/秒/体）。機械的な竜なら味だが、
   **蝶竜は生物なので気になる可能性**。必要なら `turnRate` を有限にする。
4. **15種は多すぎないか**：動きが4系統（軽量／標準／重量／特殊）に集約されるなら、
   プレイヤーが違いを感じるのは実質4〜6種かもしれない。**Ⅰ〜Ⅲの9種で一度止めて判断**したい。
