## 1. ランの流れ

```
タイトル「はじめる」
  → 竜種を選ぶ（解放済みのみ）
  → [ステージ 1] 地域は自動で決まる（解放済みからランのシードで1つ）
  → [ステージ 2〜8] 地域を3択（解放済みからランダム3つ）
  → ステージ本編（今と同じ：警戒度4段・首都撃破でクリア・5〜20分）
  → ステージクリア（竜晶・踏破記録）
  → n < 8 なら次の時代へ／n = 8 ならラン完了
```

| 項目 | 仕様 |
|---|---|
| ステージ数 | 8（`RUN_STAGES`） |
| 時代 | ステージ n ＝ 時代 n（I 石器 → VIII 最終）。自分では選べない |
| 地域 | ステージ1は自動（v3.1.1・Shooter指示「選ばせない」）。ステージ2から、解放済みの地域からランダムで重複なし3つ。**直前のステージと同じ地域は出さない**。足りなければ出せる数だけ |
| 乱数 | 3択はラン用の `random()` で引く＝`?seed=` で同じ3択が出る。各ステージの地形シードは「ランのシード＋ステージ番号」から作る |
| 持ち越すもの | レベル・XP・三択強化（進化ノード含む）・特殊個体・竜種 |
| リセットするもの | **竜の数**（`stageStartFlockCount()` に戻す）、マップ、警戒度 |
| 初回ラン | 火竜固定。ステージ1は大陸固定。以降は通常どおり |

### 1.1 全滅と残機

| 項目 | 仕様 |
|---|---|
| 全滅 | 群れの生存スロットにいる竜が**全員ダウン中**になった瞬間 |
| 全滅したら | 残機 −1。**その場で3秒見せる**（v3.12.2。この間は誰も復活しない）。その後、リーダーを地域のスタート地点（`START_X/Y`）へ戻し、全竜を満タンで復帰させて周りに並べる。2秒の無敵 |
| 全滅の一文 | v3.13.0。見せ場の間、**最後にダウンした竜を落とした相手**を一文で出す（例「最後の火竜は騎士団に翼を裂かれ、大地へ還った」）。言い回しは手の種類（射抜く／爆炎／打撃／炎／瘴気／雷／光）ごとに数本から選ぶ。コミカルにしない。相手は移動敵・建物（時代兵器・役割の名、無ければ大きさ）・首都の大技（「首都の巨岩投擲」）。弾・危険地帯・レーザーは**出した時点の撃ち手を持ち歩く** |
| 残るもの | 群れの頭数・街の破壊状況・警戒度・首都の傷。**場所だけ戻る** |
| 残機 | 1ラン通しで3（ステージで回復しない）。0になったらラン終了（敗北リザルト） |
| 報酬 | 敗北でも、それまでに得た竜晶と解放は残る |

### 1.1c 警戒度ラッシュ（v3.16.0・Shooter指示）

> **v3.50.4（案帳 DT-472・Shooter指示）**：精鋭の追跡者の攻撃の苛烈さを ×2.5→×1.8（衝撃波の連発が強すぎた）。大型包囲・小型の大軍の敵は体力 ×2.5・攻撃の苛烈さ ×1.5（弱すぎた）。図鑑「その他」にラッシュ10種と襲撃隊の説明を載せた（数値は定数から引く）。

> **v3.51.0（案帳 DT-476・Shooter判定）竜狩りの銛**：ラッシュに11種目を足した。竜狩りの騎士（警戒度2〜4で4・5・6体、体力はステージごとに +50%）が群れの端の竜（特殊個体は狙わない）に銛を打ち込み、綱で秒速85pxで引きずる。騎士のもとまで引かれた竜は**ダウンではなく本当に減る**。放す方法は騎士を倒すことだけ（綱は切れない）。全部倒しても回復は無い。45秒で騎士は引き揚げる。減った竜の枠は、卵からかえる竜が使い直す（群れの上限を食いつぶさない）。

警戒度が上がるたびに（動員・総力戦・決戦の3回）、人間が竜卵の力で反撃してくる山場を1つ起こす。
- **選び方**：10種類からシード乱数で1つ選ぶ。同じステージの中では同じ種類を出さない。輸送隊は首都が残っているときだけ候補に入る。
- **流れ**：警戒度の帯とスローが引くまで2.4秒待つ → 予告1.3秒（名前と一言、方向のあるものは矢印） → 発動。
  - 発動中は画面上部に名前と残りのバーを出す。バーは、時間で区切る種類なら残り時間、敵を出す種類なら残りの敵の数。
- **打ち切り**：次の警戒度アップ・全滅・首都の陥落・タイトルへ戻ったときに打ち切る。再開には持ち越さない。
- **追加する敵の上限**：`TR_UNIT_CAP = [-, 24, 22, 12]`。決戦は普段の敵がすでに6倍居るので少なめ。

## 2. ステージ内のバランス：寄り道したぶん群れが勝つ

**原則（Shooter判断）**：敵は弱くしない。寄り道で増えるのは**湧く敵の数**。1体ずつの強さはあまり上げない。
群れは寄り道で強くなる（XP・卵・持ち越し）ので、差し引きで寄り道が得。
急ぐと「最初から最大段階」の首都・要塞に、育っていない群れで挑むことになる＝難しい。

| 変更 | 前 | 後（叩き台） |
|---|---|---|
| 最強モード（7割陥落で首都が本気） | 火力×2.2・連射×2.2・弾数+2・射程×1.45 | **廃止**。首都はラン中一定 |
| `POWER_TIER_BOOST` の HP | 1.0 / 2.6 / 4.2 / 6.5 | 1.0 / 1.3 / 1.6 / 2.0 |
| 同 火力 | 1.0 / 2.9 / 4.3 / 7.0 | 1.0 / 1.2 / 1.4 / 1.6 |
| 同 連射・弾数・射程 | 0.60〜0.36・+0〜2・×1.16〜1.40 | ほぼ据え置き（間隔 1.0/0.85/0.75/0.65、弾数 0/0/1/1、射程 1.0/1.05/1.10/1.15） |
| `TIER_MOVER_MULT`（動く敵の数） | 1.0 / 2.6 / 4.2 / 6.0 | **据え置き**（量の軸） |
| `TIER_MOVER_FEROCITY` | 1.0 / 1.35 / 1.75 / 2.25 | 1.0 / 1.15 / 1.3 / 1.45 |
| 要塞・首都区画の「最初から最大段階」 | あり | **残す**（直行への壁）。段階4の値が下がるぶん、要塞・首都の基準値を引き上げて直行の難しさを保つ |
| クリア★ | 最強モードなら★5、他は 1＋警戒度 | **クリア時間が短いほど★が多い**（急ぐのは難しい＝腕前の評価） |

## 3. 三択強化の中身

三択のプールは次の4種類だけになる。

| 種類 | 中身 | 出る条件 |
|---|---|---|
| 汎用 | 硬鱗（HP）・再生の潮（復帰）・吸引域・大繁殖・竜鱗共鳴（被ダメ減） | いつでも（上限まで） |
| **攻撃カテゴリ威力（新）** | 直撃の牙（直接 +12%）・烈火の喉（ブレス +12%）・爆ぜる心臓（爆発 +12%）。各 max 5、common | いつでも |
| 進化 | 今の竜種のツリー（§5）と、加入中の特殊個体のツリー（§6） | 前提を満たしたノード |
| 特殊個体の加入 | 今の `sp_*` カード | 解放済みで枠が空いているとき |

**三択から外すもの**：疾風（速度）・見渡す顎（ブレス角）・一斉突撃と突進5枚・武器別カード12枚・特殊個体の専用カード14枚・死んでいた `evo_*`。
武器別・専用カードの中身は進化ツリーの無分岐の段に吸収した。

> **v3.43.0（案帳 DT-128・Shooter指示）**：上の「汎用」と「攻撃カテゴリ威力」はレベルアップの三択から外し、§3.2 の**町の陥落で選ぶカード**へ移した。
> レベルアップの三択は「進化」と「特殊個体の加入」だけになる（特殊個体の強化が中心）。候補が足りないときは竜玉で埋める。

### 3.2 町の陥落で選ぶ強化（v3.43.0・案帳 DT-128）

レベルアップとは別に、**町が陥落するたびに**ステージ限定の強化を1つ選ぶ。陥落を「手応え＋報酬」の単位にするため（DT-128 のテンポ計測で、陥落が均等に来るのに見返りが無く、どれも山にならなかった）。

- **出し方**：陥落した瞬間にゲームを**完全に止め**、画面の中央に3枚を横に並べる。取るか「見逃す」を選ぶ。同時に複数の町が落ちたら1つずつ出す。
- **効き目**：取ったカードは**そのステージだけ**効く（`stageCards`。ステージが変わると消える。途中セーブには残す）。取ったカードのアイコンは左上に常に並べる（重ねたら ×数）。
- **警戒度**：（v3.43.0〜v3.43.3）カードを取った陥落だけを数えていた。v3.44.0 で、どの陥落でも数える形に戻した（下記）。
- **ゲージ**：警戒度は画面上段に目盛りで出す（次の段階までに要る陥落の数だけ並び、取った陥落で1つ埋まる。16より多い地域は帯）。
- **候補**（上限まで取ったものは出ない。特殊個体向けは特殊個体を連れているときだけ）：

| カード | 効き目 | 上限 |
|---|---|---|
| 硬鱗・再生の潮・吸引域・大繁殖・竜鱗共鳴・直撃の牙・烈火の喉・爆ぜる心臓 | 今までの通常強化（群れ全体） | 今までと同じ |
| 特殊個体の牙／喉／膂力 | 特殊個体の直接攻撃・ブレス・衝撃力 +60%（群れ全体の強化と別に重なる） | 各3 |
| 特殊個体の鱗 | 特殊個体のHP +80% | 3 |
| 特殊個体の再起 | 特殊個体の復活時間 ×0.75 | 2 |
| 双子の卵 | 卵から竜が2体ずつかえる | 1 |
| 形見の卵 | 竜が落ちると半分の確率でその場に卵を残す | 1 |
| 捨て身の賭け | 群れのHP 半分・攻撃 2倍 | 1 |
| 逆襲の血 | ラッシュの間、群れの攻撃 +50% | 2 |

- **v3.43.1（Shooter指示）**：通常強化（再生の潮を除く）は効き目を倍にした（v3.43.3 で大繁殖も据え置きに戻した：上限 +25・竜 +5）（陥落カード1枚を2枚分に数える `genCount`）。重ねすぎる分は上限を下げた：硬鱗3・竜鱗共鳴2・攻撃カテゴリ威力3。レベルアップの三択には特殊個体の強化が複数並ぶようにした。左上のアイコンをタップすると、取ったカードの一覧が出る（5秒かもう一度タップで閉じる）。

### 3.1 攻撃カテゴリの対応表

攻撃は v2.10.0 から `hit = { direct, blast, shot, impact }` で当たっている。カテゴリ威力カードはこの分類にそのまま掛かる
（竜側から敵・建物への当たりだけ。`hitMover` / `hitBuilding` で掛ける）。

| カテゴリ | 該当する攻撃 |
|---|---|
| **直接** `direct` | 体当たり・突進（全竜種）、爪撃（緋竜）、刃翼（隼竜）、衛星蜂（蜂竜）、落下叩きつけ（ガーゴイル）、舌撃（蛙竜）、止まらぬ鉄塊、穿つ楔の体当たり |
| **ブレス** `shot` | 炎息（火竜・UFO）、氷槍（氷竜）、影弾の直撃（影竜）、羽根散弾（燕竜）、星屑（彗星竜）、極光、光剣、暴食の撃ち返し |
| **爆発** `blast` | 影弾の爆風、絨毯爆撃（爆竜・惑竜）、ロケットマン |

煽る風は自分ではダメージを出さない（通った竜の「次の直接攻撃」を強める）ので、直撃の牙と相性が良い。

### 5.1 共通の骨格

```
L1 → L2 → L3 → L4（無分岐。見た目は変わらない）
                 ├→ 分岐 A ─→ A6 → A7      （分岐を取った瞬間に色・大きさが変わる）
                 ├→ 分岐 B ─→ B6 → B7
                 └→ 分岐 C（種またぎ進化）─→ C6 → C7   （特殊個体の条件を満たしたときだけ選択肢に出る。§5.3）
```

- 1種9ノード＋種またぎの分岐C。分岐は A／B／C のどれか1つだけ（取ったら他は出ない）
- **進化はステージ中にその場で起きる**。分岐・種またぎのカードを取った瞬間、群れ全体が変身演出とともに姿を変える。以降に孵る竜も変身後の姿
- 無分岐の段は common、分岐と種またぎは star（★）
- **カードの見せ方（v3.4.2・Shooter指示）**：無分岐の段は「火竜 Lv2 / Lv3 / Lv4 / Lv Max」と段階で呼ぶ（竜種を選んだ時点が Lv1、

- **首都**：巨大な高層ビル（屋上のヘリポートを真上から見た絵）。首都区画の建物は道路に掛からない所だけに建てる
- **車（道路の上しか走らない）**：交差点から交差点へ走り、交差点で曲がる。曲がる向きは車列の番号と交差点の位置から決めるので、
  同じ車列の車は同じ角で同じ向きに曲がる＝列のまま流れる（乱数を使わないのでランの再現性も崩れない）。
  進む向きの右側の車線を走る。首都区画の交差点・抜いた区間には入らない。群れは追わない
  - 渋滞の車／箱バン：撃たない的。約1700台。前の車に近づくと止まる（詰まると渋滞になる）。
    列の長さは1台が70%、2台が22%、3〜4台が5%、5〜7台が3%（v3.24.0。長い列はたまにいるアクセント）。車間54px。
    列は交差点へ向かう区間の途中に湧かせ、同じ車線の同じ区切りには1列だけ。
    v3.22.0 は車間26pxでムカデに見えた → 車間を広げ、ムカデの見た目は別の敵の案（案帳 DT-043）に残した
  - パトカー：10台。走りながら撃つ
  - 戦車：大通りだけを走る硬い敵。2台＋時代3つごとに1台。車体とは別に砲塔が群れへ旋回し、向ききったら主砲（予告円つきの広い榴弾）、
    砲塔の向きに機銃の連射。回り込めば砲塔が追いつかない
- **攻撃ヘリ**：道路に縛られず飛ぶ大物。群れの周りを回りながら機首を群れへ向け、機関砲の連射とロケットの斉射（予告円つき）を浴びせる。
  回転翼は絵ではなく描画で回す。首都の守り（最初から2機）と、首都に近づいたときの増援（1機から、2回ごとに1機増えて最大3機）はヘリだけ
  - 慣性（v3.27.0・Shooter指示「ビタ付けでこちらを向くので強すぎる」）：速度は加速度70px/s²までしか変わらない（向きを変えると膨らむ）。

    実測：群れが半径250の円を回り続けると、機首のずれは中央値17°、撃てる向きにいるのは時間の半分。ずれたまま撃つ機関砲は外れやすい
  - v3.30.0（Shooter判定「全然こっちを見なくなった。最初の感じに近く」）：角速度1.9rad/s・角加速度4.0rad/s²・照準のゲイン4.5、撃つのは14°以内。

### 10.3e 光線の高原（v3.34.0・案帳 DT-015・1回目）

見晴らしのよい高原（8400×8400・正方形）。町は大陸と同じ並べ方で、町の外の野に**光線の塔**が14本立つ。首都は中央の**プリズム塔**。最初から選べる。

  - 予告1.5秒：赤の点線が群れを追う（角速度3.0rad/秒まで）。最後の0.4秒は向きが止まり、点線が太くなって点滅する＝ここで横へ避ける

  - 休む1.4秒：その後、群れが1900px以内ならまた予告から（遠ければ見失う）

### 10.3f 英雄の国（v3.35.0・案帳 DT-107・1回目）

人類が英雄を立てて竜に立ち向かう国（8400×8400・正方形）。地図は大陸と同じ作りで、中心に王城（首都）。地域の仕掛けは英雄ひとつ。最初から選べる。
