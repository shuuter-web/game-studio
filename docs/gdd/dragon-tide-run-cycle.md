## 1. ランの流れ

```
タイトル「はじめる」
  → 竜種を選ぶ（解放済みのみ）
  → [ステージ 1] 地域は自動で決まる（解放済みからランのシードで1つ）
  → [ステージ 2〜8] 地域を3択（解放済みからランダム3つ）
  → ステージ本編（今と同じ：警戒度4段・首都撃破でクリア・5〜20分）
  → ステージクリア（竜晶・踏破記録）
  → n < 8 なら次の時代へ／n = 8 ならラン完了
```

| 項目 | 仕様 |
|---|---|
| ステージ数 | 8（`RUN_STAGES`） |
| 時代 | ステージ n ＝ 時代 n（I 石器 → VIII 最終）。自分では選べない |
| 地域 | ステージ1は自動（v3.1.1・Shooter指示「選ばせない」）。ステージ2から、解放済みの地域からランダムで重複なし3つ。**直前のステージと同じ地域は出さない**。足りなければ出せる数だけ |
| 乱数 | 3択はラン用の `random()` で引く＝`?seed=` で同じ3択が出る。各ステージの地形シードは「ランのシード＋ステージ番号」から作る |
| 持ち越すもの | レベル・XP・三択強化（進化ノード含む）・特殊個体・竜種 |
| リセットするもの | **竜の数**（`stageStartFlockCount()` に戻す）、マップ、警戒度 |
| 初回ラン | 火竜固定。ステージ1は大陸固定。以降は通常どおり |

### 1.1 全滅と残機

| 項目 | 仕様 |
|---|---|
| 全滅 | 群れの生存スロットにいる竜が**全員ダウン中**になった瞬間 |
| 全滅したら | 残機 −1。**その場で3秒見せる**（v3.12.2。この間は誰も復活しない）。その後、リーダーを地域のスタート地点（`START_X/Y`）へ戻し、全竜を満タンで復帰させて周りに並べる。2秒の無敵 |
| 全滅の一文 | v3.13.0。見せ場の間、**最後にダウンした竜を落とした相手**を一文で出す（例「最後の火竜は騎士団に翼を裂かれ、大地へ還った」）。言い回しは手の種類（射抜く／爆炎／打撃／炎／瘴気／雷／光）ごとに数本から選ぶ。コミカルにしない。相手は移動敵・建物（時代兵器・役割の名、無ければ大きさ）・首都の大技（「首都の巨岩投擲」）。弾・危険地帯・レーザーは**出した時点の撃ち手を持ち歩く** |
| 残るもの | 群れの頭数・街の破壊状況・警戒度・首都の傷。**場所だけ戻る** |
| 残機 | 1ラン通しで3（ステージで回復しない）。0になったらラン終了（敗北リザルト） |
| 報酬 | 敗北でも、それまでに得た竜晶と解放は残る |

## 2. ステージ内のバランス：寄り道したぶん群れが勝つ

**原則（Shooter判断）**：敵は弱くしない。寄り道で増えるのは**湧く敵の数**。1体ずつの強さはあまり上げない。
群れは寄り道で強くなる（XP・卵・持ち越し）ので、差し引きで寄り道が得。
急ぐと「最初から最大段階」の首都・要塞に、育っていない群れで挑むことになる＝難しい。

| 変更 | 前 | 後（叩き台） |
|---|---|---|
| 最強モード（7割陥落で首都が本気） | 火力×2.2・連射×2.2・弾数+2・射程×1.45 | **廃止**。首都はラン中一定 |
| `POWER_TIER_BOOST` の HP | 1.0 / 2.6 / 4.2 / 6.5 | 1.0 / 1.3 / 1.6 / 2.0 |
| 同 火力 | 1.0 / 2.9 / 4.3 / 7.0 | 1.0 / 1.2 / 1.4 / 1.6 |
| 同 連射・弾数・射程 | 0.60〜0.36・+0〜2・×1.16〜1.40 | ほぼ据え置き（間隔 1.0/0.85/0.75/0.65、弾数 0/0/1/1、射程 1.0/1.05/1.10/1.15） |
| `TIER_MOVER_MULT`（動く敵の数） | 1.0 / 2.6 / 4.2 / 6.0 | **据え置き**（量の軸） |
| `TIER_MOVER_FEROCITY` | 1.0 / 1.35 / 1.75 / 2.25 | 1.0 / 1.15 / 1.3 / 1.45 |
| 要塞・首都区画の「最初から最大段階」 | あり | **残す**（直行への壁）。段階4の値が下がるぶん、要塞・首都の基準値を引き上げて直行の難しさを保つ |
| クリア★ | 最強モードなら★5、他は 1＋警戒度 | **クリア時間が短いほど★が多い**（急ぐのは難しい＝腕前の評価） |

## 3. 三択強化の中身

三択のプールは次の4種類だけになる。

| 種類 | 中身 | 出る条件 |
|---|---|---|
| 汎用 | 硬鱗（HP）・再生の潮（復帰）・吸引域・大繁殖・竜鱗共鳴（被ダメ減） | いつでも（上限まで） |
| **攻撃カテゴリ威力（新）** | 直撃の牙（直接 +12%）・烈火の喉（ブレス +12%）・爆ぜる心臓（爆発 +12%）。各 max 5、common | いつでも |
| 進化 | 今の竜種のツリー（§5）と、加入中の特殊個体のツリー（§6） | 前提を満たしたノード |
| 特殊個体の加入 | 今の `sp_*` カード | 解放済みで枠が空いているとき |

**三択から外すもの**：疾風（速度）・見渡す顎（ブレス角）・一斉突撃と突進5枚・武器別カード12枚・特殊個体の専用カード14枚・死んでいた `evo_*`。
武器別・専用カードの中身は進化ツリーの無分岐の段に吸収した。

### 3.1 攻撃カテゴリの対応表

攻撃は v2.10.0 から `hit = { direct, blast, shot, impact }` で当たっている。カテゴリ威力カードはこの分類にそのまま掛かる
（竜側から敵・建物への当たりだけ。`hitMover` / `hitBuilding` で掛ける）。

| カテゴリ | 該当する攻撃 |
|---|---|
| **直接** `direct` | 体当たり・突進（全竜種）、爪撃（緋竜）、刃翼（隼竜）、衛星蜂（蜂竜）、落下叩きつけ（ガーゴイル）、舌撃（蛙竜）、止まらぬ鉄塊、穿つ楔の体当たり |
| **ブレス** `shot` | 炎息（火竜・UFO）、氷槍（氷竜）、影弾の直撃（影竜）、羽根散弾（燕竜）、星屑（彗星竜）、極光、光剣、暴食の撃ち返し |
| **爆発** `blast` | 影弾の爆風、絨毯爆撃（爆竜・惑竜）、ロケットマン |

煽る風は自分ではダメージを出さない（通った竜の「次の直接攻撃」を強める）ので、直撃の牙と相性が良い。

## 5. 竜の進化ツリー

> **v3.11.0（現行）：竜のレベルはレベルアップのたびに自動で +1**（Shooter指示。三択では選ばない）。
> 三択は特殊個体（レベル・分岐・突然変異）と汎用の強化だけ。
> レベルアップはラン全体で約60回なので、**竜の上限を Lv60** にし、1レベルあたりの伸びを半分にした（Lv60 で以前の Lv30 と同じ強さ）。
> 竜の分岐は **Lv20・Lv40**、竜の突然変異は **Lv10・Lv30・Lv50**（どちらも以前の2倍）。
> その段に着いたレベルアップは**竜の画面だけ**（分岐＝A／B、突然変異＝「このまま」か突然変異）で、三択は出ない。
> 特殊個体は今まで通り（上限30・分岐 Lv10・突然変異 Lv5・15・25・合成 Lv10）。

> **v3.6.0 で「竜のレベル・特殊個体のレベル」に作り替えた（Shooter判断「行き来を考えると、同じレベルで行き来するほうが調整しやすい」）。**
>
> - 竜は**竜のレベル 1〜30** を持つ。進化カード1枚で +1（3択の1枠目は竜のカード）。**種またぎしても同じレベル**のまま別の竜種になり、戻っても同じ
> - 能力は竜種ごとの「伸び方の傾き」（旧 L1〜L4 の合計）× (Lv−1)/9。Lv10 で旧 L1〜L4 と同じ、Lv30 で約3.2倍。数で数える効果（同時照射・貫通・弾数など）は切り捨て。30段の表は手で書かない
> - 同系統の分岐は **Lv10（A／B）と Lv20（その分岐の型を2つから1つ）**。分岐は竜種ごとに覚えていて、種またぎで戻ってきても同じ
>   （Lv20 の型は旧ツリーの続き1段ぶん ×2）。分岐を選ぶまで竜のレベルは上がらない。「今は見送る」でその回だけ通常の3択
> - 種またぎは特殊個体の条件（2体）を満たしていれば**いつでも**、竜の枠に★カードで出る。引き継ぎ・生まれつきの補正は無し（同じレベルだから要らない）
> - 特殊個体は**種類ごとに特殊個体のレベル 1〜30**（3択の2枠目）。Lv10 で A／B。種またぎ（群れの攻撃カテゴリで別の種類へ）は**同じレベルのまま**移る（移り先のほうが高ければそちら）
> - 竜種・特殊個体を足すときは、SPECIES_EVO_SPEC（傾きの元の L1〜L4、A／B とその続き2つ）・CROSS_EVOLUTIONS、SPECIAL_EVO_SPEC・SPECIAL_CROSS に行を足すだけ
> - 以下（v3.5.0 の「形態のつながり」の説明と §5.1〜§6 の表）は、傾き・分岐の効果値の出典として残す


> **v3.5.0 で「形態のつながり」に作り替えた（Shooter「どんどん進化して欲しい」）。下の §5.1〜§6 の表は効果値の出典として残す。**
>
> - すべての姿（元の竜種・分岐 A/B の姿・種またぎの進化形）を**形態**として同じ扱いにする。各形態は **Lv2 → Lv Max の2段**のあと分岐点に着く
>   （元の L1+L2 を Lv2、L3+L4 を Lv Max にまとめた。合計の強さは同じ。A6/A7・C6/C7 は各姿の Lv2/Lv Max）
> - 分岐点：元の竜種＝自分の A／B ＋種またぎ、A／B の姿＝種またぎ、進化形＝別の竜種への種またぎ → **ラン中に何度でも竜種が変わる**
> - 種またぎの条件は**特殊個体2体**（ロケットマン×2→影竜、ロケットマン＋止まらぬ鉄塊→爆竜、止まらぬ鉄塊×2→ガーゴイル、煽る風×2→燕竜、
>   穿つ楔×2→隼竜、煽る風＋穿つ楔→緋竜、暴食×2→蛙竜、極光＋光剣→彗星竜、光剣×2→UFO）。どの形態からでも（自分の竜種へは行かない）
> - 進化形の生まれつき＝進化先の Lv2＋Lv Max ＋ 威力 +20% ×（この種またぎを含めたラン中の分岐の数）。深い段から乗り換えても弱くならない
> - 竜が分岐点に着いた次のレベルアップは**「進化の分岐」画面**（A／B／種またぎを全部並べる）。「今は見送る」で1回だけ通常の3択
> - 三択の**1枠は進化カード専用**（竜・特殊個体の Lv、特殊個体の分岐）。特殊個体の加入カードの重みを 3→6
> - **特殊個体**も Lv2 → Lv Max → 自分の A／B ＋**種またぎ（別の特殊個体へ）**。条件は**群れの竜の攻撃カテゴリ**：
>   光剣（爆発→ロケットマン／直接→穿つ楔）、止まらぬ鉄塊（直接→穿つ楔／ブレス→極光）、暴食（ブレス→極光／爆発→ロケットマン）、
>   ロケットマン（ブレス→光剣／直接→止まらぬ鉄塊）、煽る風（直接→止まらぬ鉄塊／爆発→暴食）、穿つ楔（ブレス→煽る風／爆発→光剣）、
>   極光（爆発→暴食／直接→煽る風）。**その種類が全員変わり**、変わった先は Lv Max から始まる。A／B の姿からも種またぎできる
> - 竜の進化が特殊個体の種またぎ条件（カテゴリ）を動かし、特殊個体の種またぎが竜の種またぎ条件（頭数）を動かす
> - **特殊個体は7体とも最初から使える**（§7.3 の条件は今後足す特殊個体に使う）
> - 実測（seed=12345）：ステージ1の建物XPは約31,700＝6割破壊で14回・全破壊で19回のレベルアップ。
>   進化カードを優先して選ぶと、種またぎが選べるようになるまで4回（300回試行の全部）＝**ステージ1の序盤で届く**
> - 竜種・特殊個体を足すときは、SPECIES_EVO_SPEC／EVOLVED_FORMS／CROSS_EVOLUTIONS（竜）、SPECIAL_EVO_SPEC／SPECIAL_CROSS（特殊個体）に行を足すだけ


### 5.1 共通の骨格

```
L1 → L2 → L3 → L4（無分岐。見た目は変わらない）
                 ├→ 分岐 A ─→ A6 → A7      （分岐を取った瞬間に色・大きさが変わる）
                 ├→ 分岐 B ─→ B6 → B7
                 └→ 分岐 C（種またぎ進化）─→ C6 → C7   （特殊個体の条件を満たしたときだけ選択肢に出る。§5.3）
```

- 1種9ノード＋種またぎの分岐C。分岐は A／B／C のどれか1つだけ（取ったら他は出ない）
- **進化はステージ中にその場で起きる**。分岐・種またぎのカードを取った瞬間、群れ全体が変身演出とともに姿を変える。以降に孵る竜も変身後の姿
- 無分岐の段は common、分岐と種またぎは star（★）
- **カードの見せ方（v3.4.2・Shooter指示）**：無分岐の段は「火竜 Lv2 / Lv3 / Lv4 / Lv Max」と段階で呼ぶ（竜種を選んだ時点が Lv1、
  分岐の直前が Lv Max）。分岐後の続きも「焔竜 Lv2 → Lv Max」。進化カードは「竜の進化」「○○の進化」「★ 進化 ─ 分岐」「★ 種またぎ進化」の札・
  色の縁取り・段階の目盛り（●●○○）で、通常の強化カードと見分けられるようにする
- 効果の書き方：`dmg` 威力、`range` 射程（範囲型は半径）、`rate` 発射間隔の短縮、`hp` 竜のHP、`speed` 速度、

## 8. 竜晶（ラン外で買う強化）

竜晶は**選択肢を広げるもの**にだけ使う。難度を直接崩す数値の積み上げ（HP+15% 等）は置かない。
今の恒常ツリー（26ノード）は撤去する（未サービスインなので返金・移行はしない）。

| 封印 | 三択のカード1枚をそのランから消せる回数 +1（「封印」を押してからカードを押す。進化カードは封印できない） | 2 | 120 / 240 |
