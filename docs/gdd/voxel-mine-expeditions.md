# 掘り島 — 飛空艇遠征への拡張

## 目標

浮島を掘る手触りを保ちながら、限られた燃料で持ち帰るものを選び、飛空艇と装備を育てて未知の空域へ進むゲームにする。

基本ループは「拠点で準備 → 行き先選択 → 採掘・探索 → 帰還 → 換金・強化 → 新航路」。2026-09-20にユーザーがこの方向と段階的な実装を承認。

## 第1段階：燃料と遠征（今回の実装）

- 拠点から出発し、帰還すると拠点へ戻る。工房は拠点で利用する。
- 有効な採掘1回を1ターン、燃料1とする。ひびを入れるだけの打撃も消費する。
- 空振り、硬さ不足、視点操作、メニュー、思考時間は消費しない。範囲採掘と時間差連鎖は追加消費しない。
- 燃料は浮遊・採掘作業用。帰還用燃料は別枠という設定。0になったら最後の採掘と連鎖の報酬を処理し自動帰還する。
- 任意帰還でも獲得素材を保持する。出航時に無料で満タンにし、費用不足で出航不能にならないようにする。
- 同じ島へ再訪できる。島の形は世界の種と行き先に対して固定、出航ごとに鉱床を再生成する。再読込だけでは再生成・補給しない。
- 燃料タンクと航路を素材で強化する。最初の行き先は草・土・石・銅、次は結晶が得られる島。
- 既存の鉄・金・黒曜・星核への進行を失わないよう、航路は計6島まで用意する。開放費用に未開放の島でしか得られない素材を要求しない。
- リアルタイムの連打コンボを、一撃とその鉱脈連鎖のまとまりによるボーナスに変更する。観察時間をペナルティにしない。
- 旧セーブの在庫・採掘強化を引き継ぐ。燃料、遠征状態、損傷、予約済み連鎖を保存し再開できるようにする。

## 後続の拡張

1. 換金品：種類・品質がランダムな古代の品を掘り出し、拠点で換金。通常素材との取得判断を作る。
2. 特性素材：つるはしと飛空艇に装着し、硬い鉱石、鉱脈、燃費など目的別の装備を組む。最高数値一択にせず相性を作る。
3. モンスター：採掘ターンで攻撃予告が進む。足場破壊など採掘で対処する。攻撃対象・敗北ペナルティはこの段階で設計する。
4. 遺跡：世界の秘密の記録、座標、航行技術を収集し、探索が次の旅につながるようにする。

## 最大の賭け

採掘回数制限が窮屈さだけにならず、「掘る順番を考える」「強化して再訪したい」を生むか。初期燃料、容量増加、最初の強化費用は実プレイで調整する。機械検証では資源保持・詰まり防止・同一seed再現を判定する。
