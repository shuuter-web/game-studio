### 設計コンセプト（v0.6.1）

**各ステージ＝1本の独立したビルド構築ラン**。
毎ステージ「群れ10体・Lv1」から始まり、薙いで・増やして・3択で進化させ、城壁を破ってボスを落とす。
4つの時代で4回、違うビルドを組む楽しさが生まれる（石器は純ビームで押し切り、近世要塞はミサイル型で壁越し攻略、など）。
塊魂型の「毎回ゼロから雪だるま」の快感構造（v0.5.2 の現行挙動）をそのまま活かす。

- 「毎ステージリセット」はレベル・強化カード・進化も含む**完全リセット**とする
  （群れ数だけでなくビルドも組み直す。ステージ×ビルドの相性が攻略の幅になる）
- リセットされない要素: 累計スコア類（撃破数・総XP）とベスト記録のみ（§2.4）

## 1. コアループ（v0.6.1）

```
【秒単位】 線を引く → 群れが薙ぐ → 建物が砕けXPジェムが群れに吸い込まれる
【分単位】 レベルアップ → スローモー＋3択カード（指は離さない）→ 群れが進化（色と武器が一斉に変わる）
【面単位】 城壁をブリーチしてボス城塞を攻略 → 次の時代へ（群れ・ビルドはリセット、景色一新）
【1プレイ】 4つの時代を制覇 → ALL CIVILIZATIONS CONQUERED → リザルト
```

- 「ちょっと気持ちいい」= スイープ＋XPジェム吸引（破壊のたびに光が群れへ流れ込む）
- 「すごく気持ちいい」= ①3択進化で群れ全体の色が一斉に変わる瞬間 ②城壁ブリーチで雪崩れ込む瞬間

## 2. ゲーム全体フロー

### 2.1 画面遷移

```
[タイトル] → タップ → [STAGE 1 → 2 → 3 → 4] → 制覇 → [リザルト] → [タイトル]
```

| 画面 | 内容 |
|---|---|
| タイトル | ロゴ＋「タップで開始」＋ベスト記録（クリア時間 / 総撃破数）。初回のみ線を引くジェスチャーヒント |
| ラン | 全4ステージ（既存の石器→古代→中世→近世） |
| リザルト | クリア時間 / 総撃破数 / 最終ステージのビルド（進化型と取得カード一覧）/ 最大群れ数 |

### 2.2 クリアとゲームオーバー

- **ステージクリア**: ボス城塞の撃破（現行踏襲）。残存建物の掃討は任意（XP・卵稼ぎ）
- **エンディング**: STAGE 4 ボス撃破 → 「ALL CIVILIZATIONS CONQUERED」演出 → リザルト
- **ゲームオーバーなし（確定）**: 全個体が同時にダウンしても順次復帰するだけで、敗北演出は出さない
  （v0.3 の「失敗は罰でなく一瞬の陰り」哲学を維持）。
  現行の `triggerDefeat()` / `checkGameConditions()` / SCATTERED オーバーレイは**削除**する

### 2.3 想定プレイ時間

1ステージ 4〜7分 × 4 ＝ **1プレイ約20〜30分**。qa-engineer のプレイテストで実測し §9 の密度で調整。

### 2.4 記録（localStorage）

ベストクリア時間・総撃破数・クリア済みフラグのみ保存。**ラン中断セーブは作らない**（確定）。

## 5. XP・レベル・3択強化システム（ステージ内完結）

### 5.1 XP の獲得

破壊した対象から **XPジェム**（光の粒）が飛び出し、最寄りの群れ個体へ自動吸引される
（吸引半径120px・吸引速度600px/s。取り損ねなし）。

| 撃破対象 | 基礎XP |
|---|---|
| tiny | 1 |
| small | 2 |
| medium | 8 |
| large | 20 |
| 首都建物（capital） | 30 |
| 城壁セグメント | 12 |
| 移動敵 | 60〜150（種別 §7） |
| ボス | 300（クリア演出前に吸収） |
| 群れ上限到達後の卵 | XP+10 に変換（拾って無駄がない） |

ステージごとの XP 倍率は設けない（レベルもリセットされるため。後半面は建物数と大型比率が増える分だけ自然にテンポが上がる）。

### 5.2 レベル曲線（1ステージ内）

```
必要XP(Lv n → n+1) = 25 × 1.45^(n-1)   （端数切り上げ）
```

| Lv遷移 | 必要XP | 累計XP | 想定タイミング |
|---|---|---|---|
| 1→2 | 25 | 25 | 開始60〜90秒（最初の3択を早めに体験させる） |
| 2→3 | 37 | 62 | 序盤 |
| 3→4 | 53 | 115 | 序盤〜中盤（★進化が出始める） |
| 5→6 | 111 | 302 | 中盤 |
| 7→8 | 233 | 646 | 終盤（城塞攻略前） |
| 9→10 | 489 | 1,368 | 全掃討プレイ時のみ到達 |

目標: **1ステージで Lv7〜9 到達（3択を6〜8回）**。曲線の実測調整は system-designer に委譲。

### 5.3 レベルアップ演出と3択UI（v0.6.2で非モーダル化）

**時間停止は廃止**（プレイテストで「流体感をぶった切る」と判明）。スローモー方式に変更:

1. フラッシュ＋咆哮＋**ワールドが0.25倍速のスローモーに**（イージングで滑らかに減速）
2. カード3枚は**画面下部**に縦積み（縦持ち片手の親指で届く。背後の暗転は下部グラデのみ）
3. **線描画はスロー中も継続**（カード領域外は通常どおり誘導できる。指を離す必要がない）
4. カード: アイコン＋名前1行＋効果1行（全文 i18n キー経由）
5. タップで即選択→通常速度へ復帰。**7秒選ばなければスローだけ解除**され、カードは選ぶまで下部に残る
6. リロール・スキップなし。ゲームオーバーが存在しないため選択中の被弾リスクは実質ゼロ

### 5.4 強化カードプール

レアリティ: ◇コモン（重み10）/ ◆レア（重み4）/ ★進化（重み3、条件付き出現）。
ステージ内でのみ有効（クリアで全消去）。

**A. 群れ強化**

| カード | 効果 | 重複取得 |
|---|---|---|
| ◇ 硬鱗 | 個体最大HP +20% | 4回まで |
| ◇ 疾風 | 群れ移動速度 +8% | 3回まで |
| ◇ 再生の潮 | ダウン復帰時間 -15% | 3回まで |
| ◇ 吸引域 | XP吸引半径 +40% | 2回まで |
| ◆ 大繁殖 | 群れ上限 +25（即時に卵5個分を無償孵化） | 2回まで |
| ◆ 竜鱗共鳴 | 被投射ダメージ -12% | 3回まで |

**B. 武器強化（現在の武器タイプに対応するものだけ出現）**

| カード | 効果 | 重複 |
|---|---|---|
| ◇ 火勢/氷威/影炸/剛爪 | 現在の武器のダメージ +15% | 各4回 |
| ◇ 射程延伸 | 現在の武器の射程 +15%（MELEE除く） | 3回 |
| ◆ 連射機構 | BULLET/MISSILE の発射間隔 -18% | 3回 |
| ◆ 多重照射 | BEAM の同時照射対象 +1 | 2回 |
| ◆ 貫通弾 | BULLET の貫通数 +1 | 3回 |
| ◆ 広域炸裂 | MISSILE の爆発半径 +30% | 3回 |

**C. 進化（★）— 群れ100%の全転換**

| カード | 出現条件 | 効果 |
|---|---|---|
| ★ 氷竜の血 | Lv3以上 | 群れ**全個体**が氷竜（BULLET）に転換 |
| ★ 影竜の血 | Lv4以上 | 群れ**全個体**が影竜（MISSILE）に転換 |
| ★ 緋竜の血 | Lv3以上 | 群れ**全個体**が緋竜（MELEE）に転換 |

- **全転換方式（v0.6.1 確定）**: 混成なし。群れは常に単一タイプで、進化のたび全員の色が一斉に変わる
  （fire/ice/shadow の既存パレットを充当。緋竜用に fire の高彩度変種を1枚 graphics-engineer へ発注）
- **転換は何度でも可**（★カードが出れば別タイプへ引き直せる）。ただし現在と同タイプの★は出ない
- **B群の武器強化はタイプ別に保持**: 転換で消えず、そのタイプに戻れば効く
  （例: BEAM強化3枚→氷竜転換→BULLET強化2枚→ビームに戻すとBEAM強化3枚が復活）。
  「転換したら積み上げが消える」ストレスを防ぎつつ、転換の決断を軽くする
- 未転換（純BEAM）はそれ自体が有効ビルド。★を取らなければ A/B カードが厚く出る

### 5.5 抽選ルール

- 3枚は重み抽選・重複なし。取得上限に達したカードはプール除外
- ★は3枚中1枚まで
- プールが痩せた場合は「◇ 竜玉」（XP+50）を補充カードとして無限供給

## 6. 武器タイプ仕様

群れは常に単一の `attackType`（BEAM / BULLET / MISSILE / MELEE）を持つ（§5.4-C 全転換方式）。
ステージ開始時は BEAM。数値は基礎値（強化カードのみで成長）。

### 6.1 BEAM（火竜・現行ブレス）

| 項目 | 値 | 備考 |
|---|---|---|
| 射程 | 80px | 現行踏襲 |
| DPS | 3.0/s 持続照射 | 現行踏襲 |
| 対象 | 最寄り建物1つ（強化で+1） | |
| 役割 | 密集市街の面制圧。群れの厚み＝DPSの基準武器 |

### 6.2 BULLET（氷竜・直進弾丸）

| 項目 | 値 |
|---|---|
| 射程（射出距離） | 220px |
| 弾速 | 400px/s（直進・非追尾） |
| ダメージ | 6（単発） |
| 発射間隔 | 1.2s |
| 貫通 | 1体（強化で最大4） |
| 特記 | **城壁を貫通しない**（壁に当たり壁にダメージ） |
| 役割 | アウトレンジと攻城槌。壁を削る速度は全武器最速 |

### 6.3 MISSILE（影竜・加速ホーミング）

| 項目 | 値 |
|---|---|
| 射程（ロックオン距離） | 300px |
| 初速→最高速 | 60px/s → 500px/s（加速度 600px/s²） |

| ダメージ | 15 ＋ 爆発半径30pxに範囲50% |
| 発射間隔 | 2.5s |
| 特記 | **城壁を飛び越える**（唯一の壁越し攻撃） |
| 役割 | 高価値目標の狙撃と城内攻撃。近世要塞（ゲート1）で輝く |

### 6.4 MELEE（緋竜・直接攻撃特化）

| 項目 | 値 | 現行比 |
|---|---|---|
| 体当たりダメージ | 25（単発） | 約5倍 |
| 体当たりクールダウン | 0.35s | 短縮 |
| 個体最大HP | +50%（45） | 前線適性 |
| 被ノックバック | 無効 | 突っ込み続ける |
| 遠隔攻撃 | なし | — |
| 役割 | 群れ＝刃。線の引き方が攻撃そのものになる操作派向け。壁も轢き砕く |

### 6.5 バランス骨子

- 純BEAM を基準DPS 1.0 とし、各型は状況特化で 0.9〜1.4 に振れる
  （壁面: BULLET/MELEE ＞ BEAM、密集市街: BEAM 最強、点在ボス級・壁内: MISSILE）
- 「進化しないと詰む」は作らない。STAGE 4 も純BEAMで（時間はかかるが）クリア可能であること
- DPS検証テーブルは system-designer が実装前に作成（§13）

## 7. 移動敵ユニット（動く要塞）

### 7.1 設計原則

- **遅い・硬い・高報酬**。追いかけっこにしない（低速の巡回/行進のみ、執拗に追わない）
- ミニマップに専用アイコンで常時表示。撃破で XP大＋卵2〜3個ドロップ
- 出現数はステージ固定: 1 / 2 / 3 / 4 体（§4）

### 7.2 文明別ユニット表

| 文明 | ユニット | 移動 | HP | 攻撃 | XP |
|---|---|---|---|---|---|
| 石器 | 巨獣の群像（マンモス隊） | 2点間往復 20px/s | 120 | 踏鳴らし: 半径100px衝撃波（3s毎、ダメージ2） | 60 |
| 古代 | 歩く神像（コロッサス） | 街道巡回 15px/s | 250 | 眼光ビーム: 単体照射 DPS2.5、射程200px | 100 |
| 中世 | 騎士方陣 | 群れ方向へ低速行進 25px/s（反応射程400px内のみ） | 180 | 矢の斉射: 扇状5本（2.5s毎） | 80 |
| 近世 | 陸上甲鉄艦 | 外周航路を周回 18px/s | 400 | 舷側砲: 直交2方向に3連砲（2s毎、ダメージ2.5） | 150 |

### 7.3 実装ノート

- Boids とは別系統の waypoint ステートマシン。最大4体なので負荷軽微
- 当たり判定は大型円1つ。全武器・体当たりが有効

## 8. 障害物（侵入不可オブジェクト）

### 8.1 種別

| 種別 | 通行 | 破壊 | 投射透過 | 配置 |
|---|---|---|---|---|
| **城壁**（wall segment） | 不可 | 可（HP 40、ステージ3: 46 / 4: 52） | 不透過（BEAM/BULLET は壁に当たる。MISSILE のみ越える） | 首都要塞の外周リング |
| **岩山/湖**（地形） | 不可 | 不可 | 岩山: 不透過 / 湖: 透過 | マップに5〜9個散在 |

### 8.2 首都城壁の構造

- 現行の首都要塞（ボス＋大型リング＋城下充填）の**外周 半径420px に城壁リング**を追加
- 壁はセグメント分割（幅60px相当の弧、HP独立）。開口部（ゲート）から出入り可能
- ステージ進行でゲートが減る: **STAGE 1 城壁なし → 2 ゲート3 → 3 ゲート2 → 4 ゲート1＋二重リング**
- 攻略ルート3通り:
  1. ゲートから流れ込む（無傷だが敵火線が集中する導線）
  2. 壁をブリーチして雪崩れ込む（穴が開く瞬間＝「すごく気持ちいい」候補。BULLET/MELEE が得意）
  3. MISSILE で壁越しに内部を先に削る

### 8.3 Boids の障害物応答

- 障害物は円/カプセル近似。個体に壁法線方向の**スライド押し出し力**を加える（分離力より高優先で合成）
- リーダー（指の軌跡）は壁を無視できるが個体は止まる →「線は通ったのに群れが堰き止められ、壁面で渦を巻く」
  こと自体を視覚フィードバックにする
- スタック防止（ゲート幅・凹形状）は qa-engineer の重点テスト項目

### 8.4 破壊演出

- 城壁セグメント破壊時: 瓦礫パーティクル＋開口フラッシュ＋振動強め。ブリーチ跡はマップに残す

## 9. マップ高密度化（ワールドサイズ据え置き）

### 9.1 方針

**ワールドは 4800×3600 のまま変えない**。空白地帯を減らして敵の設置範囲と数を約2倍にする。

| 項目 | v0.5.2 | v0.6 | 備考 |
|---|---|---|---|
| ワールドサイズ | 4800×3600 | **4800×3600（据え置き）** | オフスクリーン69MBのまま。チャンク化不要 |
| 町の数 | 5〜6 | **10〜12** | 町間の空白を圧縮 |
| tiny集落クラスタ | 10 | **16〜18** | 町の隙間を埋める |
| 首都要塞 | 1 | 1＋**副砦1**（壁なし小型要塞。large密集＋移動敵の駐屯地） | 道中の山場 |
| 総建物数 | 数百〜千数百 | 約2倍 | ビューポートカリング済みで per-frame コストほぼ一定（実装コメント準拠） |

### 9.2 空白削減の生成ルール変更

- 町クラスタ中心の最小間隔を現行より詰める（town spacing を約 0.7倍に。重なり除去は維持）
- tiny ハムレットの「既存街区との最小間隔」（現行120px）は維持し、**個数だけ増やす**
  （隙間はハムレットで埋まる。ゼロ距離までは詰めず、群れが通る「路地」は残す）
- 岩山/湖（§8.1）も空白領域に優先配置し、「何もない空間」を「回り込む地形」に置き換える
- 卵の実効率は現行維持（建物2倍×率据え置き＝卵も約2倍 → 上限100到達が早まる。
  上限到達後は XP+10 変換が受け皿になり、高密度化がそのままレベル進行の燃料になる）

### 9.3 パフォーマンス確認事項（tech-lead）

- 建物2倍時の `rebuildBuildingLayer()` 一括描画時間（ステージ遷移時のみなので許容見込み）
- 空間ハッシュのセル当たり建物数増加が近傍探索に与える影響（グリッドサイズ100px の再調整要否）
