## 0. 一行で

**壊せば壊すほど、人類が文明を進めて反撃してくる。1ラン＝1つの大陸で、
石器の集落が目の前で神殿になり、城塞になり、要塞都市になる。**

---

## 1. なぜ変えるか

現行（v0.48.0）は「固定8ステージを順に舐める一本道 × 群れは毎面1体にリセット ×
ビルドだけ持ち越し」。ここに3つの不満がある。

- ステージ間の差が「色と敵テーブル」に留まり、構造の差になっていない
- 1ラン8面は長く、通しで遊びきる密度がない
- ランごとの変化が竜種のみ。2周目以降の引きが弱い

一方で8ステージが担っていた仕事は3つあり、1ラン1面にするならこれを
**面の中に作り直す**必要がある。

| 8ステージが担っていた仕事 | 新構成での引き受け先 |
|---|---|
| 難度カーブ（`STAGE_DIFFICULTY_BOOST`） | 時代レベル `eraLevel` ベースに付け替え |
| 見た目の変化（8文明ぶんのアセット） | 1ラン内で「その場で建て替わる」演出に転用 |
| 群れ再成長の反復（毎面 1→150体） | **廃止**。1ランで1回の長い成長弧にする（§5） |

## 2. ラン構成

| 要素 | 仕様 |
|---|---|
| 1ラン | 1大陸 = 1マップ。目安 10〜15分 |
| ラン開始の選択 | **竜種 × 開始時代**（大陸）。開始時代はクリアで解放 |
| 1ランに含まれる時代 | 開始時代から**連続4時代** |
| 進行 | 破壊率が閾値を超えると次の時代へ。ワールドはアンロードしない |
| クリア条件 | 第4時代（そのランの最終時代）の首都を陥落させる |
| 敗北 | なし（従来通り。ダウンした竜は必ず復帰する） |
| ラン毎の変化 | 開始時代 × 大陸シード（地形・町配置・首都位置・川） × 竜種 |

### 2.1 大陸（開始時代）の一覧

既存 `STAGE_CONFIGS` の8文明をそのまま「時代」として使い、連続4つで1大陸とする。

| 大陸 | 含む時代 | 首都（ボス） | 解放条件 |
|---|---|---|---|
| I 黎明 | 石器 → 古代 → 中世 → 近代要塞 | 電気 (HP 5448) | 初期解放 |
| II 神話 | 古代 → 中世 → 近代要塞 → 産業 | 大戦 (HP 7900) | 大陸I をクリア |
| III 鉄 | 中世 → 近代要塞 → 産業 → 電気 | 最終支配 (HP 11455) | 大陸II をクリア |
| IV 煙 | 近代要塞 → 産業 → 電気 → 大戦 | 最終支配 (HP 11455) | 大陸III をクリア |
| V 終焉 | 産業 → 電気 → 大戦 → 最終支配 | 最終支配 (HP 11455) | 大陸IV をクリア |

- 後ろの大陸ほど**初手から難度が高く、ランは短く濃くなる**（Balatro の ante/stake に相当）
- 解放状態は `profile.unlockedContinents` に保存（メタ進行の竜晶・チャレンジと同じ器）
- **ボスは大陸III 以降で頭打ち**（`clampEra` が最終時代で飽和するため）。
  III〜V の差はボスではなく**世界そのものの難度**で付く
- **初回ランだけは選択なし**（黎明の大陸×火竜で即開始）。2回目以降に
  「大陸を選ぶ → 竜を選ぶ」の2段階が入る

## 3. 時代進行（コア発明）

### 3.1 引き金は破壊率

`eraDestroyRatio = (その時代の開始時に存在した町の数 - 現存する町の数) / その時代の開始時の町の数`

- 閾値 **30%** を超えた瞬間に時代遷移が発火する（v0.52 で 60%→30%。60%は作業になっていた）
- 分母は**時代が上がるたびにリセット**される（＝その時代の文明の6割を潰せば次へ）
- 町の数は既存の `settlements.filter(s => !s.isBoss && !s._isWall)` で取れる
  （[index.html:12941](../../prototypes/dragon-tide/index.html:12941) の HUD が既に同じ集計をしている）
- 城壁と首都は分母・分子どちらにも数えない

### 3.2 遷移で起きること

1. **非モーダルの遷移演出**（v0.51 で方針変更）。当初は既存のステージクリア演出を流用する想定だったが、
   あれは `gameState` を止めて 2.8 秒待たせるシーケンスで、ラン中に3回起きると毎回テンポを殺す。
   プレイは止めず、**フラッシュ（0.35秒）＋スローモー（1.2秒）＋見出し（2.2秒）**だけで伝える。
   見出しは `ERA 2 / ANCIENT ERA`
2. **生き残った町が、その場で次の時代の建築に建て替わる**（色・形・攻撃パラメータが次の `STAGE_CONFIGS` のものになる）
3. **廃墟の一部（約30%）が新しい町として復興する** — マップが空にならず、
   「人類は潰されながら復興し、なお前へ進む」という物語が立つ
4. 首都も次の時代の姿に建て替わり、HPと火力が上がる
5. 難度ブーストが次の段へ（§3.4）
6. 群れの上限が解放される（§5）
7. 建物レイヤーの焼き直しはこの演出の暗転に隠す

### 3.3 首都の扱い（v0.52 で確定）

**ランのクリア条件は「首都（ボス）撃破」。時代は問わない。**

**ボスはラン開始時点で「そのランで到達しうる最強の姿」で立っている**（v0.53）。
以後、時代が上がってもボスは一切強くならない＝動かない壁になる。

- ボスの時代 = `clampEra(開始時代 + ERAS_PER_RUN - 1 + CAPITAL_ERA_OFFSET)`
- 既定のラン（開始時代0）なら**第6時代（ELECTRIC AGE）のボス。HP 5448**
- 時代遷移でボスを建て替えないので、**削ったHPは時代をまたいでも残る**

経緯: v0.52 ではボスも時代ごとに建て替えて強くなっていたが、それだと
「待って強くした群れの伸び」を「ボスの伸び」が相殺し、いつ挑んでも同じになる。
ボスを固定することで、時代を進める＝純粋に自分だけが強くなる行為になり、
「今の火力で削り切れるか、もう一時代ぶん育ててから行くか」が意味のある判断になる。

時代進行はこれにより**必須の関門ではなく、任意の強化サイクル**になった。
30%を壊して次の時代へ行くかどうかはプレイヤーの選択で、行けば群れの天井が開く一方、
世界も強くなる。

### 3.5 大陸は最初から一様ではない（v0.52）

石器時代の大陸に石器の街しか無いと、壊す前に強弱が読めない。
そこで**街ごとに「時代オフセット」**を持たせ、進んだ文明が既にそこにある状態にする。

| 対象 | 時代 | 効果 |
|---|---|---|
| ボス本体 | **ランの最大値で固定** | 開始時点から最終形態（既定ランで第6時代・HP5448）。以後変化しない |
| 首都区画・首都の城壁 | **同じく固定** | 時代が上がっても変わらない |
| 要塞都市（ボスに近い2〜3町） | **同じく固定** | v0.54。ボス直行を道中で止めるための壁 |
| ランダムな25%の街 | +1時代 | 時代とともに建て替わり、常に1時代先を保つ |
| 残り | 0 | その時代そのもの |

**時代固定の建物（`_fixedEra`）は建て替えも復興もしない。**
削った傷は時代をまたいで残り、落とせば落としたまま＝攻略が積み上がる。
これに対し通常の街は時代ごとに建て替わってHPが戻り、廃墟の3割が復興する。

難度係数（`STAGE_DIFFICULTY_BOOST`）も**建物ごとの時代**で引く。
v0.53 までは世界の時代で一律に掛けていたため、先の時代で建っている街に
本来の底上げが乗っていなかった（v0.54 で修正）。

### 3.6 ボスの武装は「ボスの時代」で決まる（v0.54）

`stageFeatures()` の参照先を世界の時代から `runBossEra()` に変えた。
ボスは既定ランで第6時代（電気）に固定されるため、**極太レーザーを最初から撃つ**。

今後ボスの武装バリエーションを増やすときも、参照するのはこの「ボスの時代」にする。
時代・文明に合った武装を割り当てていく（§9 参照）。

オフセットは**時代が上がっても保たれる**（建て替えのたびに同じ差がつく）ので、
「ずっと先を行く街」として一貫する。色・形が時代ごとに違うため、
遠目にも「あの街は格上」と分かる。

### 3.4 難度カーブ

`STAGE_DIFFICULTY_BOOST` を `stageIndex` ではなく**その時代の絶対番号（0〜7）**で引く。
テーブルの値はそのまま流用できる。開始時代が後ろの大陸ほど初手のブーストが高くなる。

## 4. マップ

| 項目 | v0.48 まで | v0.50（実装済み） |
|---|---|---|
| ワールド | 4800 × 3600（17.3Mpx） | **9600 × 7200**（面積4倍） |
| 町の数 | 10〜13 / 面 | **50〜65**（v0.52 で密度 0.75→1.25。時代遷移の復興で増減する） |
| 建物数 | 1600〜2100 / 面 | **5700〜9100** |
| 巡回する動く要塞 | 7〜40 | **21〜124** |
| ミニマップ | 80 × 60 | **120 × 90**（ドット半径も比率で縮小） |

数量は `scaledForWorld(基準個数, 密度係数)` で面積比から決める。基準は 4800×3600。
町は `TOWN_DENSITY_FACTOR = 1.25`、動く要塞は `MOVER_DENSITY_FACTOR = 0.75`、
岩山・湖・森は空白を埋める役なので面積比そのまま（4倍）。
動く要塞を町と同じ係数で増やすと後半で200体近くになり、遭遇密度ではなく物量になるため分けている。
**密度係数はフェーズ5で体感から詰める調整代**。

首都までの直線距離が 約2900px → 約5800px になった（竜の巡航 ~185px/s で片道 約31秒）。
ラン全体の尺に効くので、遅すぎるなら密度係数か竜速度で詰める。

### 4.1 前提となる技術改修：レイヤーのタイル化

現在、地面レイヤーと建物レイヤーは**ワールド全面のオフスクリーン canvas**として確保している
（[index.html:2001](../../prototypes/dragon-tide/index.html:2001)）。17.3Mpx × RGBA ≒ 69MB が2枚で
約138MB あり、iOS Safari の canvas 面積上限（約16.7Mpx）を既に微妙に超えている。
**面積4倍にすると1枚276MB・2枚で553MB となり、モバイルで確実に落ちる。**

したがってワールド拡大の前に、両レイヤーを **1200×1200 のチャンクに分割し、
可視範囲＋周囲1枚ぶんだけ保持する**方式へ改める。これを入れればワールドサイズは
実質青天井になり、制約は canvas ではなく `settlements` 配列・建物グリッド・
ミニマップ縮尺の側に移る。

改修が絡むのは4箇所:

- `rebuildGroundLayer()` — チャンク単位の遅延生成に
- `rebuildBuildingLayer()` — 同上。時代遷移時の全焼き直しもチャンク単位で dirty 化
- 建物破壊時の部分クリア — クリア矩形が跨ぐチャンクを特定して消す
- `minimapBaseDirty` / ミニマップ基底 — 縮尺を新ワールドサイズに合わせる

## 5. 群れ：削らない、代わりに上限を解放する

**確定事項: 時代が進んでも群れは削らない。** 1ランで 1体 → 上限まで、1回の長い成長弧を描く。

ただし現行は `MAX_BOIDS = 150` に早く到達してしまう。毎面リセットがこのキャップ問題を
隠していたので、削らないなら**キャップ到達後の卵の使い道**が必要になる。

解決策として、**群れ上限を時代で解放する**:

| 時代 | 群れ上限 |
|---|---|
| 第1時代 | 60 |
| 第2時代 | 90 |
| 第3時代 | 120 |
| 第4時代 | 150 |

「時代が上がる＝敵が強くなる」と同時に「＝群れの天井が開く」となり、
遷移の瞬間が損ではなく**解放の快感**になる。性能負荷も段階的に上がるので実機で追いやすい。

上限に張り付いている間に取った卵は、既存の経験値と同じく Lv とカードに還元される
（ここは現行の挙動を変えない）。

## 6. セーブ / 再開

現行はステージ開始時にオートセーブしている（`snapshotRunSave`）。これを
**時代遷移時のオートセーブ**に読み替える。保存する進行は以下。

- `continentId`（開始時代）
- `eraIndex`（0〜3）
- 大陸シード（同じ大陸を再生成するため）
- 既存の `playerLevel` / `playerXp` / `pendingCards` / `flockSpecies` / `upgradeCounts` / ラン統計
- **群れの現在数**（削らない設計なので、再開時に1体に戻すと理不尽になる）

町の破壊状況までは保存しない。再開時はその時代の頭から復興済みの状態で組み直す
（現行も「ステージ開始状態」から再開しており、粒度は同じ）。

## 7. 報酬・メタ

- **時代遷移ごと**に竜晶を付与（現行の `crystalsForStageClear` を流用）
- **第1〜3時代の首都陥落**でボーナス竜晶＋カード1枚
- **ラン終了（最終首都陥落）**で `CRYSTAL_ALLCLEAR_BONUS` 相当＋大陸の解放判定
- チャレンジ（`evaluateChallenges`）は時代遷移とラン終了の両方で判定

## 8c. v0.52 の変更（Shooter指示）

| 変更 | 前 | 後 |
|---|---|---|
| 時代遷移の閾値 | 60% | **30%** |
| ランのクリア条件 | 最終時代の首都撃破 | **首都撃破（時代を問わない）** |
| 首都・一部の街 | その時代の建築 | **首都と要塞都市が+2時代、25%の街が+1時代** |
| 町の数 | 30〜39 | **50〜65**（密度 0.75→1.25） |

実測（時代1・seed=12345）:

- 建物 5929棟 / 町50。うち オフセット0=3982・+1=1245・+2=701
- 首都HP 850 → **1787**（+2時代ぶん）。時代2へ進むと 2591
- 次の時代まで **1683棟**（5929の30%）。閾値は半分になったが町を増やしたぶん総量は近い
- 生成 62〜95ms / ミニマップのインク被覆率 30.9%（潰れずに読める）
- 毎フレーム: HPバー0.15ms / 卵マーカー0.09ms / 動く要塞0.04ms / タイル焼き直し3.1ms

クリア条件が首都撃破になったことで、1683棟は「進むために必要な作業量」ではなく
「留まって強くなる場合のコスト」に変わった。ラン尺を決めるのは首都HPと群れの火力。

## 8d. v0.53 の変更（Shooter指示）

**ボスは時代で強くならない。ラン開始時点で最強。**

| | v0.52 | v0.53 |
|---|---|---|
| ボスHP（時代1） | 1787 | **5448** |
| 時代2 / 3 / 4 | 2591 / 3757 / 5448 | **5448 のまま** |
| 削ったHP | 建て替えでリセット | **時代をまたいで残る** |

ボスが動かない壁になったことで、時代を進める行為が「純粋に自分だけが強くなる」に
なった。ラン尺は「HP5448 を削り切れる火力にどれだけ早く届くか」で決まる。
これが遅すぎ/速すぎるなら `CAPITAL_ERA_OFFSET` か `BOSS_HP_STAGE_MULT` で詰める。

## 9. 積み残しの論点

### 9-0. v0.55（大陸選択）の実測

- 初回ラン: 大陸選択を出さず 黎明×火竜で即開始（`isFirstEverRun()` 判定）
- 2回目以降: 「大陸を選ぶ」→「竜を選ぶ」。竜種の「もどる」は大陸選択へ1段戻る
- 未解放の大陸はカードが暗くなり、押しても反応しない（解放条件を本文に出す）
- クリアで次の大陸が解放され、リザルトに `🔓 ◯◯の大陸 が解放された` が出る
- 5大陸すべてで開始時代・時代の並び・ボスの時代が想定どおりであることを確認
- `elementFromPoint` で全カードが到達可能・タイトル(z50)が選択中は隠れていることを確認
- つづきからが開始大陸を保つ（`startEra` を runSave に保存）

### 9-1. ボス武装のバリエーション（次の作業・Shooter方針）

現在ボスの大技は極太レーザー1種のみで、`STAGE_FEATURES.bossLaser` の真偽で
出る／出ないが決まるだけ。**時代・文明に合った武装を増やしていく。**

- 参照するのは常に `runBossEra()`（ボス自身の時代）であって世界の時代ではない
- 方向性の例: 石器＝巨岩の投擲／古代＝神殿からの光の柱／中世＝城壁全周からの一斉射／
  近世要塞＝多連装砲／産業＝蒸気の熱波／電気＝極太レーザー（既存）／
  大戦＝絨毯爆撃／最終＝軌道爆撃
- 実装の受け皿は `STAGE_FEATURES` を「ボス技リスト」に拡張する形が素直
  （`bossLaser: true` を `bossArts: ["laser"]` のような配列にする）



- 大陸ごとの「特異点」修飾（例: 火山帯 / 重装の国）でラン変化をさらに増やす案 — 第2弾として保留
- 時代遷移時の建て替えで、プレイヤーが目の前で見ている町が変形する際の当たり判定の連続性
- 復興した町の湧き位置（廃墟跡そのままか、少しずらすか）
