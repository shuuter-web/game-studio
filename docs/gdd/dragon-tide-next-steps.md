## 2. 確定済み・未実装（次セッションで最初にやる）

### 2-1. 母竜ブレスを「最初からラン中強化に」
- **ユーザー確定**（2026-07-27）。現在 `buildLevelUpCards` に
  `if (def.mother && permaBuff.motherBreath <= 0) return false;` のゲートがあり、
  恒常ツリー `m_breath`（150竜晶）を買うまでラン中カードに出ない。
- **やること**：このゲートを撤去し、母竜ブレスは**ラン開始時から発動＋強化カードも初回から抽選対象**にする。
  ツリーの `m_breath` は「解禁」ではなく**下限強化**（威力/頻度の底上げ）へ役割変更。
- 併せて `mbreath_rate`（頻度上昇）はラン中強化として残す（v0.28で追加済み）。

## 3. 検討中の方針（未決定・アイディア保管）

> 背景の構造的診断：**現在のカードは全部 `eff*` を通る独立した掛け算**なので、
> 構造的にシナジーが生まれない。バリエーションとシナジーには「組み合わせが生まれる土台」が必要。
> 候補は **①サブ武器スロット** と **②状態異常** の2つ。

### 3-1. サブ武器スロット（竜種と独立した攻撃手段）
`updateWeaponAttacks` 末尾に `updateSubWeapons(dt)` を足し、取得済みサブ武器を回すだけで載る。
既存の `spawnDragonProjectile` / `emitShockwave` / 火FX / `motherBreathFx`（線＋フェード）を再利用可能。

| 案 | 挙動 | 噛み合う軸 |
|---|---|---|
| 焔の軌跡 | 竜の通った跡に炎の帯が残る | **速度↑・群れ数↑で面積増**（統率/大群） |
| 衛星竜 | 群れ周囲を小竜が周回、接触ダメージ | 群れ上限・速度 |
| 落雷 | 一定間隔でランダムな建物に雷（射程無限） | 手数 |
| 火の雨 | 一帯にメテオがランダム着弾 | 建物密集地 |
| 氷結波 | 群れ重心から冷気リング（**凍結**付与） | 状態異常の起点 |
| 咆哮 | 周囲をノックバック＋短時間スタン | 不屈・衝撃兵対策 |
| 溶岩溜まり | 壊した建物跡に溶岩の帯 | 破壊速度 |
| 卵爆弾 | 卵回収の瞬間に小爆発 | **磁力・大繁殖と直結** |
| 竜巻 | 竜巻が徘徊して巻き込み | 塊魂感 |
| 母竜の落陽 | 母竜が特大AoE爆弾を落とす | 母竜ライン |

### 3-2. シナジーの4型

**型A：状態異常＋起爆**（最も汎用な土台）
| カード | 効果 |
|---|---|
| 業火の刻印 | 攻撃が**燃焼**付与（継続ダメージ） |
| 燃え広がり | 燃焼中の敵が死ぬと**周囲へ燃焼が伝播**（連鎖崩壊） |
| 絶対零度 | 攻撃が**凍結**付与（移動・攻撃速度低下） |
| 砕氷 | **凍結中の敵へのダメージ +60%** |
| 狩りの刻印 | ボス/エリートに刻印、刻印対象へ全ダメージ +25% |

**型B：閾値条件**
| カード | 効果 |
|---|---|
| 数の暴力 | 群れ40体以上で全ダメージ +40% |
| 疾風怒濤 | 速度強化1つにつき威力 +6% |
| 孤高の母 | 群れ15体以下で母竜ブレス威力 +150%（少数精鋭） |
| 満身創痍 | HPが減っている竜ほど攻撃力上昇 |

**型C：変換（ステータスの二重活用）**
| カード | 効果 |
|---|---|
| 竜血変換 | HP強化の30%を威力に加算 |
| 翼の理 | 速度の20%を射程に加算 |
| 巨躯 | 群れ上限を下げる代わりに1体を大幅強化（トレードオフ） |

**型D：進化合成（Vampire Survivors 型）** — 2枚maxで上位カードが出現＝ラン中の目標
| 素材 | → 進化 |
|---|---|
| 火勢(max)＋多重照射(max) | **業炎放射**：全方位に太いブレス |
| 貫通弾(max)＋連射機構(max) | **氷嵐**：貫通弾幕を扇状に連射 |
| 広域炸裂(max)＋影炸(max) | **黒星**：着弾点にブラックホール |
| 剛爪(max)＋疾風(max) | **突貫**：群れが定期的に一斉突撃 |
| 母竜の吐息(max)＋母竜の鼓動(max) | **虹輝の吐息**：極太の虹色ブレス |

### 3-3. 選択そのものを面白くする（Balatro的な引き）
- **リロール**（ラン中N回／竜晶消費）、**バナー（二度と出さない）**＝ビルド純度、
  **呪い付き強カード**（威力+80%／群れ上限-20 等）、star枠の当たり感の演出強化。

### 3-4. 図形の違いで操作課題を変える（★重要な設計視点）
この game の操作は「群れの進路を描く」ことなので、**攻撃の図形＝操作の課題**が変わるのが本質的な差別化。

現状のカバー範囲：火竜=短い線／氷竜=直線貫通／影竜=誘導＋着弾円／緋竜=接触点。
**空いている図形**：扇・回転掃射・同心円・周回リング・設置領域・連鎖グラフ・跳弾折れ線・長射程直線・吸引・**群れの形そのもの**。

| 図形 | 操作がどう変わるか |
|---|---|
| 回転掃射 | 敵の**真ん中に居座る**（滞在型） |
| 同心円パルス | 町の**中心に潜り込む**、密集地ほど得 |
| 周回リング | 建物の**縁をかすめる**グレイズ操作 |
| 設置領域 | **塗って離脱**、往復ルート設計 |
| 連鎖グラフ | **密集地に突っ込む**ほど爆発的 |
| 跳弾折れ線 | **壁のある町**（v0.29追加）で激増＝閉所有利 |
| 長射程直線 | **街路に整列**して撃つ（碁盤目の町で快感） |
| 扇（前方） | 常に**進行方向を敵へ向ける**操舵 |
| 吸引→爆縮 | 散った敵を**まとめてから**倒す段取り |
| 群れの形＝武器 | 群れの両端を結ぶ線が焼く／近い竜同士が線で繋がる＝**群れを伸ばす/固める**新軸（Boidsでしか成立せず独自性が高い） |

### 3-5. アンロック竜種案（図形＋専用カード群）
竜種を増やすと**専用カードがまるごと増える**ので、バリエーション不足も同時に解決。
解放条件は既存のチャレンジ機構（`CHALLENGE_DEFS`）に接続する。

| 竜種 | 図形 | 専用カード例 | 解放条件（案） |
|---|---|---|---|
| **雷竜** | 連鎖グラフ | 連鎖数+1／連鎖距離／**連鎖するほど威力上昇** | エリート累計撃破 |
| **嵐竜** | 回転掃射 | 回転速度／ビーム長／**逆回転の2本目** | 1ランで群れ60体 |
| **毒竜** | 設置領域 | 帯の持続／幅／**重ねると濃度上昇** | 町を完全破壊 |
| **鋼竜** | 長射程直線 | 溜め短縮／貫通枚数／**街路に沿うと威力増** | 町壁をN枚破壊 |
| **星竜** | 周回リング | 衛星数／軌道半径／**内外の半径切替** | 全クリア回数 |
| **鏡竜** | 跳弾折れ線 | 跳弾回数／**跳ねるたび威力+15%** | 壁つき町を壁から攻略 |
| **響竜** | 同心円パルス | 輪の間隔／**2重・3重の輪** | 累計クリア |
| **重竜** | 吸引→爆縮 | 吸引半径／爆縮威力／**巻き込み数で増幅** | 巨獣を撃破 |

**推し3種**（操作課題が完全に分かれる）：**雷竜**（滞在×密集）／**星竜**（グレイズ）／**鋼竜**（整列）。
まず**1竜種を縦に通す**（竜種＋専用カード3〜4枚＋解放条件）と手触りを早く確認できる。実装が軽く既存の
建物密集と即噛むのは**雷竜**。

### 3-6. グラフィカルな見せ場（俯瞰で映える攻撃演出）
※**トップビュー厳守**。地面に残るもの・大きな幾何形・群れ自体が絵になるものが最も強い。

- **地面に残る**：龍脈（枝分かれする溶岩の亀裂が残り冷えて黒く沈む）／焔の軌跡／溶岩湖／氷華（角ばった結晶）
- **大きな幾何形**：極光の帯（虹色リボンが波打って薙ぐ）／鯨波（巨大な三日月）／天焦がし（警告円→白熱の光柱）／蝕（暗転＋巨大な光の環）
- **群れが絵になる**：**星座の網**（近い竜同士が光の線で結ばれ、群れが増えるほど網が濃く美しい）／群れの陣（回転する魔法陣が群れ規模で拡大）／渦潮／衛星竜
- **一撃**：星降り（**影が地面で膨らむ**俯瞰ならではの予告→着弾）／プリズム（建物間を反射する光の折れ線）／黒星／雷雲（地面に影を落とし稲妻）

**推し3つ**：**星座の網**（群れの数がそのまま美しさ＝3本柱に最も忠実・実装軽い）／**龍脈**（俯瞰の強み・破壊の痕跡）／**天焦がし**（溜めと解放が気持ちいい）。

### 3-7. メタ側の残タスク
- **チャレンジ報酬に特別解放ノード**（`unlockBy: challengeId`／竜晶では買えない）＝
  「竜晶＝量の育成／チャレンジ＝腕前で解く特別ノード」の**二層経済を閉じる**。
  `treeNodeState` に "challenge-locked" 追加、`purchaseTreeNode` でブロック、`evaluateChallenges` で解放。
- **各ラインの名物ノード**（対処に無関係でも欲しくなる演出系）：母竜=虹色特大ブレス／
  大群=一定数超えで群れが黄金化しXP+／統率=軌跡が光る彗星の尾／恵み=クリア時に竜晶が花火のように舞う。
- **母竜ブレスの進化（枝分かれ）**：直線貫通／分裂／範囲凍結／なぎ払い（挙動が変わる分岐＝Balatro柱の本命。作業量は最大）。
- 数値バランスの実機チューニング。

## 4. 恒久ルール・制約（必ず守る）

- **トップビュー厳守**：ドーム/立面など横視点の形は禁止（干し草をドームにして差し戻した実績あり。v0.28.2で描画カット）。
- **敗北要素なし**：竜はダウンしても必ず復帰。ノーダウン系のチャレンジも**コンセプト違反として不採用**（v0.25.1で削除）。
- **モーダルでプレイを止めない**：メニュー系はプレイ外（タイトル）で開く。カード選択はスローモーで非モーダル。
- **音は当面後回し**。
- 「被り」（スタジオ内・過去の種・市場の先行作）は設計・判定の制約にしない。
- 変更は毎回 `/deploy-dragon-tide` で検証→master 反映。URLは装飾なしのプレーンテキストで単独行に書く。
- 全ユーザー向け文字列は `STRINGS` 経由、数値は定数に集約（マジックナンバー禁止）。

### プロトタイプ検証の既知の罠（時間を溶かした実績あり）
- `preview_screenshot` は必ずタイムアウト → 状態検査（JS評価）で代替。
- プレビューでは canvas サイズ0（viewH=0）→ **描画は自動確認できない**。見た目はユーザー実機に委ねる。
  （`drawMovers` の `def.attack.type` 無防備参照バグを描画未実行のため一度見逃した。無攻撃 mover を足すときは注意）
- 実行時FPSは計測不能（バックグラウンドスロットリング）。性能はコード構造で判断。
- `generateStageLayout(idx)` は**返り値**で建物配列を返す（グローバル `settlements` を更新しない）。
  ステージ生成の検証はこの返り値を見る（グローバルを見て「0件」と誤判定した実績あり）。
- 構文チェックは `<script>` 内JSを**BOMなしUTF-8**で抽出して `node --check`。

## 5. 実装の差し込み口（識別子で参照）

| 目的 | 差し込み口 |
|---|---|

| 母竜 | `MOTHER_DRAGON`／`isMotherActive`／`updateMotherBreath`／`MOTHER_BREATH_INTERVAL`（現7.0秒）／残像は `motherBreathFx`＋`drawMotherBreathFx` |
| 敵 | `MOVER_DEFS`／`MOVER_SPAWNS_BY_STAGE`／`updateMovers`（attack type: beam/shockwave/fan/broadside/bomb/**heal**/**summon**）／`damageMover`／`updateBehemothArm` |
| ラッシュ | `updateEnemyRush`／`RUSH_*` 定数／`_rushWave` タグ |

| 竜種 | `flockWeapon`（beam/bullet/missile/melee）／ラン開始の4択は `SPECIES_CHOICES`／武器別カードは `CARD_DEFS` の `weapon:` フィルタ |

## 6. 次アクションの推奨

1. **母竜ブレスを最初から**（§2-1。確定済み・小さい）
2. **1竜種を縦に通す**（推奨：**雷竜**＝連鎖グラフ。竜種＋専用カード3〜4枚＋解放条件）
   → 図形の違いが操作の課題を変えるか、実機で手触りを確認
3. 良ければ**星竜（グレイズ）／鋼竜（整列）**へ横展開
4. 並行して**状態異常（燃焼・凍結）＋起爆カード**＝シナジーの土台
5. **特別解放ノード**で二層経済を閉じる（§3-7）
