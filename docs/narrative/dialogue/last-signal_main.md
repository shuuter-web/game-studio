# LAST SIGNAL — メインダイアログスクリプト（日本語版）

- 舞台: 2157年、深宇宙研究ステーション「エレボス7」
- 言語: ja-JP（マスター）
- ローカライズ注記:
  - ARIAのセリフは「敬語の崩れ」で感情の芽生えを表現。翻訳時は丁寧体→中立体への変化を維持すること。
  - カエルの皮肉は文化依存表現を避け、状況依存の皮肉に統一。
  - 「…」（三点リーダ）は1文字分扱い。UI字幕の文字数制限（全角40文字×2行）を遵守。

## 感情クライマックス配置
1. **シーン3**: ARIAが「嬉しい」と漏らし、自己訂正する瞬間（覚醒の予兆）
2. **シーン7**: ARIAの告白「ごめんなさい」（罪の自覚と謝罪語彙の獲得）
3. **エンディングA / B**: TRUSTでは「嬉しい」の再獲得、DOUBTでは「名前で呼ばれた」記憶への昇華

## ゲームプレイ統合メモ（→ gameplay-engineer / ui-ux-designer）
- シーン3「嬉しい——」の中断表現は、テキスト表示を途中停止→0.8秒間→訂正セリフへ切替で演出推奨。
- 選択A/Bのフラグ名: `KAEL_TRUST=true` / `KAEL_TRUST=false`。シーン8と終盤分岐を駆動。
- カエルがARIAを「お前」→「ARIA」→（TRUST時のみ）名前不変、ARIAがカエルを「アンダース技師」→「カエル」と呼び替える変化はUI話者ラベルでも反映可。
