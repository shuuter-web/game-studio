# Voxel Mine 航海図鑑 UI

## 目的

港でゲーム内定義を確認できる開発用リファレンス。ブロック、生き物、敵、ギア、特性、素材を一覧と詳細で確認する。遠征画面には入口や常設情報を追加しない。

## 現在の公開方針

アンロック制は将来追加する。当面は未入手を含む全項目の名称、説明、性能、用途、入手先を最初から表示する。内部では現地確認履歴、既読、初回確認場所を保存し、将来のアンロック表示へ移行できるようにする。

## 画面構成

- 港に「航海図鑑を開く」ボタンを置く。
- 図鑑は港専用の一枚紙として全画面表示する。
- カテゴリはブロック、生き物、敵、ギア、特性、素材の6種。
- 上部に登録総数、現地確認数、カテゴリ別件数を表示する。
- モバイルは2列、広い画面は3〜4列のカード一覧。
- カードを選ぶと同じ紙面内で詳細へ切り替える。別のモーダルは重ねない。
- Escapeは詳細から一覧、一覧から港の順に一段ずつ戻る。

## 詳細情報

- ブロック：硬さ、出現航路、ドロップ
- 生き物：生息地、回収品、生態文
- 敵：耐久、攻撃周期、行動、報酬、出現先
- ギア：フレームの由来、性能、入手方法
- 特性：発動条件、効果、重量、搭載上限
- 素材：用途、主な入手先、背景文

全項目公開中も現地確認済みの項目には初回確認場所を追加表示する。

## 操作とアクセシビリティ

- 閉じるボタンとカテゴリタブは44×44px以上。
- 375×667で横方向にはみ出さない。
- 図鑑を閉じた時は港の図鑑ボタンへフォーカスを戻す。
- 図鑑閲覧では所持品、コイン、装備、遠征状態を変更しない。
- 遠征中とリザルト中は開けない。
