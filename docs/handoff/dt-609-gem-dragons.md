## 1. ひとことで

竜の見た目を **進化に合わせて「原石 → 全身カットの宝石（キラキラ）→ 宝石＋飾り」** に変える。
いまは **火竜・氷竜・影竜・緋竜・飛竜の5竜種** がゲームに入っている（v3.205.0）。
**残りの竜種に広げる途中で、画像生成（Gemini API）のクレジット切れ（HTTP 402）で止まっている**（2026-11-26 時点、まだ 402）。

## 2. いまの決まり（Shooter が決めたこと。これに沿って作る）

| 段階 | 見た目 | きらめき |
|---|---|---|
| 進化前 | **原石**。竜種の色・イメージを優先（色あせ・茶色・灰色の岩にしない） | 無し |
| 1回目の進化 | **全身カットの宝石**（面と白い縁取りで描いた絵） | 全部の面がしっかり光る |
| 2回目の進化 | 1回目の絵に **石とは別の色・素材の飾り** を足す | 全部の面 |

**きらめき**（v3.188.0〜）
- 手法は「③ 面が光る＋にじみ」と「④ 虹色のファイア」を合わせたもの。光った面は面の形のまま光り、ずれの向きで赤→黄→緑→青と色が変わり、まわりに淡いにじみ。
- 光り方は **竜の向き＋地図の上の位置** だけで決まる（時間・乱数では光らない。同じ向き・同じ場所なら同じ光り方）。
- 重さ：光った面の層を「絵・量・向き（2°刻み）」ごとに1回だけ作り置きし、竜1匹あたり `drawImage` 1回で重ねる。

**飾り（2回目の進化）で Shooter が良い・悪いと言ったこと**
- ✗ 顔の前に突き出る飾り（冠・ティアラなど）は変。**後頭部（頭の後ろ側）から後ろ・外へ** なら良い
- ✗ 全身の縁取り（輪郭を細い線でなぞる）はイマイチ → やめた
- ✗ 首輪・ハチマキ・額飾りのような「巻き付く」飾りはペットみたい → やめた
- ○ 襷掛け・斜め掛けは良い
- ○ 飾る部位と飾らない部位にメリハリ。飾りは **元の輪郭からはみ出す** くらいに
- ○ 竜種ごとに個性を。外へ広がる飾りだけでなく **上に乗る飾り** なども。色・素材は **金属に限らない**
- ○ 解釈は「言われたことだけ」より、ある程度自由に。細かい注意書きを増やさない

**翼を胴の上に描く**（v3.184.0・全竜種）：胴を先に描き翼を上に重ね、翼の付け根を翼の幅の3%ぼかす。`DRAGON_WING_OVER`（false で前の描き方）。

## 4. 作り方（1竜種あたり）

1. **原石の胴・翼の絵** と **全身カットの宝石の胴・翼の絵** を作る（`assets/dragon_<id>_rough_{body,wing}.png`・`dragon_<id>_sparkle_{body,wing}.png`）。
   - いまの絵（`dragon_<id>_body.png`・`_wing.png`）を下絵に、**輪郭・ポーズ・大きさを変えずに** 材質だけ描き直す。
   - 輪郭は当たり・翼の付け根の位置に効くので、生成した絵は「緑抜き → 下絵の外接矩形に合わせて伸縮 → 下絵のアルファで切る」で下絵と同じ輪郭にする。そうすれば `DRAGON_PART_SPRITES` の寸法は元の竜種の値をそのまま使える。
   - この手順は `tools/gen_gem_restyle.py`（作業ブランチ `claude/kind-hamilton-w157gf` のコミット 966c1dd。**まだ一度も動いていない**）にまとめてある：
     `python3 tools/gen_gem_restyle.py falcon sparkle body` など。隼竜・燕竜・蜂竜の石の描写は中の `GEMS` に入っている。
2. **2回目の進化の飾り** は画像生成ではなく、`tools/gen_gem_ornaments.py`（master）に竜種ごとの飾りを手で形を決めて描き足し、`dragon_<id>_jewel_{body,wing}.png` を書き出す（乱数を使わず毎回同じ絵）。
3. `prototypes/dragon-tide/index.html` に登録する：
   - `DRAGON_PART_SPRITES`（`<id>_rough`・`<id>_sparkle`・`<id>_jewel`。寸法は元の竜種の値）
   - `GEM_SPARKLE_SPECIES[<id>]`：`tiers: [{look:"<id>_rough", amount:"none"}, {look:"<id>_sparkle", amount:"full"}, {look:"<id>_jewel", amount:"full"}], gloss: 0.9`
   - `EVO_TINT_GEM_LOOKS` に `<id>_sparkle`・`<id>_jewel`（分岐の色を薄く 0.15 で重ねる）
   - `GAME_VERSION` を上げる
4. 見本ページ `prototypes/dragon-tide/gem-evolution-sample.html` に竜種の段を足す（3段階を大きく並べてゆっくり回す。ゲームの描き方をそのまま使う）。
5. 検証：`node tools/check.mjs`、ヘッドレスの指紋が変更前と一致すること（見た目だけなので遊びは変わらない。`--render` 付きでも一致）。
   コマンドはリポジトリの `CLAUDE.md` の「検証」の節。図鑑の進化の姿・デバッグの竜種選択（└ 分岐・└└ 型）でも見られる。

## 5. コードの場所（prototypes/dragon-tide/index.html）

- `GEM_SPARKLE_SPECIES` / `GEM_SPARKLE_SPECIALS` / `GEM_SPARKLE_*` の定数 … 竜種ごとの段階の絵ときらめきの量・強さ
- `gemSparkleForSpecies()` / `gemSparkleFacets()` / `gemSparkleLayer()` / `renderGemSparkleLayer()` … 面の区切り・光り方・作り置き
- `DRAGON_PART_SPRITES` … 竜の胴・翼の絵と寸法（`tools/sprite_meta.py` の実測値）
- `EVO_TINT_ALPHA_GEM` / `EVO_TINT_GEM_LOOKS` … 宝石の絵に重ねる分岐の色の濃さ
- `DRAGON_WING_OVER` … 翼を胴の上に描く
- 見本ページ：`gem-sample.html`（DT-597 ルース）・`gem-sparkle-sample.html`（星の見本）・`gem-facet-sample.html`（きらめき手法①〜⑥）・`gem-evolution-sample.html`（進化の3段階）

## 7. いま止まっていること・決めてほしいこと

画像生成が使えないので、次のどちらかが要る（チケットで Shooter に聞いている）。
1. Google AI Studio でクレジットを足して、画像生成で続ける（いままでの5竜種と同じ作り方）
2. 画像生成を使わず、いまの絵の色を宝石の色に塗り替え、カットの面の線と照りを手で描き重ねる（すぐ作れるが描き込みは粗くなる）

別の仕組みに引き継ぐ場合も、この2つのどちらかで「4. 作り方」の 1 を満たせば、2〜5 はそのまま進められる。
