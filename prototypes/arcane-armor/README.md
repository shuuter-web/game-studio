# ARCANE ARMOR — 魔導機甲戦線（プロトタイプ）

魔法のある世界の近代戦。平らで広い戦場を、12両 対 12両の車両が**自分の判断で走り回って撃ち合う**オートバトル。
プレイヤーは指揮官で、7秒ごとの**指令フェーズ**（戦闘が止まる）に「どの部隊のスキルを使うか」を1つ発令する。
戦闘後は同じ戦闘を**止まらずに**演出カメラで見直せる。

v0.1.0 はグリッド・高低差ありのマス移動だった。v0.2.0 でグリッドと高低差をなくし、自由走行＋実弾の撃ち合いに作り替えた。

## 仕様の要点

| 項目 | 内容 |
|---|---|
| 走り | 前進・後退・旋回・加減速のみ（横滑りなし）。履帯はその場で旋回、装輪は走りながらでないと曲がれない |
| 弾 | 当たり判定を持って飛ぶ。避けられる。障害物（岩・遺跡・水晶・木立）に当たると止まる |
| 耐久 | 1〜数発で撃破（魔導戦車4／重戦車8／自走砲2／装甲車3／魔導車3）。**背面命中はダメージ2倍**、重戦車は正面被弾を半減 |
| 行動方式 | 魔導戦車＝目標の周りを回りながら撃つ／重戦車＝正面装甲を向けて押す／自走砲＝遠くに止まって撃ち、寄られたら後退／装甲車＝戦場の端を回り込んで後衛を襲う／魔導車＝味方主力の後ろについて追尾魔弾 |
| スキル | 車種ごとに1つ：徹甲魔弾・魔導障壁・流星弾幕・疾風機動・連鎖雷撃（クールタイムあり。その車種が全滅すると使えない） |

数値は `index.html` 冒頭の `BALANCE` にまとめてある（本制作では `data/balance/` へ切り出す）。

## リプレイの仕組み

戦闘ロジック（`<SIM>`〜`</SIM>` 区間）は固定60ティック・シード付き乱数で、描画から完全に切り離してある。
リプレイは録画ではなく、**同じシード＋自軍の指令ログで戦闘を再計算**している（敵の指令はシードから同じものが出る）。
見た目だけの乱数は `fxRandom()` を使い、戦闘結果に触れない。

## 検証

```bash
node tools/check.mjs prototypes/arcane-armor/index.html
node prototypes/arcane-armor/verify.mjs            # 決定性（本番とリプレイの指紋一致）・勝率・戦闘時間
```

## URLパラメータ

- `?seed=4242` 戦場と戦闘を固定（HUDにシードが出る。不具合は再現シードとセットで報告）
- `?auto=1` 自軍の指令もAIに任せる（眺める用・検証用）
- `?fx=low` ブルームと影を切る（重い端末用）
- `?lang=en` 英語表示
