# 掘り島 — HORI-SHIMA v0.3.1

飛空艇で浮島へ出航し、採掘で見つけた素材と換金品を持ち帰る探索プロトタイプ。
**港で準備 → 出航 → 発掘・生き物の捕獲 → リザルト → 売却・強化**を繰り返す。

巨大浮島から自然に切り出される漂流島の資源を、冒険者が飛空艇で拾う世界。地上に豊富な「黒い水」が燃料となり、中位の居住浮島の暮らしを支える。巨大浮島の中心にあると噂される古代遺跡への直接進入は、魔物と防衛施設に阻まれている。

港の「世界の手引き」で背景設定を読める。「発見物の覚え書き」には発見済みの品の来歴が残り、売却しても消えない。リザルトの「積み荷の覚え書き」では今回の発見物だけを読める。

## 操作と燃料

`index.html` をブラウザで開く。港の航路図から出航する。

- ブロックをタップで採掘。ドラッグで回転、ピンチ・ホイールでズーム。
- 生き物は島に最初から配置される。見えている個体をタップして捕獲し、換金品を得る。
- 有効な採掘・捕獲は1回につき燃料1。割れる前の打撃も消費する。
- 空振り・硬さ不足・視点操作・思考時間は無料。範囲採掘と連鎖は追加消費なし。
- 任意帰還、燃料切れ、島の採掘完了でリザルトへ。最後の連鎖の報酬も回収する。
- 出航時に無料で補給。同じ島にも再訪できる。帰還用の燃料は別枠。

## 発見物と強化

土・石・草は掘る地形であり、そのまま所持素材にはならない。破壊時に、何も出ない場合と、工作用素材や換金品を発見する場合がある。銅などの鉱石は従来どおり強化素材になる。

換金品は港で売却してコインにする。素材は売却対象外。初期つるはし・燃料タンク・航路の強化はコインで行え、保証配置の生き物から換金品を集めても進行できる。

遠征終了時のリザルトには、その遠征で獲得した素材・換金品、売却見込額、捕獲数、使用燃料を表示する。「港へ戻る」では報酬を重ねて加算しない。

## 行き先

初期は1島、航路強化で最大6島へ進める。各島で銅→結晶→鉄→金→黒曜→星核を発見できる。より硬い鉱石には上位のつるはしが必要。深層素材は浮島の底ではなく芯側に生成する。

## 保存・再現

```text
?seed=12345   世界の種を指定。種ごとにセーブ枠が分かれる
?fresh=1      通常セーブと別の試遊枠。同じ枠の再読込は続きから
```

地形は世界の種と行き先で決まる。発見物はさらに遠征通番とブロックの位置で決まり、新たに出航すると抽選が変わる。同じ遠征の再読込では燃料・採掘状態・生き物・抽選結果を引き継ぐ。

v0.1/v0.2の土・石は1個につき新しい工作用素材1個に換算する。既存の装備・航路・容量も保持する。旧版で進行中だった遠征はそのまま引き継ぎ、生き物は次の出航から配置する。

node tools/check.mjs prototypes/voxel-mine/index.html
