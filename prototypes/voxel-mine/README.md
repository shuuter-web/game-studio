# 掘り島 — HORI-SHIMA

手描きの線が沸く浮島を、タップで掘る。素材を集めて工房でつるはしを鍛え、掘れなかった硬い層に手が届く。
島は掘り尽くしたら次へ。**次の島は前より大きく、深く、芯に濃いものが埋まっている**。上限はない。

土台は SKETCH VOXEL（`prototypes/voxel-sketch/`、描画の仕組みはそちらの README）。
企画上の位置づけは PS-047 けずり町（素材の行き先＝クラフト）と PS-049 の実測
（島が固定だと消費の加速に供給が追いつかず、終盤が数タップで終わる）への答えで、
**供給側＝島を番号ごとに育てる**ことでランの形を保っている。

```
prototypes/voxel-mine/index.html をブラウザで開くだけ
?seed=12345   … 世界の種を固定（島 n の形は 種と n から決まる）。種ごとに別のセーブ枠
?fresh=1      … セーブを読まずに最初から（セーブは消さない）
```

操作: **タップで掘る ／ ドラッグで回す ／ ピンチ・ホイールで寄る**。進行は localStorage に自動保存。

## 採掘の手応え（何が「気持ちいい」を作っているか）

| 仕組み | 中身 |
| --- | --- |
| ひび → 割れ | ブロックには hp があり、打撃力ぶんずつ削れる。割れるまではひびが増えていく（面の中心から縁へ折れ線） |
| 硬さのゲート | 素材ごとに必要なつるはしの段階がある。足りないと「×」が弾いて何も起きない（面にも薄く×が出る） |
| 範囲 | 一撃で球状に削る。幅 1 → 3 → 5 → 7 |
| 鉱脈連鎖 | 鉱石を割ると、つながった同じ鉱石が 55ms 間隔で続けて割れる（近い順）。最大 48 |
| コンボ | 1.1 秒以内に続けて割ると数が乗り、10 ごとに取れる量が +1 倍（上限 ×3） |
| 音 | 素材ごとに音程が違い、コンボと連鎖で半音ずつ上がる。WebAudio で合成（アセットなし） |
| 揺れ・破片・浮き文字 | 壊した量に比例して画面が揺れ、破片が飛び、獲得が浮き文字で出る。在庫の数字が跳ねる |

## 素材と硬さ

| 素材 | 必要なつるはし | hp | 出る島 | 場所 |
| --- | --- | --- | --- | --- |
| 草・土 | 素手 | 1 | 1〜 | 表面 |
| 石 | 素手 | 2 | 1〜 | 地の大半 |
| 銅 | 石 | 3 | 1〜 | 外側の鉱脈 |
| 結晶 | 石 | 3 | 2〜 | 少し内側の鉱脈 |
| 鉄 | 銅 | 4 | 3〜 | 中ほどの鉱脈 |
| 金 | 鉄 | 5 | 4〜 | 芯寄りの鉱脈 |
| 黒曜 | 鉄 | 7 | 5〜 | 芯を包む殻 |
| 星核 | 黒曜 | 9 | 6〜 | 殻の内側 |

「深い」を**下ではなく芯**にしている。浮島は底が丸見えで、下から叩けば深層に届いてしまうため。
芯に置けば、必ず外側から掘り進めないと手が届かない。

## 工房（素材の唯一の行き先）

| 系統 | 段階 | 効果 |
| --- | --- | --- |
| つるはし | 素手 → 石 → 銅 → 鉄 → 黒曜 → 星 | 掘れる素材が増え、打撃力の土台が 1/2/3/4/6/8 |
| 打撃力 | 上限なし | +1 ずつ。要求素材が 2 段階ごとに石→銅→結晶→鉄→金→黒曜→星核と上がり、最後は 1.3 倍ずつ伸びる |
| 範囲 | 3 段階 | 幅 3 / 5 / 7 |
| 鉱脈連鎖 | 5 段階 | 3 / 6 / 12 / 24 / 48 |

数値は `index.html` 冒頭の `MATERIALS` `PICKAXES` `RANGE_LEVELS` `CHAIN_LEVELS` `POWER_COST_BRACKETS` `ISLAND`
にまとめてある（本制作では `data/` に切り出す）。

## 検証

```
node tools/check.mjs prototypes/voxel-mine/index.html   # 構文・Math.random・バージョン
node prototypes/voxel-mine/verify.mjs                   # headless Chromium で機械判定
```

verify.mjs が見ているもの: 例外 0 ／ 島 1 の構成（銅あり・鉄なし）／ 素手で掘れる数 ／
石は 1 回目でひび・2 回目で割れる ／ 銅は素手だと × ／ 工房は素材不足で作れず・足りれば作れて減る ／
連鎖が時間差で処理される ／ 幅 3 でまとめて割れる ／ 連打でコンボが乗る ／ 保存→再読込で戻る ／
島 2 で結晶・島 6 で鉄〜星核が出る ／ 島 6 の島レイヤー 1 回描画が 25ms 未満（実測 約 4〜5ms、面 764）／ 同じ種で同じ島。

## 拡張の余地

- 支えを失ったブロックの落下（今は宙に浮いたまま。芯を抜くと殻だけ残る）
- 島のテーマ（雪・溶岩）と素材の差し替え。生成は `pickMaterial()` だけ見ればよい
- 消耗品（爆弾・松明）と、島ごとの「お宝」（1 個だけ埋まった特別なブロック）
- 実機での触り心地（コンボ窓 1.1 秒、連鎖 55ms、揺れの上限 7px）は headless では測れない。手で触って調整する
