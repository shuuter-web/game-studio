# 掘り島 — HORI-SHIMA v0.8.5

開発の軸は[短いゲームコンセプト](../../docs/voxel-mine-concept.md)。小さな変更を公開し、プレイ評価を受けて次の一歩を決める。

v0.8.5の評価点：ギアを拾った瞬間と種類が分かるか、積載架の拡張方法が見つかるか。ギア発見は手書き風SVGアイコン・特性・重量つきで7秒表示し、同時発見も2件まで保持。港では搭載するまで「新着」を表示する。素材も獲得通知・在庫・強化費用に共通アイコンを使う。積載架は重量6/3個 → 重量9/4個（30コイン・工作部品4）→ 重量12/6個（60コイン・銅6・工作部品8）。港のギア欄から拡張可能。schema 11の既存セーブは維持する。

v0.8.4：初回ギアを獲得した後は、地形ブロックの破壊ごとに6%でランダムギアを発見できる。通常採掘・連鎖・自律削岩杭が対象で、1遠征につき追加発見は最大2個。土や石などの通常ドロップとは独立した抽選。木のブロックや捕獲は対象外。初回ギアを持たない間はv0.8.3の案内を優先する。帰還リザルトには回収ギアの特性と重量を表示する。保存形式はschema 11のまま。

v0.8.3の評価点：ギアを持っていない状態では、はじまりの草島で地形を3ブロック壊すと条件付きギアを1個発見する。自律削岩杭・三拍増幅器・樹冠共振器から決定的に抽選され、港で搭載して次の探索で試せる。自動搭載はせず、既にギアがある場合は追加配布しない。保存形式はschema 11のまま。

飛空艇で浮島へ出航し、採掘で見つけた素材と換金品を持ち帰る探索プロトタイプ。
**港で準備 → 出航 → 発掘・伐採・生き物の捕獲 → リザルト → 売却・強化**を繰り返す。

巨大浮島から自然に切り出される漂流島の資源を、冒険者が飛空艇で拾う世界。地上に豊富な「黒い水」が燃料となり、中位の居住浮島の暮らしを支える。巨大浮島の中心にあると噂される古代遺跡への直接進入は、魔物と防衛施設に阻まれている。

港の「世界の手引き」で背景設定を読める。素材の来歴は航海図鑑へ集約し、港とリザルトには長い説明文を並べない。

港の「航海図鑑」では、ブロック・生き物・敵・ギア・特性・素材を6カテゴリで確認できる。現在は開発用資料を兼ねるため、未入手を含む全項目の名称、説明、性能、入手先を最初から表示する。現地確認の履歴と初回確認場所は内部に保存され、カードから同じ紙面内の詳細を開ける。図鑑は港でのみ利用でき、遠征やリザルトの入口は設けない。

## 操作と燃料

`index.html` をブラウザで開く。港の航路図から出航する。

- ブロックをタップで採掘。ドラッグで回転、ピンチ・ホイールでズーム。
- 島には若木と、木ブロック・葉ブロックからなる大木が生える。若木は一度で伐採し、大木はタップしたブロックを1個ずつ削る。幹ブロックは木材になり、葉ブロックからは「風乾きの葉」「空樹の実」「琥珀樹脂」のいずれかを個体換金品として必ず回収できる。
- 生き物は島に最初から配置される。丸い立体パーツを持ち、2コマの動きを繰り返す。見えている個体をタップして捕獲し、換金品を得る。
- 島2には古代哨戒機が島の地表に着地して現れる。赤銅と暗鉄の大型四脚機で、通常時は機体のそばに細い4分割耐久ゲージと攻撃までの数字アイコンだけを表示する。残り1手では数字アイコンが赤く脈動し、色だけでなく太い輪郭でも警告する。機体が地形などに完全に隠れたときは表示も隠れ、一部でも見えれば再び追従する。攻撃は機体本体のタップで行い、攻撃ボタンは置かない。ゲージまたは数字アイコンをタップすると機体の横に幅196px以下の情報札が開き、「行動」「特性」「報酬」を切り替えて確認できる。札を開いたままカメラを動かせ、情報の確認では燃料や手番を消費しない。足場を削ると島上の安全な高所へ移動し、足場が全くなくなると撤退する。
- 地中の宝箱は周囲を掘ると発見できる。開封にも燃料1を使い、個体換金品・ギア・工房の設計図を回収できる。
- 有効な採掘・伐採・捕獲は1回につき燃料1。割れる前の削岩も消費する。
- 空振り・硬さ不足・視点操作・思考時間は無料。範囲採掘と連鎖は追加消費なし。
- 任意帰還と島の採掘完了でリザルトへ。燃料切れでは「燃料がなくなった。帰還しよう。」と知らせ、確認後にリザルトへ進む。最後の連鎖の報酬も回収する。
- 出航時に無料で補給。同じ島にも再訪できる。帰還用の燃料は別枠。
- 初期燃料は20。燃料タンクの強化で30、45、65へ増え、増設燃料槽ギア1個につきさらに6増える。
- 通常素材、換金品、生き物のドロップを入手した瞬間、15%の決定的抽選で「拾い話」が約4秒だけ現れる。同じ手番では1回までで、表示後8行動は再表示されない。全文は航海図鑑でいつでも確認できる。

## 発見物と強化

土・石・草は掘る地形であり、そのまま所持素材にはならない。破壊時に、何も出ない場合と、工作用素材や換金品を発見する場合がある。銅などの鉱石は従来どおり強化素材になる。

木材とそのほかの換金品は港で売却してコインにする。発見した換金品には状態・来歴・希少度が個体ごとに付き、名前、説明、査定額が変わる。素材は売却対象外。飛空艇の船外削岩機・燃料タンク・航路を強化できる。

宝箱や古代哨戒機から特性付きギアを回収できる。飛空艇には重量6、最大3個まで搭載でき、編成変更は港でのみ行う。ギア特性には削岩出力、燃料、連鎖、査定、敵攻撃周期、宝箱探索に加え、次の条件効果がある。島2の宝箱で設計図を得るまでギア製作台は使えない。

- 自律削岩杭（重量3）：最初に手動採掘した地点へ設置され、次の手番から周囲2マス以内を毎手番1ブロックずつ出力1で掘る。複数搭載時は個体ごとに作動する。
- 三拍増幅器（重量2）：3、6、9……手番目の手動採掘と大木伐採の範囲を1段階広げる。
- 樹冠共振器（重量2）：大木の葉ブロックを狙ったとき、伐採範囲を1段階広げる。

範囲効果は同名ギアの複数搭載や条件の重なりで加算され、最大+2。自律削岩杭は燃料や追加手番を使わず、連鎖や別のギアを再発火させない。

遠征終了時のリザルトには、その遠征で獲得した素材・換金品、売却見込額、捕獲数、使用燃料を表示する。「港へ戻る」では報酬を重ねて加算しない。

## 行き先

初期は1島、航路強化で最大6島へ進める。各島で銅→結晶→鉄→金→黒曜→星核を発見できる。より硬い鉱石には上位の船外削岩機が必要。深層素材は浮島の底ではなく芯側に生成する。

## 保存・再現

```text
?seed=12345   世界の種を指定。種ごとにセーブ枠が分かれる
?fresh=1      通常セーブと別の試遊枠。同じ枠の再読込は続きから
```

地形・発見物・木・生き物・宝箱・敵は世界の種、行き先、遠征通番から決まり、新たに出航するたび島の形と配置が変わる。地形は丘陵・尖塔・くぼ地・双峰の傾向を持つ。同じ遠征の再読込では島の形・燃料・採掘状態・木の伐採状態・生き物・抽選結果を引き継ぐ。

島は横方向の探索面積と木の本数を保ちながら、高低差と底の深さを抑えて見渡しやすくしている。出航時のカメラは島だけでなく木の梢、生き物、古代哨戒機とその名称までを測り、HUD・燃料計・操作パネルに重ならない採掘領域へ全景を収める。採掘後の重心追従、手動ズーム、再読込時のカメラ復元は従来どおり維持する。

v0.7.0では個体アイテムとギア編成の導入に伴い保存形式を更新した。v0.7.1では同じ保存形式のまま、敵の接地・船外削岩機の設定・葉の換金品を追加した。v0.7.2では古代哨戒機の専用モデルと名称表示を追加し、v0.7.3では木を残したまま地形の縦寸法と初期カメラの全景収容を調整した。v0.7.4では常設の敵パネルを廃止し、世界内表示と任意の詳細表示へ整理した。v0.7.5では詳細表示を暗転モーダルから敵に追従する小型カードへ変更し、v0.7.6では通常時の文字札を可視判定付きの耐久ゲージと攻撃カウントへ置き換えた。v0.8.0では手番・対象条件で発動する3種のギアと自律削岩杭の3D表示を追加し、保存形式をschema 9へ更新した。v0.8.1では港専用の航海図鑑とギアフレームの安定IDを追加し、発見・既読・初回場所を厳格に保存するschema 10へ更新した。v0.8.2では燃料容量を20/30/45/65へ調整し、入手時だけ表示する決定的な「拾い話」通知へ整理した。表示履歴と累計入手数を保存するschema 11へ更新し、旧セーブは移行しない。

港・探索中・リザルトの「デバッグ」から、現在の世界の種とセーブ枠を確認してセーブデータを初期化できる。通常枠と `fresh` の独立テスト枠は別々に扱う。

node tools/check.mjs prototypes/voxel-mine/index.html
