# 掘り島 — HORI-SHIMA v0.2.0

手描きの浮島を掘り、素材を飛空艇で持ち帰る採掘探索プロトタイプ。
**拠点で準備 → 行き先を選ぶ → 燃料の範囲で採掘 → 帰還 → 装備・飛空艇を強化**を繰り返す。

## 遊び方

`index.html` をブラウザで開く。最初は拠点から最初の島へ出航する。

- タップで採掘、ドラッグで回転、ピンチ・ホイールでズーム。
- 有効な採掘1回につき燃料1。割れる前の打撃も消費する。
- 空振り・硬くて掘れない打撃・視点操作・考える時間は無料。
- 範囲採掘と鉱脈連鎖は一撃分の燃料。連鎖は時間差で割れ、報酬が入る。
- 「帰還」でいつでも素材を持ち帰れる。燃料0では最後の連鎖まで処理して自動帰還。
- 出航時に無料で満タン。同じ島を再訪すると同じ形の鉱床が再生成される。
- 工房は拠点で利用。つるはし、打撃力、範囲、鉱脈連鎖に加え、燃料容量と航路を強化できる。

燃料は採掘中の浮遊・作業用。帰還用は別に確保してある。コンボは一撃とその連鎖の中で成立するため、急いで連打する必要はない。

## 行き先と成長

初期航路は1島。航路を強化すると次の島が開き、最大6島へ進める。

| 島の生成レベル | 新しく得られる素材 | 必要なつるはし |
| --- | --- | --- |
| 1 | 草・土・石、銅 | 土・石は素手、銅は石 |
| 2 | 結晶 | 石 |
| 3 | 鉄 | 銅 |
| 4 | 金 | 鉄 |
| 5 | 黒曜 | 鉄 |
| 6 | 星核 | 黒曜 |

深い素材は「下」ではなく「芯」に生成する。浮島の底から直接深層だけを採れる問題を避けるため。
初期の飛空艇強化は初期島の素材だけで可能。以後も航路開放に未開放の島の素材は要求しない。

## 再現と保存

```text
?seed=12345   世界の種を固定。種ごとにセーブ枠が分かれる
?fresh=1      最初から試す。通常セーブとは別枠
```

進行はlocalStorageに保存する。遠征中の再読込では燃料・島の採掘状態・予約された連鎖を復元し、無料補給しない。
旧v0.1.0のセーブは素材・装備・統計を引き継ぎ、到達島に応じた航路を開いて拠点から開始する。

## 検証

```bash
node tools/check.mjs prototypes/voxel-mine/index.html
node prototypes/voxel-mine/verify.mjs
```

`verify.mjs` はPlaywrightで採掘、燃料、航路、工房、帰還、保存・移行を機械判定する。
Playwrightやブラウザを外部の実行環境から使う場合は `PLAYWRIGHT_MODULE_PATH` と `PLAYWRIGHT_EXECUTABLE_PATH` を指定する。
