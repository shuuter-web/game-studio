FX SAMPLER

画像アセットを一切使わず、コードだけでリッチに見せる表現のカタログ。すべて Canvas 2D の単一HTMLで動く。 ネオンは「光で見せる」系統の1手法にすぎないことを確かめるために、6系統を並べてある。 カードをタップすると大きく表示され、その表現の実装コードがそのまま読める。

  1. 限定パレット＋シルエット＋グラデ背景 — 実装1時間、印象の変化は最大

  4. 多層パララックス＋フォグ — 奥行きはレイヤー分けだけで作れる
    5. 
    
  5. ブルーム（縮小バッファ） — ネオンの正しい実装
    6. 
    
  6. 色収差＋スキャンライン＋グレイン — 仕上げの後処理3点セット
    7. 
    
  7. プロシージャルノイズ — テクスチャ画像不要化の本丸
    8. 
  

  
実機で落ちる3大要因

  
    
    
  • shadowBlur の毎フレーム呼び出し → グロー画像をオフスクリーンへ焼いて drawImage + lighter
    • 
    
  • ctx.filter = "blur()" のフル解像度がけ → 1/4 縮小バッファでぼかしてから拡大
    • 
    
  • 毎フレームの getImageData / putImageData → 低解像度バッファ限定＋更新レートを 20〜30Hz に落とす
    • 
  

  
選び方

  

    絵づくりは「A:光 → C:質感 → D:奥行き」の順に足すと破綻しにくい。B:形 と F:生成 は作風そのものを決めるので先に決める。
    E:動き は他のどれと組んでも効く上に一番安いので、迷ったらここから。
