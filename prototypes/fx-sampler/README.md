# FX SAMPLER

画像アセットを使わず、コードだけでリッチに見せる表現の比較カタログ。単一HTMLで28種。
「ネオンは “光で見せる” 系統の1手法にすぎない」ことを確かめるための資料兼サンプル集。

```
prototypes/fx-sampler/index.html をブラウザで開くだけ
?seed=12345  … 乱数を固定（低ポリの頂点配置などが毎回同じになる）
```

## 収録している6系統

| 系統 | 収録デモ |
|---|---|
| A. 光 | ネオン / ブルーム / 2Dライティング＋影落とし / リムライト・擬似球 / 接地影 |
| B. 形 | シルエット＋限定パレット / 低ポリ / ボロノイ / 再帰の木 / 稲妻 / 手描き風ストローク |
| C. 質感 | プロシージャルノイズ / 秩序ディザ（1bit） / CRT（色収差・走査線・粒子） / パレット量子化 / 時間帯グラデ |
| D. 奥行き | 多層パララックス＋空気遠近 / 疑似3D床（Mode 7） / 被写界深度 / 板ポリ＋Zソート |
| E. 動き | フィードバック残像 / パーティクル / Verletの紐 / 群れ（Boids） / ジュース（潰し・止め・揺れ） |
| F. 生成 | 落砂シミュレーション / 反応拡散（Gray-Scott） / DOOMの炎 |

カードをタップすると拡大表示になり、`create()` の実装がそのまま読める
（コード文字列を二重管理せず `Function.prototype.toString()` で出している）。

## 実装の作法

- デモは `create(w, h) → { draw(ctx, t, dt) }` を返す閉包1個。`DEMOS` に足すだけで増える
- 可視タイルのみ描画（IntersectionObserver）。重いデモは `hz` で更新レートを落とす
- ピクセル処理は `makeLowRes()` の低解像度バッファ経由に固定（全解像度 `getImageData` は実機で落ちる）
- 乱数はスタジオ共通ルールどおり `random()` / `fxRandom()`。`?seed=` で再現できる

## 検証

`node tools/check.mjs prototypes/fx-sampler/index.html` に加えて、headless Chromium で
全28タイルのピクセル統計（色数・輝度分散・フレーム間差分）を取り、
「描画されている」「動いている」を機械判定した上でコミットしている。
