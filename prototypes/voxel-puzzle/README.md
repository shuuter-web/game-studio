# SKETCH VOXEL PUZZLE

手描きの線が沸くボクセルを、**タップだけで全部壊す**パズル。1タップ＝1ターン。
ブロックにはギミックがあり、放っておくと増えるもの・周りを巻き込むもの・同じ色を壊すもの・
次のタップの範囲を広げるものなどが混ざっている。手数の上限内に全部壊せばクリア。

```
prototypes/voxel-puzzle/index.html をブラウザで開くだけ
?level=7      … レベルを指定して開く
?seed=12345   … 苔の増え方・分裂の出る場所を固定（既定はレベルIDから決まる固定シード）
```

操作: **タップで壊す / ドラッグで回す / ピンチ・ホイールで寄る**。鉄はタップしても「×」が出るだけ。

## ブロック（13種）

| 記号 | 名前 | ルール |
| --- | --- | --- |
| `#` | 土 | ふつうのブロック |
| `H` | 石 | 2回当てないと壊れない（1回目でひびが入る） |
| `X` | 鉄 | タップでは壊せない。爆弾・貫き・範囲に巻き込む |
| `M` | 苔 | 毎ターン、隣の空きに苔石を1つ増やす |
| `m` | 苔石 | 苔が増やしたもの。増えはしない |
| `E` | 卵 | 3ターン経つと苔になる（残りターンは面の刻みの数） |
| `S` | 分裂石 | タップの範囲で壊すと土2つに分裂。連鎖で壊せば分裂しない |
| `B` | 爆弾 | 壊れると周り3×3×3を巻き込む |
| `I` | 氷 | 隣が壊れると割れる。氷づたいに伝わる |
| `r` `b` `y` | 共鳴 | 壊すと同じ色が全部壊れる |
| `+` | 拡げ石 | 次のタップの範囲が1段広がる（3×3×3→5×5×5、2つ同時に壊すと5×5×5） |
| `=` `\|` `/` | 貫き石 | 矢印の向き（x / y / z 軸）に一直線、全部壊す |
| `W` | 除草石 | 壊すと苔・苔石・卵が全部壊れる |

ターンの流れ: タップの範囲を壊す → 連鎖を「波」ごとに解決（爆弾・共鳴・貫き・除草・氷）→
苔が増える → 卵のカウントが減る → 手数が上限に達していれば失敗。
**y=0 の下は床**なので、盤面の裏からはタップできない（囲って隠す設計が成り立つ）。

## 構成

- `puzzle-core.js` … ルール本体。描画から独立していて Node からも `require()` できる
- `levels.js` … 15レベル。段ごとの文字列で書く（下の段から、奥の行から）
- `solve.mjs` … ビームサーチでレベルの最短手数を求める。`par` と `limit` の根拠はこれ
- `index.html` … 描画・演出・入力（描画は voxel-sketch のもの。線は毎秒10コマ引き直され、常に沸いている）

```
node prototypes/voxel-puzzle/solve.mjs            # 全レベルの最短手数。par と食い違えば exit 1
node prototypes/voxel-puzzle/solve.mjs L12 --width 2000
```

レベルを足したり直したりしたら、まず solve.mjs を通す。解けないレベル（鉄が残る等）はここで分かる。

## 描画で足したもの

- **面の上の記号**: 面の四隅を [0,1]² に対応させ、双一次補間で記号の折れ線を面の上に置く。
  記号も penLine で引くので、ブロックと同じように沸く。貫き石の矢印は、貫く軸を含む面にだけ描く
- **連鎖の可視化**: ルール側が返す波を 130ms ごとに描画用の盤面へ反映する（真実は core、描画は遅れて追いつく）
- **膨らむ出現**: 分裂・苔の増殖・孵化は中心からスケールして描く（沸きは boilFrame 基準なので線は乱れない）
- 床の枠とマス目、破片は床で一度はねる

## 検証

`node tools/check.mjs` に加えて headless Chromium で機械判定している。

- 例外・HTTPエラーが0
- 沸きの実測（10.0Hz）
- 実座標のタップで L01 がクリアになる／ドラッグで壊れない／鉄はタップできない
- **全15レベルを solve.mjs の手順で通し、ルールと描画の写しの残り数が一致する**（60fps）
- 分裂石を直接タップすると増える
- パネルが 390px 幅からはみ出さない
