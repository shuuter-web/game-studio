# SKETCH VOXEL

手描きストロークで描いた3Dボクセルの島を、タップで壊すサンプル。画像アセットは使っていない。

```
prototypes/voxel-sketch/index.html をブラウザで開くだけ
?seed=12345   … 島の形を固定（「作り直す」を押しても同じ島になる）
```

操作: **タップで壊す / ドラッグで回す / ピンチ・ホイールで寄る**。破壊範囲は 1・3・5 から選ぶ。

## 線は常に沸いている

このサンプルの主題は**線が沸いている（boil）**こと。手描きアニメが1コマずつ線を引き直すのと
同じで、何も操作していなくても毎秒 `BOIL_FPS`（既定10）回、すべての線が引き直される。

実装は、ジッターのハッシュに「沸きコマ番号」を混ぜているだけ。

```js
function jitter(a, b, salt, amount) {
  return (hash3(a, b, salt + boilFrame * 7919) - 0.5) * amount;
}
```

ボクセルは毎回その場で描いているので、沸きの追加コストはゼロ。
**焼いた絵をキャッシュして使い回す最適化は入れていない**（入れると線が止まるため）。
代わりに次の二段構えにして、沸きと動きの滑らかさを両立させている。

- 島 … 沸きコマが変わったとき（毎秒10回）と、壊したとき・カメラが動いたときだけ描き直す
- 破片・インク飛沫 … 毎フレーム描く（ジッターは沸きコマ基準なので、動きながら線は沸く）

## 描画のしくみ

- 立方体の6面は軸と符号から機械的に生成（手で座標を書くと必ずどこかで間違える）
- 埋まっているセルは描かない。露出セルだけを奥から手前へ並べて描く（画家のアルゴリズム）
- 稜線は**折り目かどうかで太さを変える**。隣に同じ向きの面が続いていれば薄い線、
  途切れていれば太い線を2度がけ。全部同じ太さだと方眼紙になり、折り目だけだと積み木に見えない
- 塗りは輪郭から少しずらす（版ズレ）。ずらすと隣との間に紙が見えるので、重心から7%太らせて塗る
- タップ判定は、描いたときに控えておいた面の画面座標を手前から順に点包含判定する
  （IDバッファを別に描かずに済む）

## 検証

`node tools/check.mjs` に加えて、headless Chromium で以下を機械判定している。

- 例外・HTTPエラーが0
- ブロック数・描画された面数・インク画素が十分にある
- **沸きの実測**: 何も操作せず2.2秒間サンプリングして画が変わった回数を数え、
  設定値（10Hz）に一致するか。さらに1コマまたいだ2枚の差分画素の割合も測る
  （直近の実測: 9.9Hz / 6.8%の画素が1コマで変化）
- タップでブロックが減り破片が出る／範囲5でまとめて壊れる
- ドラッグ（回す操作）がタップと誤認されて壊れない
- 60fps

## 拡張の余地

- 支えを失ったブロックを落とす（現状は宙に浮いたまま残る）
- 壊した面だけを描き直す部分更新（今は沸きのたびに島を全部描き直している）
- 材質ごとの硬さ（結晶は2回叩かないと割れない、など）
