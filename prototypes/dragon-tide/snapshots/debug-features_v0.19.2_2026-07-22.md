# Dragon Tide デバッグ機能リスト（スナップショット）

- **対象バージョン**: v0.19.2
- **作成日**: 2026-07-22
- **性質**: 使い捨てスナップショット（この時点の記録。以降の変更は反映されない。最新は `index.html` を参照）

---

## 起動方法

画面**左下のバージョン表示（例: `v0.19.2`）を 800ms 以内に 3 回タップ**すると、
画面上部に **デバッグパネル**がトグル表示される（モバイル対応）。もう一度 3 タップ、
または右上の「✕」で閉じる。

- **`N` キー**（デスクトップのみ）＝「次ステージ」を即実行するショートカット（パネルを開かず動く）。
- パネル上部に現在の状態を表示：
  `state / stage / Lv / 竜(生存数) / 竜晶 / runs(開始ラン数) / clears(全クリア回数)`

パネルのボタンは、**プレイ外へ抜けた場合（クリア・初期化など）や 3 択カードが開いた場合は自動で閉じ**、
それ以外（竜追加・竜晶付与など）は開いたまま数値を更新する。

## ボタン一覧（v0.19.2 時点・10 個）

| ボタン | 内部処理 | 効果 | 備考 |
|---|---|---|---|
| ▶ 次ステージ | `debugAdvanceStage()` → `advanceToNextStage()` | 次ステージへ即移動（最終→STAGE1 へループ） | **正規のクリア処理は通らない**。`clears` は増えず報酬も出ない。あくまで進行スキップ用 |
| ★ このステージをクリア | `triggerStageClear()` | 正規のステージクリア演出に入る（非最終＝次ステージ演出、最終＝全クリアへ） | クリア扱い。ステージ遷移時に**オートセーブ**が走る |
| 🏁 全クリア（即） | `triggerAllClear()` | その場で全クリア＝リザルト表示 | **`clears++`・ベスト記録更新・再開データ削除**を実行。クリア報酬フローの検証用 |
| ⬆ レベル +1 | `debugLevelUp(1)` | レベル+1して 3 択カードを開く | 強化カード（パワーアップ）の検証用 |
| ⬆ レベル +5 | `debugLevelUp(5)` | レベル+5（カード 5 回分がキューされ順に開く） | まとめてビルドを組みたいとき |
| 🐉 竜 +10 | `debugAddDragons(10)` | 群れ重心付近に竜を 10 体孵化 | 大繁殖カードと同じ孵化経路。群れ上限で頭打ち |
| 💠 XP +500 | `addXp(500)` | XP を 500 付与（曲線しだいで数レベル上がる） | レベルアップの自然発生を確認したいとき |
| 🔷 竜晶 +100 | `profile.crystals += 100` | メタ通貨「竜晶」を +100 して保存 | 恒常ツリー（Phase 2）実装後の購入検証用の先行機能 |
| 🗑 再開データ削除 | `clearRunSave()` | 「つづきから」用の再開セーブを削除 | タイトルメニューの「つづきから」を消したいとき |
| ♻ プロファイル初期化 | `debugResetProfile()` | プロファイル＋再開データを全消去し初回ラン状態へ | **初回=火竜即開始 / 2回目=竜種選択・初期1体**のフロー検証に必須 |

## 典型的なテスト手順

### メタ進行（クリア回数・オートセーブ・つづきから）
1. ♻ プロファイル初期化 → タイトルへ（初回状態）
2. タップで開始（火竜・10 体）→ ★ このステージをクリア を数回 → 途中でリロード
3. タイトルに **「つづきから STAGE X」** が出て、復帰できることを確認
4. 🏁 全クリア（即）→ `clears` が増え、再開データが消えることを確認（パネル status で確認可）

### 竜種選択フロー（2 回目以降）
1. 一度でもラン開始済み（runs ≥ 1）でタイトルへ
2. 「はじめる」→ 竜種 4 種＋「もどる」→ 選択で **1 体スタート**
3. ♻ プロファイル初期化で初回状態に戻し、初回=火竜即開始も確認

### パワーアップ（ビルド）
- ⬆ レベル +5 で強化カードを連続取得しビルド感を確認
- 🐉 竜 +10 / 💠 XP +500 で群れ規模・レベル進行の手触りを確認

## 関連メモ

- 「次ステージ」と「このステージをクリア」の違いが重要：**クリア扱いにしたいときは必ず「★ このステージをクリア」または「🏁 全クリア」**を使う（▶ 次ステージは進行スキップのみで `clears` を増やさない）。
- 竜晶ボタンは Phase 2（恒常強化ツリー）未実装時点での**先行機能**。ツリー実装後は購入原資の検証に使う。
- 実装箇所（v0.19.2 時点）: `index.html` の `DEBUG_ACTIONS` 配列と `renderDebugPanel()` / `toggleDebugPanel()`（バージョン定数直下のデバッグブロック）。
