# snapshots — 使い捨てスナップショット文書置き場

このフォルダは **その時点の仕様を切り取った「使い捨て文書」専用** の置き場です。

## 方針（重要・今後も維持）

- ここに置く文書は **一度きりのスナップショット**。仕様変更のたびに更新する必要は **ありません**。
- 各ファイル名には対象バージョンと作成日を含めます（例: `..._v0.17.1_2026-07-14.html`）。
  ファイル名の版・日付が「いつ時点の内容か」を表し、それ以降の仕様変更は反映されません。
- 内容が古くなったら **更新せず放置**（または削除）してください。最新仕様を知りたい場合は
  コード（`prototypes/dragon-tide/index.html`）や維持管理される文書（`docs/`, `ELEMENTS.md`）を参照します。
- つまり **ここのファイルは信頼できる最新仕様ではなく、作成時点の記録** です。
