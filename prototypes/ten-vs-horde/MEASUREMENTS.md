# 十人と百鬼 — 計測ログ

価値基準: **ユーザーの少ないアクションで、たくさんの影響が起きること**。

これは主観ではなく客観量なので、最初から計測器を内蔵している。

- `1タップの影響量` = そのタップで「意味のある変化」（死亡／被ダメ／0.6マス以上の移動／経路変更）を受けた敵の数
- 判定は **無操作ベースラインとの差分**。無操作でも同じように進むなら、タップに価値はない

## 測り方

ブラウザで開いて、コンソールから:

```js
window.tenVsHorde.headlessRun({ seed: 11, seconds: 240, policy: "greedy" })
```

`policy` は `none`（無操作）／`random`（クールダウンが空き次第てきとうに）／
`greedy`（射程内の敵が最も多いユニットを選ぶ）。描画を止めて回すので、
240秒 × 5シード × 3方針が **約2秒** で終わる。

`none` と `greedy` の差 = タップの価値。
`random` と `greedy` の差 = **判断**の価値（上手さが報われるか）。

## 各版で何が分かって、何を直したか

### v0.1.0（初版）
- 無操作45秒 vs タップあり240秒完走 → **タップに価値があることは確認できた**
- ただし `random` の**影響の中央値が0**。半分以上のタップが完全な空振りだった
- スキル別で **pit が 1.2影響/タップ** と死んでいた（固定位置に穴を開けるので敵がいない）
- `pull` が 59.3影響/タップ と最高値。ただしこれは**計測器の嘘**で、
  1mmでも動けば「影響あり」と数えていた

### v0.2.0（3点修正）
1. **空振りの廃止**: 射程内に対象がいないタップは発動せずクールダウンも消費しない
2. **pit を敵に合わせる**: 前方で最も密集しているセルに穴を開ける
3. **影響量の定義を厳格化**: 移動は0.6マス以上動いた場合のみ数える

結果:
- 空振り中央値 0 → 25（体験として改善）
- pit 1.2 → **75.0影響/タップ** に復活
- pull 59.3 → 42.8（過大評価が是正された）
- **副作用**: random と greedy の差が消えた（生存233 vs 232）。
  「どれを押しても効く」ようになり、**判断の価値が下がった**

### v0.3.0（湧きモデルの作り直し）
v0.2.0 までは「ウェーブごとに総量N体を撒く」方式だったため:
- 撒き終わると **敵ゼロの空白が20秒**生まれていた
- 同時生存の**ピークが94体**で、要件の「数百体」に届いていなかった

常時湧きのレート方式（毎秒7体＋ウェーブごとに+5体/秒）に変更。

結果:
- **同時生存ピーク 211体**（無操作時）で「数百体」を達成
- **判断の価値が復活**: greedy 208秒 vs random 142秒、撃破は2倍差
- 1タップ平均影響 58.7体、**最大295体**

## v0.3.0 スキル別（greedy・5シード合計）

| スキル | タップ数 | 影響/タップ | 撃破/タップ | 所見 |
|---|---|---|---|---|
| 穴 pit | 45 | **171.7** | 51.3 | 最強。穴で経路が変わる影響が広い |
| 風 push | 90 | **159.5** | 67.9 | 撃破効率も最高。縦一列を吹き飛ばす |
| 壁 wall | 135 | 52.3 | 0 | 布石。経路変更のみ |
| 磁 pull | 228 | 48.1 | 0 | 布石。最も多く使われる |
| 雷 chain | 203 | 40.8 | 40.7 | 密集依存。安定した主力 |
| 爆 blast | 176 | 20.9 | 20.8 | **最下位**。単純な範囲攻撃はこの密度では見劣り |

## 未解決 / 次に測ること

- **blast の存在意義**: 数字上は他の下位互換。密集時だけ跳ねる設計に振るか、差し替えるか
- **布石→本命のコンボ**が数字に出ていない。`pull → blast` のような2タップ連携の効果を、
  単発との差分で測る計測をまだ入れていない（価値基準の核心はここのはず）
- **上限が見えていない**: greedy が240秒打ち切りに当たる。難易度の天井は未測定
- **手触りは未評価**。機械が測れるのはここまでで、「押して気持ちいいか」は実機で人が触るしかない

## v0.4.0 — 味方の位置を捨てて10ボタンに

v0.3.0 までは味方に盤面上の位置があったが、動かせないため位置が**制約にしかなっていなかった**
（射程外だと押せないだけ）。位置の意味を捨て、全スキルが盤面を見て自動で対象を選ぶ形にした。
プレイヤーの決定は「どのスキルを・いつ」だけになる。スキルは3系統10種:

- 狩る: 雷（連鎖）爆（最密点に爆発）穴（最密点を陥没）
- 崩す: 磁（全体を最密点へ集約）風（前線を押し戻す）壁（前線の手前を遮断）反（一部を反転させ同士討ち）
- 抑える: 凍（前線60体を停止）腐（全体持続ダメージ）鼓（城の迎撃を3倍）

### 測って分かったこと（240秒・5シード）

| | 無操作 | random | greedy |
|---|---|---|---|
| 生存秒 | 59.4 | 240（完走） | 240（完走） |
| 撃破 | 373 | 6490 | 6446 |
| タップ数 | 0 | 232 | 95 |
| 1タップ平均影響 | — | 29.2 | 58.3 |

**問題が2つ出た。**

1. **10種のうち5種（凍・風・壁・穴・反）が一度も使われなかった。** 危機が発生しないため、
   防御系の札に出番がない
2. **どちらの方針でも240秒完走。** 湧きを2倍・3倍にしても両方完走し、敵数は上限900に張り付いた。
   **タップし続ける限り負けようがない＝判断が要らない**

原因は難易度ではなく **アクションが希少でないこと**だった。
クールダウンさえ空けば何でも押せるので、「少ないアクション」という前提が成立していない。

## v0.5.0 — 気力（共有リソース）でアクションを希少にする

全スキル共通の気力（上限100・毎秒5.5回復）を導入し、スキルごとに16〜34の消費を設定。
「溜めて、ここぞで撃つ」を強制する。

### 300秒・3シード

| 湧き倍率 | 無操作 | random | greedy | randomのタップ | greedyのタップ |
|---|---|---|---|---|---|
| 1.0 | 59.4秒 | 204.3秒 | **300秒（完走）** | 63.7 | 82 |
| 1.5 | 44.3秒 | 167.4秒 | 298.8秒 | 52.7 | 83 |
| 2.0 | 35.2秒 | 126.3秒 | **249.3秒** | 40.3 | 70 |

| | v0.4.0 | v0.5.0（湧き2倍） |
|---|---|---|
| 300秒あたりのタップ数 | 95〜232 | **70〜83**（約4秒に1回） |
| 1タップ平均影響 | 29〜58体 | **190〜338体** |
| random と greedy の差 | ほぼゼロ | **約2倍**（126秒 vs 249秒） |

達成できたこと:

- **アクションが少ない**: 約4秒に1回まで落ちた
- **影響が大きい**: 1タップ平均が最大338体（v0.4.0 の約6倍）
- **判断に価値が出た**: てきとうに押すと半分の時間しか保たない
- **天井が見えた**: 湧き2倍で greedy も249秒で崩れる

### 残っている問題

- **同時生存数が上限900に張り付く**。湧きが処理能力を超えており、実質「敵の総量」が
  頭打ちになっている。上限に当たっている間は難易度が正しくスケールしていない
- **スキルの使用が偏っている可能性**が残る（greedy 方策が素朴なため、方策側の問題か
  スキル側の問題かを切り分けられていない）
- **コンボの計測は未実装**。磁→爆／磁→雷が単発の何倍かを測る仕掛けをまだ入れていない
- **手触りは未評価**
